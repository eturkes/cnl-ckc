# Project operations

- Toolchain (dev machines): a system swipl ≠ 10.0.2 → `just swipl` (idempotent, digest-verified source build) = gitignored `.toolchain/swipl-10.0.2/` + `bin/` shims `swipl`→that prefix, `python3`→uv cpython 3.15 where uv supplies it (scratch + archived migration scripts only). EVERY Bash call: `export PATH="$ROOT/.toolchain/bin:$PATH"` (shell state resets per call); a PATH without the shim leaks system swipl into `ckc` → `ckc: swipl-version: expected 10.0.2, found: …` rc=2 = toolchain leak, not a corpus defect. CI digest-pinned swipl:10.0.2 container = reference runtime.
- Rust tooling = `just tools` (sha256-pinned installs into `.toolchain/`; `rust/verus.lock` + `rust/tools.lock`); direct rust Bash calls (outside `just`) add the `rust.md` exports in the same call; gate + workspace law → `.claude/rules/rust.md` (fires on `rust/**` + `justfile` touch).
- Deterministic SWI: always `-f none -F none`; writer options explicit.
- Standing decisive chain = `just gate` (root `justfile`; `.toolchain/bin` on PATH) = `just rust` + `just mobile` + `just check` + `just certify` (steps = spec `Artifacts` Gates; rust chain law = `rust.md`); each step prints its green line — `gate: <step> ok`; `fmt-check`: `gate: fmt ok`; `trust`: the `ckc: trust …` meter; `check`: `spec-lint: ok` first (firing = `spec-lint.md`) — then `time: <step> <s> s` (`test`: every binary runs (`--no-fail-fast`), totals + its 5 slowest binaries; a failing run adds each failed binary, each binary without a result line + cargo's error lines, log = `rust/target/test.log`), the run `time: total <s> s`; `just gate` >30 min → background to a log, read at completion; a host without the gitignored toolchain bootstraps in the same command = `just tools && just gate` (+ `just swipl` where SWI-Prolog 10.0.2 is absent). Fast gate (iteration; `just gate` closes the unit) = the steps + tests the change reaches, independent ones in parallel shells (cargo steps share one target lock): `rust/**` → `just fmt-check clippy build trust` + each touched area's harness `cargo test --test <name>` (exports + harness map = `rust.md`) + `just verify` once `ckc-spec` | `ckc-kernel` change + the corpus step a touched command drives (`ckc check` | `ckc ui check` | `ckc certify <id>`); `guidelines/<id>/**` → `ckc compile <id>` + `ckc queries <id>` + `ckc check` + `cargo test --test consumer_recipe` + `cargo test --test sgw_acceptance` (its P2 grades every committed document's spelling); `vendor/**` → `just check` + `just certify`; UI markup, style or script (`rust/ckc/src/ui/**`, `rust/ckc-spec/src/ui.rs`, `tools/ui-mobile-probe.mjs`, `tools/ui-reading-probe.mjs`, `tests/ur-ui/browser/**`) → `just mobile` too; `.agent/spec.md` → `.agent/spec-lint`; `justfile` → the recipes it touches; `.github/**` → `just workflows`. `ckc check` stops at its first violation and verifies release-manifest freshness before its SWI-Prolog stage; per guideline the vocabulary table grammar runs first (a table defect stops the run before the lexicon's full Clex pass, ~60 % of a pre-SWI run); per-item SWI work (`ckc check` documents, red + green probes, questions; `ckc compile` documents; `ckc queries` questions) runs on `CKC_JOBS` workers (default = available parallelism, `1` = sequential) and reports the failure a sequential run reports first (`check/par.rs`); the manifest = HEAD content digests only (no commit id) ⇒ a commit touching release inputs (guidelines/, the fork, clex, NOTICE, LICENSE, the REFERENCE schema section) carries its own manifest: commit, then `just amend-manifest`; `tests/check-mutants` + `dist_cases` d07 clone HEAD ⇒ commit first, then grade. Close order = stage THEN decisive check (`git ls-files` reads the index; a pre-`git add` green can commit red).
- CI gate (`CLAUDE.md` `Execution`) = `just ci <unit>`: a clean tree's HEAD → `ci/<unit>` → the `.github/workflows/ci.yml` run on that commit (push trigger `main` + `ci/**`): job `rust` (`just tools`, `just swipl`, `just rust`, `just mobile`, static `ckc`) → `check` (`just check`) ∥ `certify` (`just certify`) over that binary in the pinned swipl container = every `just gate` step, graded on the commit (HEAD-cloning + history-reading checks included); prints the run id, commit, tree + `time: <job> <conclusion> <s> s`; green → deletes the branch, `gate: ci ok`; red → `--log-failed` tail, branch kept: fix, amend, rerun. ≈ 75 min (rust job ≈ 50) → background to a log. A message-only amend after the run keeps the graded tree (`git rev-parse HEAD^{tree}` equal) = the commit's gate record. `just gate` = the same chain on this host: iteration's full run + the fallback where CI cannot run.
- Release lines (procedure = `docs/REFERENCE.md` § Releasing; rulings = spec Decisions `Publication scope`): `main` = development; a cut = branch `release/kb-<date>` + SSH-signed annotated `kb-<date>-rc.<n>` (signer = `CLAUDE.local.md`; verify each tag + its files per § Releasing before the user's push) + the review worktree `.release/kb-<date>/` (gitignored, durable: it holds the reviewer's live ledger, so task-close cleanup leaves it; its recipes export `CKC_TOOLCHAIN=$ROOT/.toolchain`). The line takes only ledger batches (MAIN commits them on the user's request, then `just amend-manifest` in the worktree), corrections of rejected documents (a corpus round run in the worktree, committed on the branch), development-tooling + operating-procedure changes that leave every release input unchanged (template refreshes, gates, agent law; on the user's request; user ruling at the template-refresh request) and the release record; `just ci <unit>` from the worktree grades the line; tags, branch pushes + GitHub releases = remote actions on the user's go. After the release tag: `git merge --no-ff release/kb-<date>` on `main` (a `release-manifest.tsv` conflict → keep either side + commit the merge, because `ckc release-manifest` digests HEAD = pre-merge main while the merge is open; a moved schema → recompile + commit), then `just amend-manifest` (amending the merge commit keeps both parents), gate, then `git worktree remove .release/kb-<date>`. The cut freezes the line's schema identifier: the next predicate-set or meaning change on `main` = the next identifier (spec Decisions `Schema evolution`).
- Corpus loop (ruling on `CLAUDE.md` `Session flow` MAINTAIN bodies + `Routing`) = the MAINTAIN body for corpus rounds, whatever the run's length, run in its own sessions — never inside a deferral-queue run (user rulings): prompt + procedure = `docs/REFERENCE.md` § Operating; queue = `.agent/queue.md` (one source doc in progress at a time); round roles + close = `.claude/rules/corpus.md` (MAIN drafts ACE, edits compiler + lexicon, rules + commits; `researcher`s + one closing `reviewer` covering L0–L6).
- Unit contracts (IMPLEMENT + MAINTAIN): `.agent/contracts/<unit>.md` = testable predicates + tier + gate identity + rulings, written before code (every kernel contract passes `consultant` first, required rather than MAIN's per-case dispatch: user ruling on `CLAUDE.md` `Session flow` deep units; its `tester` = `rust.md` kernel unit flow), moved to `.agent/archive/contracts/` at unit close. Legacy contracts: M5 = `.agent/archive/contracts/m5u*.md` (`.scratch/contracts/m5u*.md` = read-only symlinks serving frozen brief text); M3/M4 = scratch-only, pointers in the archive records. Milestone history: `git log --grep "(M<m>[. ]"` (compendium replan restarted numbering → topic sorts earlier-era hits).
- Authority map: simplified overview → root `README.md`; pipeline + audit story → `docs/REFERENCE.md` (holds the pre-split root README's technical content — archive/scratch refs to `README § …` resolve there); guideline provenance/rights/coverage → `guidelines/<id>/README.md`; ACE→Prolog compiler contract → `vendor/ape/prolog/ace_to_pl.pl` header; TCB + fork boundaries → `vendor/*/PROVENANCE`; fork-edit law → `.claude/rules/vendor.md`; retired pre-cutover toolchain → tag `legacy`; clinician design law → `.claude/rules/clinician-design.md`; gates → `.github/workflows/ci.yml`; M5 plan of record → `.agent/archive/rust-rewrite-plan.md` (read at unit start); language-boundary charter → `.agent/spec.md` Decisions (history: `.agent/archive/standing-instructions.md`).
