# Project operations

- Toolchain (sole dev workstation): system swipl/python too new → gitignored `.toolchain/`: `swipl-9.2.9/` prefix built from `https://www.swi-prolog.org/download/stable/src/swipl-9.2.9.tar.gz` (`cmake -G Ninja -DCMAKE_BUILD_TYPE=Release -DINSTALL_DOCUMENTATION=OFF -DSWIPL_PACKAGES_JAVA=OFF -DSWIPL_PACKAGES_X=OFF -DSWIPL_PACKAGES_ODBC=OFF` + `ninja install`) + `bin/` shims `swipl`→that prefix, `python3`→uv cpython 3.13. EVERY Bash call: `export PATH="$ROOT/.toolchain/bin:$PATH"` (shell state resets per call); a PATH without the shims leaks system swipl into goal.py → `ace_to_pl_error(uncaught,unwind(halt(0)))` rc=2 = toolchain leak, not a corpus defect. Lost ⇒ repeat recipe. CI digest-pinned swipl:9.2.9 container = reference runtime; python floor = 3.11 (`-P` flag; hold to the 3.11 stdlib surface — pathlib `follow_symlinks` kwarg = 3.12+).
