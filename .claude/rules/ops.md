# Project operations

- Toolchain (dev machines): a system swipl ≠ 9.2.9 → `just swipl` (idempotent, digest-verified source build) = gitignored `.toolchain/swipl-9.2.9/` + `bin/` shims `swipl`→that prefix, `python3`→uv cpython 3.13 (scratch + archived migration scripts only). EVERY Bash call: `export PATH="$ROOT/.toolchain/bin:$PATH"` (shell state resets per call); a PATH without the shim leaks system swipl into `ckc` → `ace_to_pl_error(uncaught,unwind(halt(0)))` rc=2 = toolchain leak, not a corpus defect. CI digest-pinned swipl:9.2.9 container = reference runtime.
- Rust tooling = `just tools` (sha256-pinned installs into `.toolchain/`; `rust/verus.lock` + `rust/tools.lock`); direct rust Bash calls (outside `just`) add the `rust.md` exports in the same call; gate + workspace law → `.claude/rules/rust.md` (fires on `rust/**` + `justfile` touch).
- Deterministic SWI: always `-f none -F none`; writer options explicit.
- Standing decisive chain = `just gate` (root `justfile`; `.toolchain/bin` on PATH) = `just rust` + `just check` + `just certify` (steps = spec `Artifacts` Gates; rust chain law = `rust.md`); each step prints its green line — `gate: <step> ok`; `fmt-check`: `gate: fmt ok`; `trust`: the `ckc: trust …` meter; `check`: `spec-lint: ok` first (firing = `spec-lint.md`) — then `time: <step> <s> s` (`test`: totals + its 5 slowest binaries), the run `time: total <s> s`; `just gate` >30 min → background to a log, read at completion. Fast gate (iteration; `just gate` closes the unit) = the steps + tests the change reaches, independent ones in parallel shells (cargo steps share one target lock): `rust/**` → `just fmt-check clippy build trust` + each touched area's harness `cargo test --test <name>` (exports + harness map = `rust.md`) + `just verify` once `ckc-spec` | `ckc-kernel` change + the corpus step a touched command drives (`ckc check` | `ckc ui check` | `ckc certify <id>`); `guidelines/<id>/**` → `ckc compile <id>` + `ckc queries <id>` + `ckc check`; `vendor/**` → `just check` + `just certify`; `.agent/spec.md` → `.agent/spec-lint`; `justfile` → the recipes it touches; `.github/**` → `just workflows`. `ckc check` stops at its first violation and verifies release-manifest freshness before its SWI-Prolog stage; per-item SWI work (`ckc check` documents, red + green probes, questions; `ckc compile` documents; `ckc queries` questions) runs on `CKC_JOBS` workers (default = available parallelism, `1` = sequential) and reports the failure a sequential run reports first (`check/par.rs`); the manifest = HEAD content digests only (no commit id) ⇒ a commit touching release inputs (guidelines/, the fork, clex, NOTICE, the REFERENCE schema section) carries its own manifest: commit, then `just amend-manifest`; `tests/check-mutants` + `dist_cases` d07 clone HEAD ⇒ commit first, then grade. Close order = stage THEN decisive check (`git ls-files` reads the index; a pre-`git add` green can commit red).
- Corpus loop (ruling on `CLAUDE.md` `Session flow` MAINTAIN bodies + `Routing`) = the MAINTAIN body for corpus rounds, whatever the run's length, run in its own sessions — never inside a deferral-queue run (user rulings): prompt + procedure = `docs/REFERENCE.md` § Operating; queue = `.agent/queue.md` (one source doc in progress at a time); round roles + close = `.claude/rules/corpus.md` (MAIN drafts ACE, edits compiler + lexicon, rules + commits; `researcher`s + one closing `reviewer` covering L0–L6 where needed).
- Unit contracts (IMPLEMENT + MAINTAIN): `.agent/contracts/<unit>.md` = testable predicates + tier + gate identity + rulings, written before code (every kernel contract passes `consultant` first, required rather than MAIN's per-case dispatch: user ruling on `CLAUDE.md` `Session flow` deep units; its `tester` + `reviewer` = `rust.md` kernel unit flow), moved to `.agent/archive/contracts/` at unit close. Legacy contracts: M5 = `archive/contracts/m5u*.md` (`.scratch/contracts/m5u*.md` = read-only symlinks serving frozen brief text); M3/M4 = scratch-only, pointers in the archive records.
