# Project operations

- Toolchain (sole dev workstation): system swipl too new → `just swipl` (idempotent, digest-verified source build) = gitignored `.toolchain/swipl-9.2.9/` + `bin/` shims `swipl`→that prefix, `python3`→uv cpython 3.13 (scratch + archived migration scripts only). EVERY Bash call: `export PATH="$ROOT/.toolchain/bin:$PATH"` (shell state resets per call); a PATH without the shim leaks system swipl into `ckc` → `ace_to_pl_error(uncaught,unwind(halt(0)))` rc=2 = toolchain leak, not a corpus defect. CI digest-pinned swipl:9.2.9 container = reference runtime.
- Rust tooling = `just tools` (sha256-pinned installs into `.toolchain/`; `rust/verus.lock` + `rust/tools.lock`); direct rust Bash calls (outside `just`) add the `rust.md` exports in the same call; gate + workspace law → `.claude/rules/rust.md` (fires on `rust/**` + `justfile` touch).
- Deterministic SWI: always `-f none -F none`; writer options explicit.
- Standing decisive chain = `just gate` (root `justfile`; `.toolchain/bin` on PATH) = `just rust` + `just check` + `just certify` (steps = spec `Artifacts` Gates; rust chain law = `rust.md`); each step prints `gate: <step> ok`, `.agent/spec-lint` (the template's byte copy, `upstream-sync.md`) `spec-lint: ok`; `just gate` >30 min → background to a log, read at completion; rust-only edits → `just rust` (~25 min under load). `ckc check` stops at its first violation and verifies release-manifest freshness before its SWI-Prolog stage; the manifest = HEAD content digests only (no commit id) ⇒ a commit touching release inputs (guidelines/, the fork, clex, NOTICE, the REFERENCE schema section) carries its own manifest: commit, then `just amend-manifest`; `tests/check-mutants` + `dist_cases` d07 clone HEAD ⇒ commit first, then grade. Close order = stage THEN decisive check (`git ls-files` reads the index; a pre-`git add` green can commit red).
- Corpus loop (ruling on `CLAUDE.md` `Session flow` MAINTAIN bodies + `Routing`) = the MAINTAIN body for corpus rounds, whatever the run's length, run in its own sessions — never inside a deferral-queue run (user rulings): prompt + procedure = `docs/REFERENCE.md` § Operating; a fresh session continues a corpus run through the prompt set's `resume.md` (finish line = the corpus prompt's `Met when`) + stops to continue later through `pause.md` | `pause-now.md` (in-flight work finishes first | stops at once; prompt-set path = `upstream-sync.md`); queue = `.agent/queue.md` (one source doc in progress at a time); round roles + close = `.claude/rules/corpus.md` (MAIN drafts ACE, edits compiler + lexicon, rules + commits; `researcher`s + one closing `reviewer` covering L0–L6 where needed).
- Unit contracts (IMPLEMENT + MAINTAIN): `.agent/contracts/<unit>.md` = testable predicates + tier + gate identity + rulings, written before code (every kernel contract passes `consultant` first: user ruling on the `Session flow` fit, `upstream-sync.md` index), moved to `.agent/archive/contracts/` at unit close; review ledger = `.agent/review.md`. Legacy contracts: M5 = `archive/contracts/m5u*.md` (`.scratch/contracts/m5u*.md` = read-only symlinks serving frozen brief text); M3/M4 = scratch-only, pointers in the archive records. Milestone history: `git log --grep "(M<m>[. ]"` (compendium replan restarted numbering → topic sorts earlier-era hits).
- Pause notes: `ckc check` agent-spec grammar-checks `.agent/spec.md` `Tasks` (rows `- [ ] <unit>` | `- [x] <sha> <unit>`; last line = the `.agent/deferred.md` pointer) ⇒ a resume note = `pause.md`'s | `pause-now.md`'s one `- [ ] RESUME: …` row at the head of the open unit, deleted by the resumed run's closing commit.
- Authority map: simplified overview → root `README.md`; pipeline + audit story → `docs/REFERENCE.md` (holds the pre-split root README's technical content — archive/scratch refs to `README § …` resolve there); guideline provenance/rights/coverage → `guidelines/<id>/README.md`; ACE→Prolog compiler contract → `vendor/ape/prolog/ace_to_pl.pl` header; TCB + fork boundaries → `vendor/*/PROVENANCE`; fork-edit law → `.claude/rules/vendor.md`; retired pre-cutover toolchain → tag `legacy`; clinician design law → `.claude/rules/clinician-design.md`; gates → `.github/workflows/ci.yml`; M5 plan of record → `.agent/archive/rust-rewrite-plan.md` (read at unit start); language-boundary charter → `.agent/spec.md` Decisions (history: `archive/standing-instructions.md`).
