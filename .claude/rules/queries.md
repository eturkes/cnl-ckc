# Question / answer / trace law

Contracts of record: `.scratch/contracts/m4u5.md` (question), `m4u6.md` (answer, v1.3 + amendments), `m4u7.md` (trace, v1..v1.3.9); the answer + trace law now lives in the K2/K3 spec (`rust/ckc-spec/src/{engine,answers,trace}.rs`), byte-parity with the retired fork modes (tag `legacy`) except trace nodes naming the clause's own `% S<n>:` block (contract q8). Invocation/payload/reject vocab = docs/REFERENCE.md question/answer/trace sections + the `ace_to_pl.pl` header (question mode).

- Question mode: query sentence law = two-level — post-parse count in a query-only `accept_or_reject` clause BEFORE the shared empty-DRS guard (lone whitespace line → `query_sentences(0)`; document mode keeps `empty_drs`). Every question/modal box passes `query_box_check/1` (drs/2 + proper-list dom/conds → else `invalid_drs_shape`; non-drs question payload stays `leaf(question/1)`). Strip/scan/markers classify the `query_cond_inner/2` anchor-stripped term — anchored modal = parser-unreachable and compiles byte-equal to bare. Stage A = condition-order walker (conds + drs/2 condition args only; payload args never read). Emitted reject bytes = canonical ignore_ops (`leaf(/(relation,3))`). APE question DRS shapes: wh → `query(Ref,who|which|what)`; existential yes/no → bare question box; universal yes/no → `=>` inside the box (rejects in v1 queries); modal wh → `should(drs(...))` nested; negated wh → `-drs`; disjunctive wh → `v(drs,drs)`; unknown content words still gate on ulex.
- Answer (`ckc v1 answer <answer-manifest.tsv> <query-pl>`; rc0 = 2 stdout lines, rc1 = proof class, rc2 = check_load/usage): the query file is data (two terms: ground `'$guideline_query'/4` record with wrapper functors `ace_sha256(_)`/`ulex(_)`, then the projection); malformed → `check_load,query_file(<why>)`. Bounded solve = inner-inference exhaustion cumulative across backtracking (a depth limit alone backtracks past an exceeded branch to a shallow proof ⇒ yes). `sol/1` payload = list in answer-manifest order incl. singleton. The canonical writer emits graphic atoms bare (`goal_foreign(;,2)`) — writer bytes = sole expected-byte authority.
- Trace (`ckc v1 trace <answer-manifest.tsv> <query-pl> <answers-pl>`; rc0 = trace artifact stdout, rc2 = one stderr line `ace_to_pl_error(check_load,answers_file(<why>)).`): answers_file why ORDER = term_count → record_shape → record_nonground → record_version → qid_mismatch → record_query_sha256 → query_sha256_mismatch → result_shape → result_mode_mismatch → solutions_list → solution_shape(I) → solution_values(I) → solution_arity(I,E,A). clause_sha256 = sha256(canonical clause-line re-render + LF) of the pristine decompiled clause — emitter-definitional; hand-spelled fixture lines re-render before hashing. NAF digest body: singleton `\+ G` bare, conjunction `\+ (G1, G2)`. `% S<n>:` block marker head = ASCII digits, no leading zero. Proof roots = clause nodes only; `proved([])` invalid. trace-reject fixture lane = SINGULAR `trace-reject/`, paired `<qid>.answers` + `<qid>.expect`, qid = filename stem.
- `tests/queries/` + `guidelines/*/queries/` bytes = committed pins; `ckc check` re-derives them (question compile through the fork, answers + traces through `ckc v1`). Regenerate a pin only by running `ckc` on the case, then diff the churn against the contract (AM6 hazard, `ui.md`); wholesale literal re-pins = a script under `.agent/archive/migrations/` (precedent `r99-repin.py`).
- Empty-stderr assertions need a UTF-8 locale (LC_ALL=C adds SWI source-load warnings with identical payload bytes).
