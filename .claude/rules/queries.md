# Question / answer / trace law

Contracts of record: `.scratch/contracts/m4u5.md` (question), `m4u6.md` (answer, v1.3 + amendments), `m4u7.md` (trace, v1..v1.3.9); the answer + trace law now lives in the K2/K3 spec (`rust/ckc-spec/src/{engine,answers,trace}.rs`), byte-parity with the retired fork modes (tag `legacy`) except trace nodes naming the clause's own `% S<n>:` block (contract q8), trace mode's cut of negation calls failing `naf_safe` (contract q7), the fail-closed negation frame (contract cs0: a negation whose inner search a bound cut leaves the search incomplete, as K3's frame already did) and goal selection (contract eso: an operator goal whose inner context is unbound waits for its box content ⇒ search order, bound trips + first proofs differ from leftmost SWI; an unsafe negation reached through a waiting goal can answer differently). Invocation/payload/reject vocab = docs/REFERENCE.md question/answer/trace sections + the `ace_to_pl.pl` header (question mode).

- One schema (c1): every question record = `'$guideline_query'(v1,Qid,ace_sha256(_),ulex(_),vocabulary(none|sha256(_)))` (/5); a guideline's `vocabulary.tsv` reaches its questions too (record digest; upper-bound groups flattened into their box — a placeholder inside one rejects `condition_shape`; `relation/3` leaves admitted; then the `v2_annotate` pattern pass, a leftover `of` link rejecting); without a table both shapes reject. Answer/trace goal whitelist = the 20 semantic predicates + the comparison built-ins `guideline_satisfies/4|6` (s1: + `guideline_grade/5`, `guideline_preference/4`; s2: + `guideline_qualifier/4` — ACE questions never emit those three: question mode skips the strength pass, so an adverb question rejects `query_unsupported(leaf(/(modifier_adv,3)),S)`; a reserved adverb lemma rejects `reserved_name_collision` first, as every lemma slot; nt1: + `guideline_unit/3`, which questions emit with the built-ins: the nt1 pass runs on question goals; cs1: + `guideline_exclusion/1`, which questions never emit: question mode runs no scope pass; da1: + the arithmetic built-ins `guideline_product/6`, `guideline_quotient/6`, which questions never emit; sup1: + `guideline_supersession/4`, `guideline_evaluation_date/1`, which questions never emit: question mode runs no supersession pass) for every query; a query composes with any document set (no version or table-presence reject); answers/traces artifacts keep their `v1` token.
- Question mode: query sentence law = two-level — post-parse count in a query-only `accept_or_reject` clause BEFORE the shared empty-DRS guard (lone whitespace line → `query_sentences(0)`; document mode keeps `empty_drs`). Every question/modal box passes `query_box_check/1` (drs/2 + proper-list dom/conds → else `invalid_drs_shape`; non-drs question payload stays `leaf(question/1)`). Strip/scan/markers classify the `query_cond_inner/2` anchor-stripped term — anchored modal = parser-unreachable and compiles byte-equal to bare. Stage A = condition-order walker (conds + drs/2 condition args only; payload args never read). Emitted reject bytes = canonical ignore_ops (`leaf(/(relation,3))`). APE question DRS shapes: wh → `query(Ref,who|which|what)`; existential yes/no → bare question box; universal yes/no → `=>` inside the box (rejects in v1 queries); modal wh → `should(drs(...))` nested; negated wh → `-drs`; disjunctive wh → `v(drs,drs)`; unknown content words still gate on ulex.
- Answer (`ckc v1 answer <answer-manifest.tsv> <query-pl>`; rc0 = 2 stdout lines, rc1 = proof class, rc2 = check_load/usage): the query file is data (two terms: ground `'$guideline_query'/5` record with wrapper functors `ace_sha256(_)`/`ulex(_)`/`vocabulary(_)`, then the projection); malformed → `check_load,query_file(<why>)`. Bounded solve = inner-inference exhaustion cumulative across backtracking (a depth limit alone backtracks past an exceeded branch to a shallow proof ⇒ yes); a negation succeeds only after its inner search fails with no bound cut inside (contract cs0: a frame keeps the prune flag at site entry; a refuted negation absorbs inner prunes; a frame resuming after a prune inside ends the search incomplete ⇒ yes/no `indeterminate(limit)`, replay obligation underivable; the fork's SWI P7 replay stays fail-open, the native aggregate replay in `ckc check` catches it). `sol/1` payload = list in answer-manifest order incl. singleton. The canonical writer emits graphic atoms bare (`goal_foreign(;,2)`) — writer bytes = sole expected-byte authority.
- Trace (`ckc v1 trace <answer-manifest.tsv> <query-pl> <answers-pl>`; rc0 = trace artifact stdout, rc2 = one stderr line `ace_to_pl_error(check_load,answers_file(<why>)).`): answers_file why ORDER = noncanonical (the canonical v1 reader: any token, record shape, version or digest form a v1 answers file cannot hold) → term_count | record_shape (a traces file) → qid_mismatch → query_sha256_mismatch → result_shape → result_mode_mismatch → solutions_list → solution_shape(I) → solution_values(I) → solution_arity(I,E,A). clause_sha256 = sha256(canonical clause-line re-render + LF) of the pristine decompiled clause — emitter-definitional; hand-spelled fixture lines re-render before hashing. NAF digest body: singleton `\+ G` bare, conjunction `\+ (G1, G2)`. `% S<n>:` block marker head = ASCII digits, no leading zero. Proof roots = clause nodes or `builtin(G)` leaves (nt1 D6: a comparison built-in that held, the goal as called, no digest, no node charge; da1 D8: an arithmetic built-in that computed, outputs bound to its result, re-evaluated by trace-check); `proved([])` invalid. trace-reject fixture lane = SINGULAR `trace-reject/`, paired `<qid>.answers` + `<qid>.expect`, qid = filename stem.
- `tests/queries/` + `guidelines/*/queries/` bytes = committed pins; `ckc check` re-derives them (question compile through the fork, answers + traces through `ckc v1`). Regenerate a pin only by running `ckc` on the case, then diff the churn against the contract (AM6 hazard, `ui.md`); wholesale literal re-pins = a script under `.agent/archive/migrations/` (precedent `r99-repin.py`).
- Empty-stderr assertions need a UTF-8 locale (LC_ALL=C adds SWI source-load warnings with identical payload bytes).
