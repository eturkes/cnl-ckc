# Question / answer / trace law

Contracts of record: `.scratch/contracts/m4u5.md` (question), `m4u6.md` (answer, v1.3 + amendments), `m4u7.md` (trace, v1..v1.3.9). Invocation/payload/reject vocab = docs/REFERENCE.md question/answer/trace sections + the `ace_to_pl.pl` header.

- Question mode: query sentence law = two-level — post-parse count in a query-only `accept_or_reject` clause BEFORE the shared empty-DRS guard (lone whitespace line → `query_sentences(0)`; document mode keeps `empty_drs`). Every question/modal box passes `query_box_check/1` (drs/2 + proper-list dom/conds → else `invalid_drs_shape`; non-drs question payload stays `leaf(question/1)`). Strip/scan/markers classify the `query_cond_inner/2` anchor-stripped term — anchored modal = parser-unreachable and compiles byte-equal to bare. Stage A = condition-order walker (conds + drs/2 condition args only; payload args never read). Emitted reject bytes = canonical ignore_ops (`leaf(/(relation,3))`). APE question DRS shapes: wh → `query(Ref,who|which|what)`; existential yes/no → bare question box; universal yes/no → `=>` inside the box (rejects in v1 queries); modal wh → `should(drs(...))` nested; negated wh → `-drs`; disjunctive wh → `v(drs,drs)`; unknown content words still gate on ulex.
- Answer mode (`-- answer <answer-manifest.tsv> <query-pl>`; rc0 = 2 stdout lines, rc1 = proof class, rc2 = check_load/usage/uncaught): census physical EOF ⟺ `end_of_file` read ∧ equal `byte_count` (zero-width read; literal `end_of_file.` = data; `byte_count` works on open_string streams, `char_count` off-by-one). Record shape requires wrapper functors `ace_sha256(_)`/`ulex(_)` pre-nonground. `set_stream(S, file_name(File))` after open_string → verbatim deterministic syntax-error terms. Solve-time runtime exceptions = `uncaught` rc2 one line via main's catch. `sol/1` payload = Prolog list in answer-manifest order incl. singleton. Bounded solve = inner-inference exhaustion cumulative across backtracking (depth limit alone backtracks past an exceeded branch to a shallow proof ⇒ integer result ⇒ yes). The canonical writer emits graphic atoms bare (`goal_foreign(;,2)`) — writer bytes = sole expected-byte authority.
- Trace mode (`-- trace <answer-manifest.tsv> <query-pl> <answers-pl>`; rc0 = trace artifact stdout, rc2 = one stderr line `ace_to_pl_error(check_load,answers_file(<why>)).`): answers_file why ORDER = term_count → record_shape → record_nonground → record_version → qid_mismatch → record_query_sha256 → query_sha256_mismatch → result_shape → result_mode_mismatch → solutions_list → solution_shape(I) → solution_values(I) → solution_arity(I,E,A); `@/2` cyclic-notation record = record_shape (custody reader never reconstructs cycles). clause_sha256 = sha256(canonical clause-line re-render + LF) through the document writer from the PRISTINE decompiled clause — emitter-definitional; hand-spelled fixture lines re-render before hashing; foreign spellings then fail the validator digest join. NAF digest body: singleton `\+ G` bare, conjunction `\+ (G1, G2)`. goal.py trace scanner token classes = ASCII-definitional (unquoted atoms `[a-z][a-zA-Z0-9_]*`; non-ASCII in a gated position → scan None → parse violation; Python isdigit/isalpha are Unicode-wide and crash int() on superscripts). `% S<n>:` block marker head = ASCII digits no leading zero, else comment. Proof roots = clause nodes only; `proved([])` invalid. Writer guard detail = `trace_unserializable` (single). trace-reject fixture lane = SINGULAR `trace-reject/`, paired `<qid>.answers`+`<qid>.expect`, qid = filename stem, partner line `trace-reject member without partner: <case>/<qid>.<ext>`.
