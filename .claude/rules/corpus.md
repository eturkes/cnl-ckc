# Corpus authoring law

Protocol = docs/REFERENCE.md § Operating; supported ACE constructs = the `ace_to_pl.pl` header. Compendium + harvest technique: read `.agent/archive/harvest-technique.md` before compendium edits, queue promotion, or fetch/access work.

## Round roles (corpus loop)

MAIN drafts every ACE document; teammates read + attack (fits, dispatch economics + mechanics = `CLAUDE.md` `Teammates`).
- MAIN — ACE per ruled statement batch: knowledge-only (no witness seed facts, proper-name stand-ins, authored queries), validated by `compile` + `check`; lexicon deltas screened against `audit/lexicon-rejects.tsv` (MAIN appends each refusal). Faithfulness = MAIN review, statement by statement. Also MAIN: `ace_to_pl.pl` + lexicon edits, all primary-tree writes, `ckc check` validator pins (`ckc-spec` + fixtures), guideline README + queue updates, id choice, rights rulings, statement batch verdicts, gate reruns, commits.
- `researcher`, extraction — bulk-reads the source; verbatim extraction evidence with page/byte anchors + an anchored normative-statement inventory. Raw material: MAIN spot-checks verbatim fidelity before adopting.
- `researcher`, fetch rounds — candidate discovery, rights/licensing quotes, URL verification (brief names its browser access).
- Closing `reviewer` = one covering every lens below, every round (`CLAUDE.md` `Session flow`: a MAINTAIN request's closing diff; user ruling: template form); `file:line` findings; disputed semantics ⇒ MAIN rules.
  - L0 completeness: source normative statements vs `ace/` inventory vs README uncovered-list; grades the coverage statement + the stop check.
  - Adversarial: L1 ACE↔extraction fidelity, L2 coverage-claim soundness, L3 README claims, L4 knowledge-only status, L5 obligation count + discharge, L6 `audit/projection-notes.tsv` fidelity.
- Flow: spawn extraction early; MAIN batch-rules the inventory (project / uncovered with reason), drafts ACE per ruled batch, authors the lexicon delta, compiles, checks; the closing `reviewer` attacks the assembled round pre-commit across L0–L6; MAIN fixes, reruns, commits. Teammates never run `ckc check` — N concurrent in-worktree runs thrash the machine (subprocess wall caps trip); MAIN runs the one decisive gate at harvest.
- Round close = `ops.md` Close order (stage, then the decisive check) bound here: harvest (report read + artifacts byte-verified or re-derived); ledgers current before the gate (coverage.tsv, `audit/`, guideline README, `.agent/queue.md` pending list ordered, next round first); decisive gate = `ckc compile <id>` + `ckc queries <id>` + `ckc check` under the toolchain PATH; scoped commit(s) on main (on a release branch for a correction of a rejected document after its cut: `ops.md` Release lines); an input-touching commit carries its manifest (commit, then `just amend-manifest`). A blocked round closes the same way with `blocked(<why>)` in queue.md.

## Authoring law

- ACE facts: noun copula needs the indefinite article (`X is a noun.`); unknown content words without a ulex entry surface in `ape_messages`; consult `audit/lexicon-rejects.tsv` before proposing lexicon entries (lexicon law fires on ulex touch).
- Coverage ledger (`check_coverage`): pinned 3-line generic header (further `#` lines before rows only), 5-col rows, status grammar `ace(<docid>)`/`restates(<id>)`/`uncovered(<class>: <reason>)`/`pending`, classes heading|process|external|aim|descriptive|notice|inexpressible. Per-file region closure against each evidence file's `identify the N payloads below` census + bracketed `[<id> | ...]` locator ids (locator-less evidence closes on count alone); ace↔docid bijection; restates = single-step to a non-restated existing target; meter `ckc: coverage ok <id> <n> regions; ace=<a> restates=<r> uncovered=<u> inexpressible=<i> pending=<p>`. Document completion = check green ∧ pending=0.
- Inexpressible protocol: a normative statement the controlled language cannot express ⇒ region `uncovered(inexpressible: <reason>)`, round moves on; the meter's `inexpressible=<i>` banks the gap census (classes + dispositions: `docs/m7-gap-taxonomy.md`).
- Typing = spec Decisions `Authoring principle`: a meaning some schema carrier holds is typed, a hard statement included (MAIN's best attempt; its interpretation → the document's `audit/projection-notes.tsv` row, as for every rule); a dropped meaning the schema could carry = a defect, never a recorded choice; a meaning no carrier holds → the inexpressible protocol, never invented data (endpoint, value, referent).
- Align authoring (`ckc align <gid> <docid>` stdin rows `group<TAB>side<TAB>occurrence<TAB>span`): occurrence = 1-based raw-substring count, non-overlapping left-to-right, INCLUDING hits inside longer words (ace `opioid-therapy` occ1 sits inside `nonopioid-therapy`; standalone = occ2). Rubric = REFERENCE Operating step 4. Every ACE doc needs an align file (`ckc check` align inventory); any ACE/passage edit → re-author (render stops on stale offsets). Exemplars: `cdc-2022-opioid` rec01 (sub-span groups; g7 src occ1+occ3 with an overlap-partitioning middle), rec08-imp13 (2-src-span group). Content gate = `ckc ui check` corpus render.
- Vocabulary table (`guidelines/<id>/vocabulary.tsv`; grammar = `docs/REFERENCE.md` § Vocabulary table and time annotations): every document + question of the guideline compiles with it; any byte change rewrites every record digest → recompile the whole guideline. Shapes beyond interval + recurrence: `before|after <plain referent>` (order, no bound), `<verb> N <items> per 1 <unit>` (count per period: counted item = the verb's object), `at an interval of … during a window of <cmp> N <unit> of <anchor>` (scoped recurrence: every spacing pp of that event becomes `guideline_recurrence_window`); a unit abbreviation (`d`) = ulex count noun + `unit d day` row; approximate = `at an approximate interval of 2 hours` | `for 2 approximate hours` | `after 4 approximate weeks of <anchor>` (exact count only; compiles `about`); ranged minimum = `for at least N <unit> to M <unit>` | `after at least N <unit> of <anchor> to M <unit>` (same unit, N < M; the minimum lies in N..M, the event keeps `at least N`). Author timing as `for|during <cmp> N <unit>` (duration), `after|before <cmp> N <unit> of <anchor>`, `within <cmp> N <unit> of <anchor>` (a forward window = an `after` + `within` pair on one anchor), `at an interval of <cmp> N <unit>` (spacing between occurrences; `at most` = maximum gap, never a count per window). Source text with no integer bound (several, a few) stays lexical + recorded in projection notes; never invent an endpoint. Thresholds (nt1; REFERENCE § Comparison conditions): a condition's `exactly|at least|more than|at most|less than N` compiles to a value comparison, a plain number in a condition keeps exact matching ⇒ write the comparison the source states (`≥65` → `If a patient has an age and the age includes at least 65 years …`; `multiple` → `at least 2`, as rec09-imp12); an exact source value in a root fact → `exactly N` (`A scheduled-opioid-example uses exactly 1 tablet at an interval of exactly 4 hours.`; contract root-exact), while a root `at most` / `less than` rejects; time units compare within seconds–weeks and within months–years, never a day with a month ⇒ each passage keeps its source unit (user ruling: `30 days` and `1 month` stay distinct documents); a bare calendar adverb (`daily`) carries no bound (user ruling) and stays inside a noun.
- Dose arithmetic (contracts `.agent/archive/contracts/da2.md`, `da3.md`; REFERENCE § Formulas in ACE): an opioid dosage `contains` its drug amount (`<opioid>-milligrams-per-day`, `transdermal-fentanyl-micrograms-per-hour`) and `includes` its MME amount (`MME-units-per-day`) — the conversion rules (`cdc2022-opioid-s33-01`) read `contains` and derive `includes`; a formula rule's result verbs and result nouns stay absent from its own condition (`cdc2022-opioid-s42-15`: `target-MME-units-per-day` beside the condition's `MME-units-per-day`); a formula stays out of any rule with a time condition (S42-15 = a formula rule + a time-conditioned permission rule; the hazard — the converted time quantity reading `guideline_cardinality` before its event bound it, re-entering every cardinality head — predates binding-first bodies, which read that count after the event; the law stays: the cycle scan reports such a rule as a red case), and its condition leads with its most selective input (the drug amount: `If some <opioid>-milligrams-per-day X are contained by an opioid-dosage …`), never a generic noun that Skolem-producing rules derive (`opioid-dosage`: `s38-20`, `rec05-imp12`) — leftmost search otherwise reaches the rule's own heads without end; gate = `ckc check`'s formula cycle scan (`rust/ckc/src/check/cycle.rs`, before the SWI-Prolog stage: each formula body's open goals — key unbound when it runs — must not reach a clause of the rule's own sentence through unifying rule heads within depth 7; meter `ckc: formula-cycles ok <id> <n> formula clauses`), so an example's condition verbs are ones no rule derives (`takes`, `yields`: s33-01's worked examples); a formula target sits outside every modal box and names a computed amount or target, never a dosage the patient has; worked examples compute over example-only nouns, their derived amounts included (`daily-hydrocodone-milligrams`, never a conversion input noun: a derived input re-opens the opioid-dosage search). A table region = its title, header, rows and notes as one payload (evidence header `Table convention`), so every condition a note states reads on the table's own page (user ruling).
- Hedges (contract `.agent/archive/contracts/s2.md` D10; shapes = REFERENCE § Strength annotations): a `qualifier` row per word the corpus uses; the qualifier sits on the event of the action or claim the source qualifies. `might` + other truth-attenuating hedges → the restored proposition under `can`, adverb inside, source polarity kept under the box (`can possibly need`; `unlikely to V` → `it is possible that X does not likely V`), never `may`; softened advice (`might consider`) → `may <verb>`, no qualifier; `may` = an agent's permission only — a capability or possibility of a process, instrument or structure (`a reevaluation can confirm …`, `coverage can facilitate …`) takes `can`; applicability (`as appropriate`, `when feasible`, `as needed`) → an antecedent copula guard on the thing judged (`If a nonopioid-therapy is appropriate for a patient then …`); focus, manner + force keep the claim's own context + operator (`should carefully monitor`); a nominalized qualified action → verb + adverb; a hedge on a thing (attributive, relative clause) stays in its noun; usuality words never become time bounds. APE: an adverb before a modal lands inside the box for a copula only (`X possibly can be Y`; `can possibly be` fails); other verbs take `can often V`; `should not generally V` parses. An attenuating adverb (usuality, ideality, possibility, applicability) on a head without a modal on its path rejects `qualifier_shape(asserted, S)`; `more`/`most` + adverb rejects `qualifier_shape(degree, S)`.
- Scope exclusions (contract cs1; REFERENCE § Scope exclusions; the guideline's table holds `scope	recommendation	<guideline id>` + `exclusion	apply	scope`): a statement that the guideline's recommendations do not apply → `If <condition> then it is false that a recommendation applies to the patient.` (one sentence per condition; the subject a plain `a recommendation`; the condition over patient facts); an exception to an exclusion = a `does not provably` condition of that exclusion rule (S7-03 discharge prescribing inside the facility exclusions); `Every recommendation does not apply …` / `No recommendation applies …` reject (`scope_shape(subject, S)`); a statement that limits ONE recommendation (`Recommendation 10 applies to …`) = conditions in that recommendation's own rules, never the scope noun; population + audience statements stay data (user ruling: exclusions only). In a scoped document should/must/may boxes stay out of rule antecedents, out of negations and out of facts (`deontic_condition`, `negated_deontic`, `root_deontic`).
- Absence conditions (user ruling, CS2b; per-sentence table `.agent/archive/cs-census/rulings-classical.tsv`): a condition that means no record of X — a contraindication, a documented prerequisite step or competence (an exit-strategy discussion), evidence of benefit, another explanation, an `unless` circumstance, a recorded diagnosis — = `does not provably` (fires when the fact is absent, as CQL `not exists`); an observed or assessed finding (`the pain does not improve`, a test result, met diagnostic criteria), a clinical judgment (`a benefit does not outweigh a risk`) and the patient's actual status (opioid-naive, takes a prescribed opioid, receives a treatment) stay classical negation; record each such reading in the projection notes.
- Superseded statements (spec Decisions `Supersession`; contract `.agent/archive/contracts/sup1.md`; REFERENCE § Superseded statements): a statement that later law, regulation or guidance replaced keeps its ACE + clauses; the guideline's table gains `supersession	<docid>	<YYYYMMDD> <https url> <citation>` (whole document only: a partial case → MAIN ruling, contract D13) or, for a passage without a document of its own, `superseded	<region>	…`; the date = the legal or operative effective date, never a publication, proposal or compliance date and never invented; the census + its criterion = `.agent/archive/sup-census/` (`rulings.md`, `check.py`), a new case = a ruling there + its row.
- Duties that share a referent the source names once (`collaborate on a plan and share decisions about it`) → one `it is recommended that the clinician V1s … and V2s the <noun> …` scope: each `should` verb phrase opens its own box, so a definite noun cannot reach an indefinite of a sibling `should` (APE reads it as a new referent), while the wrapper's finite coordination is one box; a binding written as an antecedent fact (`and the patient has a plan`) instead adds a prerequisite the source does not state.
- Prohibitions = SHOULD over a negation (spec Decisions `Prohibitions`): `If … then it is recommended that the clinician does not V …`; a universal → `If there is an X then it is recommended that the X does not V`; never `X should not V` for a prohibition — it compiles to ¬SHOULD (no obligation); a source `avoid <action>` = the same form with a verb for the action (`avoid dismissing patients from care` → `does not dismiss a patient from a care`), never `should avoid <noun>` (an avoid event a consumer must know to read as a prohibition), its qualifier on the negated event — usuality + manner right after `does not` (`does not generally increase`, `does not abruptly discontinue`), a focus word after the object (`… an opioid especially for the patient`, `… a policy particularly`) because `does not particularly V` reads as a weak denial. `It is recommended that every X …` rejects `operator_scoped_rule(should, S)`.
- Generic claims about a role quantify: `Every clinician can often misunderstand …`, never a root `A clinician …` / `A patient …` sentence — a root indefinite asserts one specific clinician or patient, a witness entity that every rule over that role then matches in composition.
- A source example (`e.g.`) → an inert example fact (`A medication-combination-example includes …`), never a root indefinite of the illustrated noun (its witness would match every rule over that noun); each listed item = an example-only noun (`includes a sleep-apnea-example`, `is a benzodiazepine-example`) for the same reason; the example's own qualifiers (`as needed for moderate to severe pain` inside the parenthetical) stay on the example, never on the duty it illustrates. Illustrative means of a duty (`mitigate risk (e.g., by offering naloxone)`, `interventions such as …`) stay inert examples, never duties of their own; members of a required set (`advise about common effects such as constipation`, `include patients in decisions such as …`) may become their own duties, since the set's duty covers each member.
- Derived referents: every indefinite of a rule or universal consequent outside a box becomes a derived actual entity — the subject of a modal sentence included (`then a tricyclic-antidepressant can improve …` = one per matching patient) — and every rule whose condition reads that noun searches it (one `Every recommendation is most-relevant to a clinician` sentence fed 345 documents' clinician rules; such consequents pushed `ckc v1 aggregate-check` past the compile's 300 s cap) ⇒ a consequent introduces only nouns no condition reads: an option claim → `it is possible that a <option> <verb> …` (the option inside the box), a condition noun → folded into the object noun (`shows an at-least-opioid-equal-acute-low-back-pain-effectiveness`), a property → a specific verb (`causes`, `carries`, `shows`) over `has`, a role referent → bound to the antecedent's (`If a patient has a continued-opioid-benefit … then … with the patient`), a preference → its option quantified (`then every nonopioid-therapy is preferred for the subacute-pain`); class derivations meant to fire conditions stay (`then the patient has an acute-pain`). A root fact asserts one entity that every condition over its noun matches ⇒ a generic claim never states a root indefinite of a noun another document's condition reads: a class relation → `If there is a <X> and there is a <Y> … then the X … the Y` (rec01-imp06), a capability → `Every <X> can …` or `It is possible that a <X> …`, a listed member → an example-only noun; the grade sentence, worked examples, formula results, recurrence time quantities, be-edge + class derivations stay (SKO census `.agent/archive/sko-census/census.tsv`: every flagged derivation + its ruling). Gate = `ckc check` (`rust/ckc/src/check/derived.rs`, before the SWI-Prolog stage): every rule-derived or root-asserted actual entity whose noun another document's condition reads needs its row in `guidelines/<id>/audit/derived-entities.tsv` (docid, sentence, noun, class, reason; rows name flagged entities only; meter `ckc: derived-entities ok <id> <n> ruled`) — a new row = a ruled class derivation, never a waiver for a phantom witness; the scratch twin `python3 -I .agent/archive/sko-census/scan.py <pl-dir>` lists the same set. Run it over the drafts' compiled Prolog before `ckc compile` (a copy of `pl/` with the drafts laid over it): a phantom witness can push the compile's aggregate-check past its 300 s cap, which stops the compile before `ckc check` can name the derivation (one universal copula `Every X is a <noun other documents' conditions read>` took it past 3000 s).
- A `vocabulary.tsv` byte change re-pins two fixture families anchored on the CDC table: `tests/certify/cases.tsv` digest mutants (the table sha256 in `vocabulary(sha256(…))`, its corrupted variant one hex digit off) and the `tests/check-mutants/*.expect` pins of mutants that append a row (`at row <rows + 1>`); re-pin both = `python3 -I .agent/archive/migrations/table-repin.py <root> <old-table-sha256> <old-row-count>` (idempotent); commit first, then `cargo test --test check_mutants` + `ckc certify --cases tests/certify/cases.tsv`.
- A change of `pl/cdc2022-opioid-rec02.pl`'s line count or `audit/derived-entities.tsv`'s row count moves the positions that the appended check-mutant plants report (`formula-cycle-*.expect` = rec02 lines from count + 1, `derived-entity-stale.expect` = the appended row) → commit, run `cargo test --test check_mutants` to a log, then `python3 -I .agent/archive/migrations/check-mutant-repin.py <root> <log>`: it re-pins a failure only when its message = the pin with every position shifted by the count's change (anything else = a real finding, refused).
- A committed question's ACE edit re-projects its `queries/pl/<qid>.pl` (variables renumber) → re-anchor the `tests/certify/cases.tsv` mutants that target it, each edit keeping first-occurrence variable order (an order break rejects `noncanonical` before `projection`); then `ckc certify --cases tests/certify/cases.tsv` + `cargo test -p ckc --bin ckc` (the table's anchor test).
- `rights.tsv`: header `profile	statement	url	retrieved	note`; profiles redistributable|reconstructable|restricted; row 1 = operative.
- Committed corpus + query artifacts change only through `ckc compile` / `ckc queries` from their ACE + lexicon inputs, or a ruled re-pin script under `.agent/archive/migrations/`.
