# Scale benchmark law (contract `.agent/contracts/sb.md`)

- `ckc bench gen` writes family compositions + the run manifest; `ckc bench run` times the producer → checker path (cold or `--serve` warm; `--block-spacing-ms` = R pair offsets, `--only-blocks` = a replacement replay over the full plan's per-block draws, run numbers kept); `ckc bench grade` grades one campaign chunk; `ckc bench preflight` grades the host-only preflight; `ckc bench decide` decides the confirmation over its frozen plan + every attempt; `bench/stats.rs` = the one definition of the percentiles, SplitMix64 + the whole-pair bootstrap of R ⇒ a grade's recomputed R equals the harness's `ratio.tsv` on the same pairs; `generate.rs` `identity_frame` = the one composition-identity framing (the generator writes it, the grade recomputes it from a run's `identities.tsv`).
- Campaign chunk on the reference machine = `tools/sb-campaign-unit run`: the `tools/sb-campaign-chunk` call as a system unit run as the campaign user in `sb1.slice` (slice `AllowedCPUs` + unit `CPUAffinity` = 2 3 6 7; the slice's set before its first start, never lifted), the wrapper + its sampler on CPUs 0 1 4 5; waits ≤ 1 h for the sleeper's marker; every `systemd-run` with `--expand-environment=no` (systemd expands `${…}` in a unit's command line by default: pf1's `${EPOCHREALTIME/./}` marks came out empty) + the caller's `PATH` (the system manager's lacks the host's tools); beside it `tools/sb-campaign-unit hold` = the sleeper, launched as a job of another offload project (offload runs one job per project per host). The unit owns the shield: `ExecStartPre` = `shield <state>` (every other top-level slice + scope's configured `AllowedCPUs` → `shield-orig.tsv`, written once, then `AllowedCPUs=0,1,4,5`; a refusal fails the start), `ExecStopPost` = `unshield <state>` (the `final` record, then each recorded value back: empty = the online set, then cleared — an empty assignment alone leaves the cpuset restricted; systemd runs it after a failed start too); `unshield` without a state dir = that restore on every target. `tools/sb-campaign-unit preflight` = the same unit around a placeholder + three synthetic controls (pinned-control in `sb1.slice` on CPU 3, host-control a user unit with three loops on CPUs 0 1 4, each printing its own cgroup's `usage_usec` through `--wait --pipe`) + 600 s quiet.
