# Scale benchmark law (contract `.agent/contracts/sb.md`)

- `ckc bench gen` writes family compositions + the run manifest; `ckc bench run` times the producer → checker path (cold or `--serve` warm; `--block-spacing-ms` = R pair offsets, `--only-blocks` = a replacement replay over the full plan's per-block draws, run numbers kept); `ckc bench grade` grades one campaign chunk; `ckc bench preflight` grades the host-only preflight; `ckc bench decide` decides the confirmation over its frozen plan + every attempt; `bench/stats.rs` = the one definition of the percentiles, SplitMix64 + the whole-pair bootstrap of R ⇒ a grade's recomputed R equals the harness's `ratio.tsv` on the same pairs; `generate.rs` `identity_frame` = the one composition-identity framing (the generator writes it, the grade recomputes it from a run's `identities.tsv`).
- Campaign chunk on the reference machine = `tools/sb-campaign-unit run` (the `tools/sb-campaign-chunk` call as a systemd user unit, `CPUAffinity=2 3 6 7`, the wrapper + its sampler on CPUs 0 1 4 5; waits ≤ 1 h for the sleeper's marker; the shield = every other slice + scope on CPUs 0 1 4 5 until the unit's `ExecStopPost` restores them) beside `tools/sb-campaign-unit hold` = the sleeper, launched as a job of another offload project (offload runs one job per project per host); `tools/sb-campaign-unit preflight` = the same shield + a placeholder unit + three synthetic controls + 600 s quiet; `tools/sb-campaign-unit unshield` = the standalone restore after a lost unit. Restore = `AllowedCPUs=<online set>` then `AllowedCPUs=` (an empty assignment alone leaves the cpuset restricted). State = `<base>/state/<id>/`: `rc`, `chunk.log`, `host-before.txt` + `host-after.txt` (exact X3 keys `Model name:`, `CPU(s):`, `governors:`, `online:`, `slice-cpus:` + `clk_tck:`, `shield:`), `unit-cpus.txt` (the applied `Cpus_allowed_list`), `wrapper-cpus.txt`, `shield.txt`, `host-samples.tsv` (1 s: epoch µs, busy + idle jiffies, the unit's cgroup CPU µs + swap bytes, `pswpin`/`pswpout`, throttle counts, hottest zone, `pinned_busy_jiffies` of CPUs 2 3 6 7), `preflight.tsv` (the preflight's window marks).
- `ckc bench grade <run-dir> <state-dir> <frozen-root> <run-manifest>` = contract sb § Carried rulings X1–X4 as operationalized there: a block's interval = its first request → its last closed sink; X1 = foreign CPUs on CPUs 2 3 6 7 > 0.5 over the last sample ≤ start (none: the first) → the first ≥ end (none: the last), host-wide foreign = the block row's last column; a sampler without `pinned_busy_jiffies` = X1 `unassessed` (`X1-unpinned`); X2 = unit swap > 0 inside (unreadable throughout = `unassessed`); X3 (chunk-wide) = any X3 key or the kernel changed (an incomplete record = `unassessed`); X4 = a spacing overlapping the block or an open edge > 5 s, or a window without two distinct sample times; no sampler file = `unassessed` (p01). Memory per call: `runs.tsv` `memory_bound_bytes` (Σ HWM of the non-producer processes + the producer's wait4 peak) > 32 GB = `uncertain`; a verified run without it falls back to the HWM sum, counted in `memory_unbounded`. rc 1 = an identity mismatch, a wrong output digest or a call whose (instance, query) the manifest gives no expected output (`sha_unchecked`: a missing row proves nothing); a call short of verified printed no output (digest `NA`: a budget fail, never a wrong output); budget fails + rejected blocks are graded results (rc 0). `assess` = the grade as data, the one implementation `decide` reads.
- `ckc bench decide <plan.tsv> <base> <frozen-root> <run-manifest> [--receipts <dir> --census <sha256> --host <label> --overhead-ms <n>]` (the four receipt flags together, in that order) = contract sb § Carried rulings Decision tool: plan columns `chunk instance blocks seed pair ratio ckc checker` (`pair` `-` = a three-query chunk; `ratio` `gate` | `report` on an R chunk, `-` otherwise, exactly one `gate`); attempts = `<base>/runs/<id>` + `<base>/state/<id>`, `<id>-r` = the one replacement, any other runs/ directory holds; soundness per attempt = harness rc 0 | 1, identity, `sha_bad`, `sha_unchecked`, `memory_unbounded`, the settings keys `seed`, `blocks`, `queries`, `spacing_ns`, `only_blocks` (written by `ckc bench run`), `host.tsv` `harness_sha256` = `ckc`, the identity digest of the serve command's first word = `checker`, the plan draws (a replacement = the original's rows for its blocks, each one the original left invalid); validity = grade `accepted` on a pinned unit; selection = the first valid attempt per block; selected calls verified, ≤ 300 s, peak + bound ≤ 32 GB; R over the gate chunk's selected pairs, UB95 ≤ 2; receipt join = `<dir>/<kb_identity>.tsv` per measured identity (64 hex), direct (`basis` absent), admitted, census + host as named, full load = `load_ns` + parse + analysis + overhead ≤ 1,800 s, charged = `vmhwm_bytes` + `rss_at_ready_bytes` ≤ 32 GB; no receipt flags = a pending join (hold).
