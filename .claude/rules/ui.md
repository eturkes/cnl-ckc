# Reviewer-UI law

Contracts of record: `.scratch/contracts/m4u3.md`, `m4u4.md` (v1.2), `m4u13.md` (v1..v4). Live law also = docs/REFERENCE.md § Reviewer interface + `.claude/rules/clinician-design.md`.

Ledger-validate subprocess pins `cwd=<repo root>` (goal.py module-level require is cwd-bound; goal.py = module-level dispatch, never import). Census regex parity goal.py↔ui.py: `identify the ([0-9]+) payloads below`.
- Committed-corpus law: the reviewer surface reads HEAD, never the working tree. `resolve_corpus` = dirt probe (`git diff --name-only -z HEAD -- guidelines` ∪ untracked, minus `*/audit/adjudication.tsv` — server-written, never dirt) → filesystem mode when git unusable ∨ root ≠ toplevel ∨ dirt empty ∨ archive fails; else `git archive HEAD guidelines` → temp tree (absolute/`..`/non-regular members reject), live ledgers overlaid, released per command. Model carries `path` = corpus (reads/assets/derive) + `real_path` = working tree (ledger CAS + write, `ace_commit_hex`) + `committed_corpus` flag. `check` alone pins the working tree (pre-commit gate must see the round). The law is INVISIBLE by user ruling — no copy names it; committed carriers = `tests/ui/green/git-{uncommitted-edit,untracked-document}` (a `worktree/` sidecar beside `tree/` triggers `ui_materialize_tree`: commit `tree/` as HEAD, lay `worktree/` on top uncommitted; `ui_git_env` pins identity/dates/config so fixture hashes are functions of fixture bytes); residue carrier = `.scratch/m4u13-committed-corpus.py` 9/9.
- Bundle v2: `review_sha256` = sha256 of `bundle v2 <docid>` + ace + coverage + payload + clauses (6-field manifest; projection-notes artifact stays under `check_projection_ledger`, no page reads it). Digest-drop lesson: when a digest component is dropped, census every fixture that depends on the digest DIFFERING, not just on its value (four POST reds silently flipped 409→303). Migration replay = `python3 -P .scratch/m4u13-bundle-v2.py`.
- Copy law = two gates: L1 `check_copy_register` (stdlib `ast` literal walk over generated ui.py; five registers; scan-target marker `def page_invariant_name(`) + L2 `page_invariant_name` (per page: scope-line singleton → copy-sha256 → copy-bundle-differs → copy-hex, hex reds only containing a digit). `check_copy_chain_slot` AST-pins `check_copy_register()` directly after `check_ui()` in check_command. Visible text = strip `<style>`/`<pre>`/`<script>`/comments, drop tags, SPACE-join, `html.unescape`; attributes exempt. `selftest_violation` runs BEFORE rendering (L2 mutants die with zero fixture churn). JS/CSS string literals ride the copy register → avoid banned css tokens + alnum-then-`!` (spell ` !== ` spaced, `=== false` over `!x`); palette selftest counts EVERY `#` in css_text against palette hexes → selectors stay id-free.
- Highlight: artifact `guidelines/<gid>/align/<docid>.tsv` rows `group	side(src|ace)	start	span` (canonical decimals; start = 0-based char offset into ui payload_line (src) / raw ace_text (ace); code points ≠ UTF-8 bytes). `hl_parse_align` validation order + err strings = selftest pins; missing file → plain render, no legend; invalid → viewmodel err ⇒ check_ui corpus render = the structural gate; COMMITTED-CORPUS law applies (write → commit → visual QA). Display: dense t0.. by first ace offset, hue = index mod 12, hover = `main:has(mark.tN:hover)`, click emphasis via the UI's SOLE script (`build_hl_script`, byte-pinned; CSP = `script-src 'sha256-<b64 of exact element body incl. wrapping \n>'`; page invariant: count(`<script`)==count(hl_script_html)≤1). `hl_slice` = `text.__getitem__(slice(a,b))` (E-- lacks slice syntax). Print block resets fade colors after screen rules; `@media print` hides nav/skip/form/`.verdict-entry` and forces disclosure open via `details::details-content { content-visibility: visible }` (Chromium 131+; older `details > *:not(summary)` form does NOT work).
