# Reviewer-UI law

Live law = docs/REFERENCE.md § Reviewer interface + `.claude/rules/clinician-design.md` + the K5 spec `rust/ckc-spec/src/ui.rs` (render fidelity, escaping, copy registry, POST guard chain + ledger CAS; theorems in `ckc-kernel` `k5_*`). Contracts of record: `.agent/archive/contracts/m5u5*.md` (R84 guard order).

- `ckc ui serve|render|check|request|copy-check` (`rust/ckc/src/ui/`): std `TcpListener` on 127.0.0.1 only, per-process 64-hex token; every page byte comes from the kernel renderer; `check` = double-render byte compare + page invariants + dangling-href closure; `request` = one in-process request (fixture + oracle seam).
- Committed-corpus law: the reviewer surface reads HEAD, never the working tree (`corpus.rs`): dirt probe (`git diff --name-only -z HEAD -- guidelines` ∪ untracked, minus `*/audit/adjudication.tsv` — server-written, never dirt) → filesystem mode when git is unusable ∨ root ≠ toplevel ∨ dirt empty; else `git archive HEAD guidelines` → temp tree, live ledgers overlaid. Ledger CAS + write target the working tree. `ckc check` alone reads the working tree (pre-commit gate). The law stays invisible in copy (user ruling); fixture carriers = `tests/ui/green/git-{uncommitted-edit,untracked-document}` (`worktree/` beside `tree/`: `ui_fixtures.rs` commits `tree/` as HEAD with fixed identities + dates, lays `worktree/` on top uncommitted ⇒ fixture commit ids are functions of fixture bytes).
- Ledger write: candidate `.adjudication.tsv.<nonce>` (mode 0600 → fsync → 0644) → `LedgerLock` on `.adjudication.lock` counts only once the path still names the locked inode (holders unlink before unlock) → digest CAS under the lock → rename. Regression = `rust/ckc/tests/ui_lock.rs`; socket end to end = `ui_socket.rs`.
- Bundle v2: `review_sha256` = sha256 of `bundle v2 <docid>` + ace + coverage + payload + clauses (6-field manifest; projection-notes stays under the check's projection ledger, no page reads it). Digest-drop lesson: when a digest component is dropped, census every fixture that depends on the digest DIFFERING, not just on its value (four POST reds once flipped 409→303).
- Copy law: every string the interface can emit lives in the kernel copy registry (K5 `copy_ok` theorem over all registry literals); `copy_table!` in ui.rs = the single definition of each fixed string (a named spec fn) + the registry order, so the renderer and the registry share one spelling; the k5-sound generators parse that table; `ckc ui copy-check <file>` scans a source against the clinician copy register (fixtures `tests/copy/`). Visible text = strip `<style>`/`<pre>`/`<script>`/comments, drop tags, SPACE-join, unescape; attributes exempt. JS/CSS string literals ride the register → avoid banned css tokens + alnum-then-`!` (spell ` !== ` spaced, `=== false` over `!x`); the palette check counts EVERY `#` in the stylesheet against palette hexes → selectors stay id-free.
- Highlight: artifact `guidelines/<gid>/align/<docid>.tsv` rows `group	side(src|ace)	start	span` (canonical decimals; start = 0-based code-point offset into the payload line (src) / raw ACE text (ace)). Validation = K1 align spec (`ckc align-check`); missing file → plain render, no legend; invalid → render refusal. Display: dense t0.. by first ace offset, hue = index mod 12, hover = `main:has(mark.tN:hover)`, click emphasis via the UI's SOLE script (byte-pinned; CSP = `script-src 'sha256-<b64 of exact element body incl. wrapping \n>'`; page invariant: count(`<script`) ≤ 1). Print block resets fade colors after screen rules; `@media print` hides nav/skip/form/`.verdict-entry` and forces disclosure open via `details::details-content { content-visibility: visible }` (Chromium 131+).
- Fixture harness = `rust/ckc/tests/ui_fixtures.rs` over `tests/ui/{red,green}/` (84 red + 15 green) + `tests/copy/` (10 red + 2 green) + 2 design cases: four-column `case.tsv` argv/rc/stderr/stdout with `@TREE@`/`@OUT@`, `-` = empty, serve forbidden; `tree-order.txt`/`empty-dirs.txt` sidecars; golden tree byte compare; `assertions.tsv` contains/absent hex rows. `CKC_UI_TEST_BIN` replays a prebuilt binary.
- AM6 hazard: regenerating goldens from the current binary rewrites case-authored pins to current bytes → a contract-divergent binary regenerates itself green. After any golden regen, diff the churn against the contract before crediting green.
