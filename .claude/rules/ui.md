# Reviewer-UI law

Live law = docs/REFERENCE.md § Reviewer interface + `.claude/rules/clinician-design.md` + the K5 spec `rust/ckc-spec/src/ui.rs` (render fidelity, escaping, copy registry, POST guard chain + ledger CAS; theorems in `ckc-kernel` `k5_*`). Contracts of record: `.agent/archive/contracts/m5u5*.md` (R84 guard order).

- `ckc ui serve|render|check|request|copy-check` (`rust/ckc/src/ui/`): std `TcpListener` on 127.0.0.1 only, per-process 64-hex token; every page byte comes from the kernel renderer; `check` = double-render byte compare + page invariants + dangling-href closure; `request` = one in-process request (fixture + oracle seam).
- Committed-corpus law: the reviewer surface reads HEAD, never the working tree (`corpus.rs`): `git archive HEAD guidelines` → temp tree, live ledgers overlaid; filesystem mode only when git is unusable ∨ root ≠ toplevel. Ledger CAS + write target the working tree. `ckc check` alone reads the working tree (pre-commit gate). The law stays invisible in copy (user ruling); fixture carriers = `tests/ui/green/git-{uncommitted-edit,untracked-document}` (`worktree/` beside `tree/`: `ui_fixtures.rs` commits `tree/` as HEAD with fixed identities + dates, lays `worktree/` on top uncommitted ⇒ fixture commit ids are functions of fixture bytes).
- Rendered commit (review custody): document pages carry hidden `commit` = the snapshot commit (git HEAD | `ui request --commit` | empty in filesystem mode); POST: the kernel parses `commit` (empty | 40 lowercase hex) and the shell reads it only through `ui_posted_commit`; the shell attests `at_commit` = (posted commit, bundle v2 review digest of the docid there) after `cat-file -e <c>^{commit}` + `merge-base --is-ancestor <c> <snapshot>` + an archive-at-commit derivation (posted = snapshot → the HEAD derivation); kernel guard = (snapshot empty ∧ posted empty) ∨ attestation == (posted commit, posted digest), else 409; the row records the posted commit. Probes = `rust/ckc/tests/ui_commit.rs` (16 contract cases); fixture bodies + document goldens carry the field per `.agent/archive/migrations/n2-commit-field.py`.
- Ledger write: candidate `.adjudication.tsv.<nonce>` (mode 0600 → fsync → 0644) → `LedgerLock` on `.adjudication.lock` counts only once the path still names the locked inode (holders unlink before unlock) → digest CAS under the lock → rename. Regression = `rust/ckc/tests/ui_lock.rs`; socket end to end = `ui_socket.rs`.
- Bundle v2: `review_sha256` = sha256 of `bundle v2 <docid>` + ace + coverage + payload + clauses (6-field manifest; projection-notes stays under the check's projection ledger, no page reads it). Digest-drop lesson: when a digest component is dropped, census every fixture that depends on the digest DIFFERING, not just on its value (four POST reds once flipped 409→303).
- Copy law: every fixed string the interface can emit lives in the kernel copy registry (text slots copy corpus spans or canonical decimals) (K5 `copy_ok` theorem over all registry literals); `copy_table!` in ui.rs = the single definition of each fixed string (a named spec fn) + the registry order, so the renderer and the registry share one spelling; the k5-sound generators parse that table (they assert its size) and the generated proofs + `b::f(i)`/`l::fNNN` address entries by index ⇒ a new row appends at the table end; `ckc ui copy-check <file>` scans a source against the clinician copy register (fixtures `tests/copy/`). Visible text = strip `<style>`/`<pre>`/`<script>`/comments, drop tags, SPACE-join, unescape; attributes exempt. JS/CSS string literals ride the register → avoid banned css tokens + alnum-then-`!` (spell ` !== ` spaced, `=== false` over `!x`); the palette check counts EVERY `#` in the stylesheet against palette hexes → selectors stay id-free.
- Highlight: artifact `guidelines/<gid>/align/<docid>.tsv` rows `group	side(src|ace)	start	span` (canonical decimals; start = 0-based code-point offset into the payload line (src) / raw ACE text (ace)). Validation = K1 align spec (`ckc align-check`); missing file → plain render, no legend; invalid → render refusal. Display: dense t0.. by first ace offset, hue = index mod 12, hover = `main:has(mark.tN:hover)`, click emphasis via the UI's SOLE script (byte-pinned; CSP = `script-src 'sha256-<b64 of exact element body incl. wrapping \n>'`; page invariant: count(`<script`) ≤ 1). Print block resets fade colors after screen rules; `@media print` hides nav/skip/form/`.verdict-entry` and forces disclosure open via `details::details-content { content-visibility: visible }` (Chromium 131+).
- Timing table (m7t D10): `u::timing_section` (K5 `k5_timing` exec, `k5_sound_timing` soundness) renders after the ACE section of a page whose pl parses as v2|v3 with ≥1 annotation literal; every other page stays byte-identical. v3 rows (q12 D11): order = `before|after` + anchor noun; frequency = `<cmp>N per <count><unit>, counted item: <noun>`, no reference point; scoped recurrence = `repeats <cmp>N<unit> apart during <cmp>M<unit> from` + anchor noun; `guideline_range` renders no row of its own: it enriches its low end's interval row to `a minimum of N to M <unit>` (q13 D8); comparison `about` renders `about `. `u::timing_rows` is `#[verifier::opaque]`: unhidden it pulls the whole v1 grammar into every page query (SMT function axioms 516 → 615) and the page proofs exceed rlimit; `k5_sound_document::page` splits into `head_sound` + `tail_sound` for the same reason. Unit words = named copy entries (`unit_html`) so the generators emit their `l::fNNN` lemmas. Fixture `tests/ui/green/timing` (all five roles, three parts, six comparisons, anchor `none`, a hostile-join row).
- Time words (q14): `u::words_section` (K5 `k5_words` exec, `k5_sound_words` soundness) renders after the Status section of a guideline page whose `temporal.tsv` parses; `EGuideline.temporal` = the raw table bytes, a `corpus_bytes` input ⇒ lemmas render through `pl_word` over the table bytes. Rows = units, relations, spacings, windows, frequencies, approximations, ranges, each kind in file order (a v3 table's before/after rows explain both the timed + the unquantified reading; v2 bytes unchanged); `u::word_rows` `#[verifier::opaque]`; `k5_sound_guideline::page` splits into `head_sound` + `tail_sound` (one query over all parts exceeds rlimit). Intake refuses a table that fails `check_temporal`: `ui: viewmodel: <gid> temporal.tsv: <why>`. Fixtures `tests/ui/green/temporal-words`, `tests/ui/red/temporal-invalid`; contract `.agent/archive/contracts/q14.md`.
- Fixture harness = `rust/ckc/tests/ui_fixtures.rs` over `tests/ui/{red,green}/` (85 red + 21 green) + `tests/copy/` (10 red + 2 green) + 2 design cases: four-column `case.tsv` argv/rc/stderr/stdout with `@TREE@`/`@OUT@`, `-` = empty, serve forbidden; `tree-order.txt`/`empty-dirs.txt` sidecars; golden tree byte compare; `assertions.tsv` contains/absent hex rows. `CKC_UI_TEST_BIN` replays a prebuilt binary.
