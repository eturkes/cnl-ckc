# ace_to_pl compiler law

- One schema, identifier 1 (contract `.agent/archive/contracts/c1.md`; law = `docs/REFERENCE.md` § Compiled Prolog schema): every document declares all 15 indicators, record `guideline_document(D, ace_sha256(H), ulex(none|sha256(U)), vocabulary(none|sha256(T)))`, question record `'$guideline_query'(v1, Q, ace_sha256(H), ulex(…), vocabulary(…))`. Argv (after `--`) = `<ape-tree> <docid> <vocabulary.tsv|-> <ulex|-> [proof]` | `question <ape-tree> <qid> <vocabulary.tsv|-> <ulex|->`; `-` = no file; `proof` in a file slot → `usage, vocabulary_arg(proof)` | `ulex_arg(proof)`; a leading `v1|v2|v3` (after `question` too) + every other vector → `usage, argv(Argv)`, all before any file loads; nothing inferred from document content. An unloadable table = class `vocabulary_load` rc 2 (`error(vocabulary(Why), context(…read_vocabulary/2…))`), never a fallback. With a table, every pattern runs (m7t interval + recurrence; q12 order, frequency, scoped recurrence; q13 approximation (`about`) + range), gated only by the table's rows; the `v2_`/`v3_` predicate prefixes name those contracts' pattern families. Annotation pass = after the matched `guideline_pp`, primitives byte-identical except the `about` rewrite of an approximate claimed quantity's `eq` cardinality (q13 D3); patterns classify a referent by its `object/6` anywhere in the document DRS (`v3_set_decls` → `b_setval`, `==` lookup; q12 D3). Table presence alone gates the question law: with a table, upper-bound condition lists flatten + `relation/3` leaves pass; without, both reject. Certification (`m6_*` + `m7_annotate` + `m7_q12`) re-derives annotations from the raw table bytes + checks the record's vocabulary digest.
- Editing gotchas: read DRS via `arg/3` + `==` exclusively (unification silently instantiates canonical vars); event-referent erasure counts CONDITION positions only (`drs/2` domain arg = binder, skipped while counting); `numbervars` only after validating no pre-existing `'$VAR'/1`, acyclicity, no attvars; digests = `crypto_data_hash/3` over raw pre-decode bytes incl. final LF with `encoding(octet)`. SWI stream `encoding(utf8)` ≠ strict octet validation → the compiler reads bytes + explicit RFC-3629 boundary/overlong/surrogate/max-code-point checks; preserve on edits.
- Modes = compile, proof, question; the composition modes (check, aggregate-check, recursion-check, answer, trace) run as `ckc v1 <mode>` in the verified kernel (the fork code lives at tag `legacy`). Reserved-name mechanics: the ulex-wide reserved scan reads lemma/data slots only (every ulex category writes the surface form in argument 1, which never reaches the product) → both collision scans report ONE canonical detail per offending entry (collision ruling: lemma, not surface). Lexicon liveness is per LEXEME, never per surface form (the corpus holds infpl-only and finsg-only lexemes; a per-surface rule rejects the corpus it protects). Aggregate coverage (`ckc v1 aggregate-check`) derives from the LOADED composition's own sentence identities (`'$guideline_id'(_,DocId,S,_,_)` subterms), never from the payload stream — payloads are evidence, not authority. Per-sentence VARIANT counts are NOT so derivable: rule-head `Deps` are variables in the product, so a dropped LAST variant keeps coverage complete + numbering contiguous (open residue; detection needs a schema change).
- Bounded replay (per-doc P7 in the fork; aggregate P9 in the kernel with the same bounds): `v1_bounded_head_call` = `call_with_depth_limit` 4000 inside `call_with_inference_limit` 10^6; witness facts `asserta`'d so they precede rule clauses; either bound exceeded = ordinary underivability (DR06 family). Composition-scale hazard: classical-negation antecedents render `guideline_operator(actual,C,-)` body goals with free C that resolve against sibling `-` rule heads before the witness fact → exponential backtracking; 2 docs suffice; regression = suite AG10. Verdicts unaffected — clause order + bounds shape search only.
- DRS facts: negation by arity+spelling — `-/1` classical, `~/1` NAF, `-/2` = sentence/token anchor wrapper only. Noun copula needs the indefinite article (`X is a noun.`). Unknown content words without ulex → `ape_messages`.
- tests/red: every probe pins class + rc + byte-exact stderr through its required `.expect` sidecar; `ckc check` replays them (red section). Probe argv (`check/red.rs` `tail`) = `[question] <stage> red-probe <stem.vocabulary.tsv|-> <stem.ulex|->` from the optional sidecars (`<class>--query-…` = question mode); a `<probe>.argv` sidecar names the whole argv after `--` (one line, space-separated; `@TREE@` `@ID@` `@TABLE@` `@ULEX@` = the stage, the id, the sidecar paths) so every D5 vector is pinnable. tests/green: same sidecars, docid = the stem, `.expect` = exact stdout, rc 0, empty stderr, kernel reader accepts; an optional `.proof.expect` = the proof payload of the same argv + `proof`; `ckc check` replays them after the red section (meter `… N red probes M green probes (P proof)`); goldens certified at authoring (`ckc certify` over a scratch root holding `vendor` + `rust/ckc/prolog` symlinks + `guidelines/<g>/{ace,pl,queries,vocabulary.tsv,lexicon.ulex}`). Regenerate pins = `.agent/archive/generators/probe-pins <repo-root>` (full-Clex stage, the red.rs argv; writes every red + green pin, `--check` = compare only).
