# ace_to_pl compiler law

- One schema, identifier 1 (contract `.agent/archive/contracts/c1.md`; law = `docs/REFERENCE.md` § Compiled Prolog schema): every document declares all 20 indicators (s1 D1: + `guideline_grade/5`, `guideline_preference/4`; s2 D1: + `guideline_qualifier/4`; nt1 D2: + `guideline_unit/3`; cs1 D2: + `guideline_exclusion/1`), record `guideline_document(D, ace_sha256(H), ulex(none|sha256(U)), vocabulary(none|sha256(T)))`, question record `'$guideline_query'(v1, Q, ace_sha256(H), ulex(…), vocabulary(…))`. Argv (after `--`) = `<ape-tree> <docid> <vocabulary.tsv|-> <ulex|-> [proof]` | `question <ape-tree> <qid> <vocabulary.tsv|-> <ulex|->`; `-` = no file; `proof` in a file slot → `usage, vocabulary_arg(proof)` | `ulex_arg(proof)`; a leading `v1|v2|v3` (after `question` too) + every other vector → `usage, argv(Argv)`, all before any file loads; nothing inferred from document content. An unloadable table = class `vocabulary_load` rc 2 (`error(vocabulary(Why), context(…read_vocabulary/2…))`), never a fallback. With a table, every pattern runs (m7t interval + recurrence; q12 order, frequency, scoped recurrence; q13 approximation (`about`) + range), gated only by the table's rows; the `v2_`/`v3_` predicate prefixes name those contracts' pattern families; in documents, then the strength pass (`s1_` prefix: grade after a root-fact copula, preference after its alternative pp or copula; contract `.agent/archive/contracts/s1.md` D3/D4; `s2_` prefix: a mapped adverb → qualifier in place, a property-only copula's qualifier adjectives after its arg-2 clause, rejects `qualifier_shape(degree|asserted, S)`; contract `.agent/archive/contracts/s2.md` D3). The approximation marker (q13) + the preference adjective (s1) = one lookup, a same-context `property(X, A, pos)` with A in the kind's table list: compiler `pos_property/4` (cut after every guard; `v3_approximate/4` + `s1_preferred_prop/4` delegate), spec `pos_property` (`approximate` + `preferred_prop` wrap it), kernel `pos_property_exec`. Annotation pass = after the matched `guideline_pp` (s1: after the copula or the alternative pp), primitives byte-identical except the `about` rewrite of an approximate claimed quantity's `eq` cardinality (q13 D3); an s1 or s2 literal in a rule antecedent = one added body goal per clause; patterns classify a referent by its `object/6` anywhere in the document DRS (`v3_set_decls` → `b_setval`, `==` lookup; q12 D3). - Editing gotchas: read DRS via `arg/3` + `==` exclusively (unification silently instantiates canonical vars); event-referent erasure counts CONDITION positions only (`drs/2` domain arg = binder, skipped while counting); `numbervars` only after validating no pre-existing `'$VAR'/1`, acyclicity, no attvars; digests = `crypto_data_hash/3` over raw pre-decode bytes incl. final LF with `encoding(octet)`. SWI stream `encoding(utf8)` ≠ strict octet validation → the compiler reads bytes + explicit RFC-3629 boundary/overlong/surrogate/max-code-point checks; preserve on edits.
- Modes = compile, proof, question; the composition modes (check, aggregate-check, recursion-check, answer, trace) run as `ckc v1 <mode>` in the verified kernel (the fork code lives at tag `legacy`). Reserved-name mechanics: the ulex-wide reserved scan reads lemma/data slots only (every ulex category writes the surface form in argument 1, which never reaches the product) → both collision scans report ONE canonical detail per offending entry (collision ruling: lemma, not surface). Lexicon liveness is per LEXEME, never per surface form (the corpus holds infpl-only and finsg-only lexemes; a per-surface rule rejects the corpus it protects). Aggregate coverage (`ckc v1 aggregate-check`) derives from the LOADED composition's own sentence identities (`'$guideline_id'(_,DocId,S,_,_)` subterms), never from the payload stream — payloads are evidence, not authority. Per-sentence VARIANT counts are NOT so derivable: rule-head `Deps` are variables in the product, so a dropped LAST variant keeps coverage complete + numbering contiguous (open residue; detection needs a schema change).
- Bounded replay (per-doc P7 in the fork; aggregate P9 in the kernel with the same bounds): `v1_bounded_head_call` = `call_with_depth_limit` 4000 inside `call_with_inference_limit` 10^6; witness facts `asserta`'d so they precede rule clauses; either bound exceeded = ordinary underivability (DR06 family). Search-order hazard: classical-negation antecedents render `guideline_operator(actual,C,-)` body goals with C free, ahead of the content goals that bind C; leftmost search proves every negated-box head first (exponential once root witness facts let those rules fire). The kernel engine (answers, traces, P9) defers such a goal until its content binds C (contract `eso`; regression = tests/v1 `eso-*` + `eso_acceptance`); the fork's per-document P7 replay + any standard Prolog consumer keep leftmost order, so a document whose own rules make that search exponential can still exhaust P7's bound.
- DRS facts: negation by arity+spelling — `-/1` classical, `~/1` NAF, `-/2` = sentence/token anchor wrapper only. Noun copula needs the indefinite article (`X is a noun.`). Unknown content words without ulex → `ape_messages`.
- Root exact groups (contract `.agent/archive/contracts/root-exact.md`): APE wraps an upper-bounded quantifier's scope (`exactly`, `at most`, `less than`) in a condition list, everywhere; rules + boxes flatten it in their context. A root list is admitted (fork `v1_exact_group` → `boxed(List)`; spec `exact_group` → `Root::Boxed`; kernel `m6_drs::exact_group`) iff every upper-bounded `object/6` among its root-context leaves (anchored conditions through list spines alone, never into a box, NAF, rule or disjunction) is `exactly N`, N ≥ 1, and one is; `at most` / `less than` / `exactly 0` admit zero ⇒ `root_condition` (red probe `unsupported--v1-root-at-most`; nt1-surface `root-leq` / `root-less`). The wrapper adds no edge, ordinal or built-in; downstream rejects (disjunction, asserted attenuating adverb, approximate exact bound) keep firing.
