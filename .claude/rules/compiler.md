# ace_to_pl compiler law

- v1 = the compiler's sole schema; invocation `<ape-tree> <docid> [ulex] [proof]`, nothing inferred from document content. A future schema = version bump + a new explicit selector. `proof` = reserved argv token: a bare third token `proof` selects proof mode (a ulex literally named `proof` is unaddressable); explicit `<tree> <docid> proof proof` rejects `usage,ulex_arg(proof)` rc=2.
- Editing gotchas: read DRS via `arg/3` + `==` exclusively (unification silently instantiates canonical vars); event-referent erasure counts CONDITION positions only (`drs/2` domain arg = binder, skipped while counting); `numbervars` only after validating no pre-existing `'$VAR'/1`, acyclicity, no attvars; digests = `crypto_data_hash/3` over raw pre-decode bytes incl. final LF with `encoding(octet)`. SWI stream `encoding(utf8)` ≠ strict octet validation → the compiler reads bytes + explicit RFC-3629 boundary/overlong/surrogate/max-code-point checks; preserve on edits.
- v1 freeze mechanics: the aggregate replay asserts witnesses into `user`, so `aggregate_declare_indicators` dynamic-declares every ABI predicate BEFORE the composition loads — loading first makes them static and the assert dies `permission_error(modify,static_procedure)`. The ulex-wide reserved scan reads lemma/data slots only (every ulex category writes the surface form in argument 1, which never reaches the product) → both collision scans report ONE canonical detail per offending entry (collision ruling: lemma, not surface). Lexicon liveness is per LEXEME, never per surface form (the corpus holds infpl-only and finsg-only lexemes; a per-surface rule rejects the corpus it protects). Aggregate coverage derives from the LOADED composition's own sentence identities (`'$guideline_id'(_,DocId,S,_,_)` subterms), never from the payload stream — payloads are evidence, not authority. Per-sentence VARIANT counts are NOT so derivable: rule-head `Deps` are variables in the product, so a dropped LAST variant keeps coverage complete + numbering contiguous (open residue; detection needs a schema change).
- Bounded replay (per-doc P7 + aggregate P9): `v1_bounded_head_call` = `call_with_depth_limit` 4000 inside `call_with_inference_limit` 10^6; witness facts `asserta`'d so they precede rule clauses; either bound exceeded = ordinary underivability (DR06 family). Composition-scale hazard: classical-negation antecedents render `guideline_operator(actual,C,-)` body goals with free C that resolve against sibling `-` rule heads before the witness fact → exponential backtracking; 2 docs suffice; regression = suite AG10. Verdicts unaffected — clause order + bounds shape search only.
- DRS facts: negation by arity+spelling — `-/1` classical, `~/1` NAF, `-/2` = sentence/token anchor wrapper only. Noun copula needs the indefinite article (`X is a noun.`). Unknown content words without ulex → `ape_messages`.
- tests/red: every probe pins class + rc + byte-exact stderr through its required `.expect` sidecar; regenerate with `python3 -P .scratch/m3rev/gen_expect.py --write` — pins come from the goal-shaped overlaid stage `.scratch/polish-redstage/ape-stage` (full Clex; restage recipe in the gen_expect docstring; its guard refuses a demo-lexicon stage). The `.scratch/m3scout/ape-stage` keeps the demo lexicon as M3 gate evidence — never overlay it.
- Scratch probe entrypoints: `-g main` is argv-special in SWI → use another name (`-g probe_main -t 'halt(9)'`).
