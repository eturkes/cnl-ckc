# Deferral queue

Off-path improvements + ruled deferrals, one row each: `- <what> (<source>). Accept: <check>`. A row enters while its evidence is fresh and leaves in the commit that meets its check; a skipped, xfailed, deleted or tier-demoted case enters here with user approval (`CLAUDE.md` `Engineering`). Unfinished units stay in `.agent/spec.md` `Deferred`.

- Kani engine + trace harnesses (`rust/ckc-kani-harness` `engine_answer_tiny`, `reader_trace_check_small`; outside the `just kani` recipe): `v1_answer`/`v1_trace_check` replay the K1 loader symbolically → CBMC exhausts (engine: 5 runs rc124 at 1200 s / ~12 GiB; trace: no verdict at 60 min / 12.6 GiB, m5u2b R82). Accept: typed below-parser kernel seam + one engine harness and one trace harness green in `just kani`.
- `ace_commit` custody content check (`m5u3` R48; `map-k4` Q4/R3): a current-digest ledger row with a nonempty `ace_commit` proves commit existence only; adjudication fixtures run `ledger-validate` with ODB checking off. Accept: for each current-digest row with nonempty `ace_commit`, `ckc check` re-derives review bundle v2 at that commit and requires its `review_sha256` = the ledger digest; red fixtures = missing commit + bundle mismatch, with ODB checks on.
- Scratch validators (`.scratch/m5u*/`, `.scratch/m6/`; invocations in `.claude/rules/rust.md` + the unit contracts) = temporary encodings with no committed copy; regeneration = re-author from each unit contract's gate identities. Accept: committed Rust harness ≤ M5.7.
- `goal align` fail-path probes (legacy `goal.py`, retires at M5.7): the resolver's `fail("align",…)` branches (bad int, unknown side, occurrence miss, overlap, one-sided) have no fixture coverage; render-side twins = `tests/ui/red/align-*`. Accept: one probe per branch → rc 2 + stderr detail, wired as a red battery or `goal.emm` selftest rows.
- Non-v1 tests/queries fixtures (R15 census 10/35; m5u3 R79: `empty-solutions`, `no-finite-failure`, `limit-depth`, `limit-inner-inference`, `yesno-limit-before-proof`, …) load only through the retiring Prolog fork; `ckc check` classifies them `noncanonical`. Accept: each rewritten as a canonical v1 document exercising the same engine-limit law (or retired with a named M5.2 suite row covering it); `queries_replay.py --census` reports `noncanonical-documents=0/35`.

- Reviewer-UI ledger lock lifecycle (inherited from `tools/ui.py`, reproduced in `ckc ui`; rev-m5u5-1 U5-02): `LedgerLock` unlinks `.adjudication.lock` before unlocking → a waiter on the stale inode + a newcomer on a fresh lock file both hold the lock → concurrent POSTs both pass CAS → first accepted row lost (two 303s). Accept: `python3 -P .scratch/agents/rev-m5u5-1/cas-overlap.py` (scratch repro; regenerate = two POSTs racing across the lock handoff window, `cas-overlap-contract.log`) rc 0 on native + a committed `tests/ui` red fixture or `ui_fixtures.rs` case pinning one 303 + one 409.
