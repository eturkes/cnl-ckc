# Deferral queue

Off-path improvements + ruled deferrals, one row each: `- <what> (<source>). Accept: <check>`. A row enters while its evidence is fresh and leaves in the commit that meets its check; a skipped, xfailed, deleted or tier-demoted case enters here with user approval (`CLAUDE.md` `Engineering`). Unfinished units stay in `.agent/spec.md` `Tasks`.

- Kani engine + trace harnesses (`rust/ckc-kani-harness` `engine_answer_tiny`, `reader_trace_check_small`; outside the `just kani` recipe) — waits on its re-open trigger (user ruling). During symex, values read back from the kernel's term arena (var key, node tag, `maximum`) stay symbolic on concrete input: a loop counted by one unwinds to the bound 7, while `Vec<usize>` + `Vec<Option<usize>>` controls unwind exactly; padded structs and enums with padding in heap `Vec`s lose precision the same way, padding-free structs and tuples fold. Inference (not measured): that representation-level loss is the main obstruction, so the engine path needs padding-free or typed storage under `cfg(kani)`, contracts that avoid the reads, or another checker. Re-open trigger: a `rust/kani.lock` bump → rerun `engine_answer_tiny` (cap 1200 s); fund the unit only if that run finishes. Accept: typed below-parser kernel seam + one engine harness and one trace harness green in `just kani`.
