## Ranked summary

1. **S3: one input already aborts at the UI server's chosen 64-MiB stack size.** Replace input-character recursion, not another stack enlargement.
2. **S7: existing before-second-guideline custody decoupling deadline.** Prevent routine clause/schema changes from multiplying clinician re-review.
3. **S1: browsing one document depends on all guidelines.** Request latency, concurrent RAM and scratch copies scale with unrelated corpus content; route-local immutable prepared models are foundational.
4. **S9: full UI gate RAM breaks well before 1,000 guidelines.** ≈11 GiB at ×100, ≈110 GiB at ×1,000 from the measured G=4 sample; streaming/partitioning preserves the same checks.
5. **S8: custody cost depends on review-history batching.** At one recorded commit per document, derived historical miss work alone reaches six hours near 137 CDC-sized guidelines; at one per guideline it is far smaller. Cache immutable attestations and group git validation.
6. **S10: three serial complete browser passes approach the six-hour job cap near the upper stress envelope.** Preserve all page/red coverage through sharding; fixed reading transitions are not the scaling problem.
7. **S4/S5/S2/S11: indexing/preparation unit, not local ad-hoc caches.** Title scans are cubic in per-guideline document/region co-growth; ledger preparation is repeated per page; alignment clipping and intake contain further nested scans.
8. **S6: refine the user-visible conflict scope before concurrent review becomes routine.** Current global guideline CAS is correct but forces unrelated decisions to refresh/retry.
