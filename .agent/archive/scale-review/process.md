## Ranked summary

1. **Before guideline 2 — P4:** composition gate has a CDC-global exclusion oracle. A valid independent recommendation survives CDC exclusion but fails its zero-total assertion. Repair the oracle, not the KB semantics.
2. **Before guideline 2 — P3:** execute the existing user-ruled review-custody-decoupling deferral. Measured history proves emission-only review digest changes with unchanged ACE. Human source fidelity stays manual.
3. **Before dozens of CDC-sized guidelines — P1:** one serial authoring lane × unchanged-whole-corpus checks = quadratic cumulative intake work; existing sequential CI guideline loops cross the six-hour job envelope well before ×100 on the supplied timing model.
4. **At independently scheduled guideline releases — P5:** one whole-KB branch/archive/blocker set couples unrelated guidelines; one rejected document can block every otherwise-ready guideline. At ×1,000, even one uncompressed corpus snapshot is ~12.81 GB/1.517 M files before history/build copies.
5. **As reviewed history grows — P2:** current baseline has no decision ledger, so current gates miss the cost regime. Ledger scans are locally quadratic in documents/decisions; every gate repeats two git commands/row and whole-guideline derivation/unique reviewed commit. Index and cache without weakening attestation.
6. **Before broad/clean-host intake — P6:** maintainable committed harvest/merge/refresh machinery; the existing catalog is already 847 eligible/pending guidelines, not 847 compiled guidelines, and it has 416 organizations outside completed sweeps.
7. **Keep — agent-law/spec checks + catalog basic validator:** their algorithms and current data sizes are not the scalability bottleneck. No arbitrary text caps, gate removal or database migration follows from this audit.

## Evidence + findings

### P1 — major — serialized authoring and repeated whole-corpus verification

Text anchors (`rg -Fn`): `Exactly one source document is in progress at a time.` (`docs/REFERENCE.md:1582`); `MAIN drafts every ACE document` (`.claude/rules/corpus.md:15`); `for g in guidelines/*/; do` (`justfile:979,996`). Start-of-round `ckc check` is named at REFERENCE 1546–1548; corpus validation runs every guideline at 1558–1564. Closing law at .claude/rules/corpus.md:25 repeats compile/queries/check.

Let r = rounds per guideline; k = cost to validate one unchanged CDC-sized guideline at the fixed worker capacity. Filling G guidelines sequentially requires approximately r·k·Σ(i=1..G)i = r·k·G(G+1)/2 of whole-corpus validation work, even if every lower-level algorithm is linear. Compiler/lexicon changes add rework; no cache key or changed-only gate is specified. Per-guideline authoring also invokes align per document; `rust/ckc/src/check/pipeline.rs:40–46` collects all IDs and validates all coverage before selecting one payload. `rust/ckc/src/check/corpus.rs:12–24` has two linear projection/docid joins inside d loops. These are separate locally superlinear setup costs, not evidence that all corpus operations are quadratic in G.

History probe (`history.py`, rc 0; base fixed above): 815 total commits; 103 touch CDC; 38 touch its ACE path. The 492 surviving ACE files first appear across 14 addition-bearing commits: 12,30,37,25,27,27,23,151,2,36,8,2,2,110 files (median 26). These are **commits, not proven round/session/person-hour counts**; some include schema development and cannot predict a mature guideline's labor. Full `git log --stat` evidence = `ace-history-stat.txt`.

CI arithmetic uses the **brief-supplied** run 41022878056, not a new run: check's ~12–15 min corpus stage ×100/×1,000 = 20–25/200–250 h if that work scales proportionally on the same runner; 6 h reached near 24–30 guidelines. `justfile:996` certifies guidelines sequentially: ~8G+2 minutes → G=45 already ~362 min, before bootstrap. Internal document workers do not fix the serial per-guideline job boundary. No full gate/check/certify/test suite was run.

Revision: independently owned guideline units/worktrees; content-addressed compile/certify/review inputs + changed-scope checks; guideline CI matrix; a separate retained cross-composition check. Preserve every acceptance property and planted red case. Parallel authoring requires a user-ruled change to the current one-active/MAIN-writes policy.
