## Ranked summary

1. **Before a second interacting guideline: composition assurance (S8, S9, S22).** Both text scans and the native scope gate are invoked per guideline, but their properties are not closed under union. Reproduced: separate 0/0 → union 1 for derived entities, formula cycles and exclusion/deontic-body compatibility. Aggregate replay is already consumer-facing at runtime; build greens need an explicit composition reading. IMP must not plan a faster consumer without this acceptance coverage.
2. **Already present: bounded formula walk is not a complete cycle analysis (S9).** A seven-edge formula dependency loop passes while a six-edge control rejects. More guidelines broaden possible chains. Increasing the constant is not a scalable proof.
3. **At ≈19 CDC-size guidelines on the measured CI shape: check-job ceiling (S19/S10/S12/S17/S18).** Corpus-proportional segments alone project past six hours; ×100 is ≈32 h, ×1,000 ≈320 h before superlinear/global costs. Content-keyed re-use + independent guideline shards are required; merely adding workers does not remove serial guideline/whole-corpus stages.
4. **At real review history: U whole-guideline re-derivations and 2l git children/check (S13).** Current zero-decision baseline hides it. Content-addressed row/bundle closure and batched ancestry are the mechanism fix; revising a custody guarantee is not necessary.
5. **At ×100–×1,000: global release memory + quadratic member sort (S14/S15/S23).** Every check builds the all-guideline bag twice. ≈1.28/12.8 GB raw payload becomes several live copies; sorting/descriptors and profile joins also become superlinear. Streaming plus per-guideline immutable release partitions avoids binding routine authoring gates to the size of the entire national corpus.
