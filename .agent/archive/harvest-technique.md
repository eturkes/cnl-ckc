# Compendium + harvest technique (M1)

Read before compendium edits, queue promotion, or fetch/access work;
pointer = `.agent/memory.md`.

- Guideline-source discovery = `.agent/compendium.md` (org universe + guideline rows; header owns eligibility, independence, promotion + terminal rules). Enumeration independence = distinct source OWNER/dataset, issuer- and developer-controlled listings excluded; all NLM properties (PubMed/PMC/Bookshelf) = one owner → pair an NLM id with Crossref/GovInfo/a membership frame. Bibliographic cells cite stable ids (`PubMed PMID`, `PMC`, `DOI`, `NBK`, `GovInfo`) so claims stay checkable from the file alone.
- Access classing: decide from artifact bytes/body, never transport. Cloudflare `Just a moment` + Akamai `Access Denied` = anti-bot → row access `unverified` + `provisional(<why>)`, not an access gate. Transport-earned `open` re-decides against the entitlement prompt (`Get full text access`, a lock-marked `Check Access`, a fulltext→abstract bounce serving a page-image preview). Unpaywall NOMINATES only (`.scratch/audit_open_oa.py`): society journals post guidelines free-to-read without an OA licence, and its records predate platform moves — a substantive live artifact read decides.
- Access probes: classify the FINAL url + body; a 2xx describes the REQUEST, never the artifact. Zero bytes → `empty(<code>)`; cookie/session interstitial → `challenge(cookie-wall)` — Atypon/Silverchair answer a cookie-less fetch with 200 + real HTML + no artifact bytes at `/action/(cookieAbsent|cookieSet|showLogin)` or `[?&]cookieSet=`, so a body-only test manufactures FALSE opens (worse than false negatives: the row promotes and the fetch cannot succeed), while a proxy retrieving genuine bytes still earns `open(reader)`. 202 + 0 bytes = CHALLENGED, never dead (deadness reads as `Page Not Found` through a cleared browser); guards are path- and cache-scoped, so try case variants before ruling a URL dead. Serialize per host across the sleep AND the whole request (`probe_urls.py` holds the lock across `urlopen`; overlapping slow fetches are the concurrency a meter counts), route direct → reader → authenticated same-origin `fetch()` evaluated in an already-open page on that host (clearance lives in the browser cookie jar; `curl` keeps 403ing), and treat evidence predating a detector fix as void for the affected shapes.
- Harvest access workflow: producers emit eligible rows `unverified` + probe-pending; MAIN runs one serialized probe pass, applies convergent verdicts (`.scratch/apply_probe_access.py` rewrites only where evidence disagrees), and batches human gates. Probing is what saturates producers — the ones that skip it finish a full org in a third of a window.
- Issuer cells claim ARTIFACT authorship; `CPGs` claims ORGANIZATION enumeration evidence. Every issuer must hold an org row and none may read `CPGs=no`; requiring `CPGs=yes` inverts the dependency and makes co-issued work unrecordable. New issuers enter through validated compendium-org appends, never implicit sweep widening.
- Row re-verification reads the artifact's own text: `pdftotext -l 8` on a PDF, tag-stripped HTML otherwise, `r.jina.ai` only where a direct fetch is refused. A throttled reader returns a ~200-400 byte stub whose `Title:` header echoes the document, so title matching on a stub confirms itself — anything under ~2000 bytes verifies nothing and must be reported `thin`, never clean. `jts.health.mil` PDFs render as stubs through the reader but extract fully via `pdftotext`.
- Manifest exactness lives at report merge: each issuer report counts the rows its own index emitted, shared co-indexed artifacts emit byte-identically from each report, and `indexed-by=<org>[ + <org>...]` / `off-index(<why>)` assign custody (a row carries at most one marker). A table-only recount cannot prove provenance — split co-issuers across reports wherever a manifest must be provable, and let only a batch re-emitting the artifact replace an `off-index` row.
- A gate test that re-runs the tool's own detection regex over the shipped corpus proves nothing: replace the regex with `(?!)` and it stays green, because a detector that finds nothing reports nothing wrong. Drive the TOOL over synthetic positives and negatives instead, and keep the corpus scan as a separate convergence check pinned to the shipped tool (never to `M1U2A_ARTIFACT_DIR`, which swaps tool variants). Mutation is the measure: `.scratch/m1u2c/rev2-1/run_mutants.py` regenerates one-behavior mutants of the attribution predicates from `base/` (refresh it from the live tools first) and scores them against the gate.
- An org's guideline index = the BROADEST listing on its own site that enumerates its clinical-guidance artifacts and still enumerates inside the easy tier. A narrower filtered view is not sweepable while a broader own-site listing exists: the header emits no row for material outside the swept index, so sweeping the narrow view records the org as swept while its other eligible artifacts hold neither a row nor a deferral. Where the broad listing outruns the tier, the whole org takes `blocked(<why>)` — deferral is honest, silent narrowing is not. Societies publish one corpus under many labels, and the recorded index often sees a fraction: ACOG's own Coveo endpoint (`POST https://www.acog.org/coveo/rest/search/v2`, anonymous, `groupBy` on `@selectedcontenttype`) counts ~2,500 clinical records across 11 guidance types against the 61 the compendium's `Clinical Practice Guideline` facet carries.
- `merge_rows.py`: an issuer's sweep may REPLACE a co-issued row its own index carried, printing the diff for a MAIN ruling. Tiering split co-issuers (ACC swept in M1.2b; AHA/ADA/ASN never swept), so "sweep every issuer together to replace it" is unreachable and would freeze a co-issued row at its seed-era cells forever. Replacement authority = ownership: one of the row's issuers, or the index that carried it (`claim_orgs(row) & (issuers(stale) | attrib(stale))`), OR an emission naming every issuer the retained row named. That superset clause is what lets a third index improve a row it shares no issuer with — AASM's Endorsed Guidelines subindex carries the benzodiazepine guideline whose seed named ASAM alone, and the sweep emits all eleven issuers plus `indexed-by=` — while an emission that DROPS an issuer stays refused as a competing claim about authorship rather than a better-attributed row. A `queued|in-progress|done` row is suppressed rather than replaced, co-issued ones included.
- Harvest emitted cells are authoritative: a producer's prose and its rows disagree, and the merge ships the rows. Diff each report's stated corrections against the cells it emitted; corrections land in the report + remerge, or as one idempotent MAIN fixer (a re-merge replays producer cells and silently undoes hand edits).
- `merge_rows.py` regenerates table bytes only, never the header. A replay claim names the base + command and compares tables byte-for-byte; header prose sits outside the claim. Record the reproducible check, not a bare SHA.
- Repair fixers match the owned field's SHAPE/prefix (`provisional(access unverified:`), converge across every prior wording the script has written, and replay to zero edits — an exact-text match skips the rows that need repair most.
- MMWR states a recommendation's label year in the title (`— United States, 2024`) and its publication year in the volume (`year = 1951 + volume`, readable from every URL shape), and the two differ constantly. Rows record `title (label-year; pub YYYY)` whenever they differ, since the table sorts on version year; a season range (`2024–2025`) names no single label year and keeps the publication year alone, and a month may sit between the scope clause and the label year (`— United States, December 2024`). The volume rule holds across all 75 shipped MMWR rows with one exception in the shape it predicts: a late issue cover-dated into the next January (56(51) → January 4, 2008) takes the date's year. Titles come from the artifact's own `Suggested citation for this article` line — a topic page's link text is display shorthand, and three ACIP rows shipped it. Two current artifacts stay scope-distinct when the later replaced one component of the earlier (mm7349a3 vs rr6909a1's MenB-4C schedules); the earlier row's notes carry the version qualifier, quoted from the superseding artifact.
- A guideline that consolidates another body's recommendations without adding new ones stays eligible: it carries systematically developed patient-care recommendations, which is the test — `does not contain any new recommendations` describes novelty, not content. Check the ISSUER cell instead, since such artifacts are commonly indexed by a body that only reviewed them (HICPAC indexes MMWR rr6007, whose work group, vote and title are ACIP's). A manifest reconciles an INDEX while the org cell records ISSUANCE, so the two diverge routinely; notes carry `indexed-by=<org>` (counts in the indexer's manifest, issuer keeps the org cell) or `off-index(<why>)` (no index carried it, so no manifest counts it — the shape the cross-check's gap rows need). Sweep tooling attributes deletion, claiming and counting by the same rule.
- HRSA women's preventive services = WPSI-developed living recommendations: no version year appears on a WPSI recommendation page (reader proxy or real browser), beside a service in the HRSA index, or on the WPSI recommendations table. Their rows carry `provisional(year unresolved: ...)`; only a row whose notes state a dated adoption (`HRSA-adopted YYYY-MM`) has an evidenced year. `www.hrsa.gov` + `www.womenspreventivehealth.org` 403 scripted UAs.
- Compendium gates: committed `tools/goal.py check` owns the `/goal`-consumed subset FIRST, before any swipl work — row format/vocabulary (org table + TSV), both canonical orderings, the one-active-row promotion invariant, dup keys, and the terminal meter `goal: compendium ok <O> organizations <G> rows; terminal remaining: orgs=<n> rows=<m> provisional=<p>` (exhaustion ⟺ n=0 ∧ m=0; a non-terminal compendium stays green). Strictness deltas vs the scratch validator: TSV header line required, `CPGs=no`+`pending` counts terminal, missing TSV fails, first violation stops. `.scratch/check_compendium.py` owns the deep predicates (independence, collisions, LEGAL_SWEPT, manifest grammar/arithmetic/attribution, `--require-swept`) when present — before any bulk compendium re-edit, regenerate any missing deep gate from the compendium header + `.scratch/contracts/`; M1 unit mutation/prechange suites are history.
- `compendium_io.py` owns every question two tools would otherwise answer separately: org-name normalisation (`norm_dash`→`norm_punctuation`→`norm_affix`→`norm_stopwords`, `name_collisions`), enumeration independence (`OWNERS`, `NON_QUALIFYING`, `FRAME_OWNER`, `CONTROLS`, `qualifying(cell, org)`), the `LEGAL_SWEPT` matrix, and both canonical sorts. Independence needs the CITING org, not just the label: a frame its owner or parent controls proves nothing (`APTA sections/academies` for an `APTA <name>` academy, `AAFP-PG` for AAFP), while a third-party MEMBERSHIP roster stays independent for its members. Validate a `FRAME_OWNER` value against the universe only where the label is CITED — an unused label's owner holding no row says nothing about the table, and failing on it makes every small fixture unpassable, which is how it broke every synthetic positive control at once.
- Compendium mutation tooling: `.scratch/merge_rows.py` = the only M1.2+ row inserter and the canonical full sort (orgs class→CPGs→alpha; guidelines open-band→class→org→year desc→title). A sweep is total for its org — every guideline row of an org whose emitted `swept` is a date is deleted, then the report's rows insert, so the sweep and not the seed defines that org's rows; `blocked(...)` deletes nothing; `queued|in-progress|done` rows outrank a sweep, are kept verbatim, and their suppressed corrections print for a MAIN ruling. Reports are the source of truth → repair a report and re-merge, never hand-edit the compendium; every repair lands as an idempotent script so the wave stays re-derivable. `.scratch/apply_fixes.py` + `.scratch/splice_compendium.py` = M1.1-only; they reject sweep/provisional states and erase harvest → never reuse for M1.2 rows.
- Index-harvest technique: the `https://r.jina.ai/<url>` reader proxy renders indexes that return scripted-UA 403 (CDC, HRSA, HICPAC, ClinicalInfo, ACIP, ASCO) and costs one fetch. `www.cdc.gov` refuses headless Chrome `--dump-dom` too, so the reader proxy and the authenticated browser are the only routes into CDC and a DOM-fetch batch there yields zero bytes however long it runs; Cloudflare/Akamai challenge pages still need the authenticated browser. Enumerate from an org's data layer where one exists (USPSTF `data.uspreventiveservicestaskforce.org/api/json`, VA PBM `/formularyadvisor/DOC.json`, ACOG Coveo, ACR `acsearch.acr.org/list`) — one fetch replaces whole-site crawling.
- M1.3b gap evidence: `.scratch/m1u3b/gapcheck/gaps.tsv` (669 candidates over 16 organizations), cache-replayable via `build_gaps.py`; terminalization fixer `.scratch/fix_m1u3b_terminal.py` (idempotent, embeds MAIN rulings). M1 crosswalk/production-gate details are historical — re-derive from compendium header records + `.scratch/agents/` reports.
