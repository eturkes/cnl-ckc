# N14 — recipe checks in the gate (contract; archived at unit close)

Row = refresh find (fddc538d): the toolchain + bump recipes (`swipl`, `amend-manifest`, `bump-crate`, `bump-verus`, `bump-kani`) were checked once from `.scratch/` (history differentials, planted failures, the review probe harnesses that `rust.md` names), so no gate guarded their fail-closed behavior. Accept: a committed check in `just gate` (mocked network + toolchain; shell or Rust, since python stays scratch-only) that fails when a recipe's version probe sits inside another command's arguments or when `amend-manifest` accepts a staged manifest edit, and passes on the current recipes; `rust.md`'s scratch-check note then names it.

## Design

- D1 vehicle = `rust/ckc/tests/recipes.rs` (`just test` ⇒ `just rust` ⇒ `just gate` + CI job `rust`). Each case copies the repo `justfile` into a private fixture root under `rust/target/recipes/<pid>/` and runs one recipe through the real `just` (found on PATH; absent ⇒ the test fails) with a cleared environment: `PATH` = a mock dir + `/usr/bin:/bin`, `CKC_TOOLCHAIN` = a fixture toolchain, `HOME`, `TMPDIR` + git config/identity inside the fixture. Mocks: `curl` (URL → fixture file routes; an unrouted URL exits 22), nested `just` (logs its arguments, exits 0 for `tools` + `_relock`), `uv`, `ckc` (`CKC_BIN`), the probed binaries (swipl, z3, rustc, CBMC, Kissat); archives = real `tar -czf` output; `git`, `jq`, `tar`, coreutils = the system's.
- D2 version-probe cases: each probe (swipl; bump-verus z3 + rustc; bump-kani CBMC + Kissat + rustc) gets a failure case (the probe prints a plausible version, then exits 23 ⇒ its recipe exits nonzero; bump-kani leaves `kani.lock` byte-identical; bump-verus never reaches `_relock`); one control per recipe (every probe succeeds ⇒ rc 0 + the probed values recorded).
- D3 amend-manifest cases (a git fixture repo; mock `ckc release-manifest` = sha256 of NOTICE): current ⇒ rc 0 `current`, HEAD kept; stale ⇒ rc 0 amended, parent kept, an unrelated staged file stays staged, a rerun says `current`; dirty working manifest ⇒ rc 2, bytes kept; staged-only manifest edit (working file = HEAD) ⇒ rc 2, staged blob + HEAD kept.
- D4 bump-tool cases: GitHub controls (a `v` tag with a versionless asset; a bare tag with a versioned asset) + a rustup control ⇒ the row = version, asset, sha256, URL from the release data, nested `just tools` runs, the other rows byte-identical; digest mismatch + missing digest ⇒ nonzero, `tools.lock` byte-identical, `just tools` never runs.
- D5 the check's own red input: each D2 failure case and the D3 staged-only case also run a planted pre-fix form of the recipe (the probe moved into another command's arguments; the guard without its index half) and require that form to slip through (rc 0, with the lock, HEAD or staged blob changed where D2/D3 require them kept). A plant whose anchor is missing, or whose form no longer slips through, fails the test ⇒ every gate run shows the check able to fire.
- D6 scope: `bump-crate`/`_relock` hold no version probe; the history differentials (`bump-kani`/`bump-verus` at the pinned release, `bump-crate` round trips, `bump-tool` on every row) need the network ⇒ they stay manual, named in `rust.md` with their results pointers. The python probes retire: `rust.md` names the committed check.

## Tier

shell (checks of trusted tooling recipes). A defect = a check that cannot fail ⇒ D5 makes each run show its firing; `reviewer` on the diff before commit (fixed check set R1–R6: probe + guard coverage, plant fidelity to the pre-fix forms, control strength, environment isolation, runner portability, rule-text accuracy).

## Predicates (acceptance = the row's check)

- P1 `cargo test --test recipes` passes on the unit tree (every D2–D5 case).
- P2 red replay: the test fails against the historical pre-fix justfiles — a6fc4f9d (the probes inside arguments) and 88536705 (the amend guard without its index half) — through `CKC_RECIPES_JUSTFILE=<file>`, which replaces the repo justfile in every case.
- P3 runtime ≤ a few seconds; no file written outside `rust/target/recipes/<pid>/`; no network access (mock curl routes only).
- P4 `rust.md` names the check (+ its firing), the python probes retire from it; full `just gate` green at the unit commit.
