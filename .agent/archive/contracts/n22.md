# N22 — reviewer UI viewport meta + narrow-screen tables (contract; archived at unit close)

Row = template refresh find (8681e3a9, O13): no page carries `<meta name="viewport">` ⇒ phones lay pages out at ~980 px. Measured at 8681e3a9 (Playwright mobile emulation 390×844, `isMobile`, DPR 3, every page `ckc ui render` emits): no meta → 0/340 pages scroll sideways (zoomed-out 980 px layout); meta alone → 53/340 (index table 794 px, guideline `table.compact` 560 px, 51 timing tables 436–499 px). User ruling (AskUserQuestion, this session): meta + table scroll box; the row's acceptance widens to the meta + one narrow-screen rule. Accept (widened): every page carries `<meta name="viewport" content="width=device-width, initial-scale=1">` + the stylesheet rule `@media screen and (max-width: 40rem) { table { display: block; overflow-x: auto; } }` under the K5 render proofs, golden re-pins diffed against those two changes alone; a mobile-emulated 390 px render of each page kind the renderer emits shows no page-level horizontal scroll.

## Tier

`kernel`: `ckc-spec` ui.rs (copy table, frame, stylesheet) + uninspected `ckc-kernel` impl + proofs (K5 frame render fidelity + copy soundness) + goldens (data, re-pinned by script).

## Design

- D1 Copy table: `meta_viewport = "<meta name=\"viewport\" content=\"width=device-width, initial-scale=1\">";` appended at the `copy_table!` end (registry index 301; table size 301 → 302; the k5-sound generators' size assertion moves with it).
- D2 Frame: the page head = `<meta charset="utf-8">`, then the viewport meta on its own line, then `<title>` (spec `frame` + kernel `k5_frame::frame` + the `k5_sound_build::frame` soundness proof). Every page kind (index, guideline, records, document, every error/refusal page) renders through `frame` ⇒ every page carries it once.
- D3 Stylesheet: `css_text` gains the line `@media screen and (max-width: 40rem) { table { display: block; overflow-x: auto; } }` directly before `@media print {` (screen-only: print layout unchanged; a narrow table keeps its rows as a table inside a horizontally scrollable box; `display: block` keeps table semantics in Chrome, Firefox + Safari 17+). No new color, no banned CSS token (`css_tokens`), no `#`.
- D3r Proof cost: the copy table's growth to 301 entries already pushed `k5_sound_document::head_sound` to `#[verifier::rlimit(20)]` (q13); entry 302 may push a page proof over its budget → rust.md remedies (split, hide, short pieces), never a bigger rlimit.
- D4 Generated kernel files (`k5_sound_{chrome,encoding,literals,patterns,registry}.rs`) regenerate from ui.rs through `.agent/archive/generators/` (size assertion 302); `generators.tsv` target sha256 rows follow; `replay` → identical ×6.
- D5 Goldens: `.agent/archive/migrations/n22-viewport.py` (idempotent) inserts the meta line after each golden page's charset line + the rule line before its `@media print {` line in every `tests/ui` golden/expect file holding a page; no other byte moves. `assertions.tsv` rows keep their meaning.
