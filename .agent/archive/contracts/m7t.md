## Design (A+ = v1 primitives kept, typed annotations added)

D1 Input. `guidelines/<id>/temporal.tsv` = corpus data; its presence selects schema v2 for every document of that guideline; absent ⇒ v1, byte-identical to today. Grammar: 2 pinned header lines `# format: kind<TAB>lemma<TAB>value` + `# kind: unit (value: second|minute|hour|day|week|month|year) | relation (value: duration|within|after|before) | spacing (value: frame noun lemma)`; rows `unit<TAB>L<TAB>U` (noun lemma L → unit id U), `relation<TAB>P<TAB>R` (preposition lemma P → role R), `spacing<TAB>P<TAB>F` (preposition P + frame noun lemma F); lemma bytes = nonempty valid UTF-8, every byte > 0x20 and ≠ 0x7F (MAIN rulings: an APE lemma is one token, so no matchable lemma holds a space; reviewer-1 R1 — the compiler matches decoded lemmas, so the spec requires UTF-8 too); a lemma occurs in at most one `unit` row, a preposition in at most one `relation` row, a (P,F) pair in at most one `spacing` row, a frame noun never as a unit lemma; final LF; ≥1 row. Unknown kind/value, malformed row, duplicate → `ckc check` + `ckc compile` reject (first violation, pinned message).
D2 Selector. Compiler argv `v2 <tree> <docid> <temporal.tsv> [<ulex>] [proof]` (explicit token; never inferred from ACE); v1 argv forms unchanged. A v2 guideline with a missing/unreadable/malformed temporal input fails closed (no v1 downgrade).
D3 v2 document ABI. Header = v1 layout with `guideline_schema_version(2).`, record `guideline_document(DocId, ace_sha256(H), ulex(none|sha256(H)), temporal(sha256(H)))` (/4; H = sha256 of the raw temporal.tsv bytes), declaration block = v1 order with `guideline_document/4`, then `guideline_interval/6`, `guideline_recurrence/4` (11 indicators). Every v1 clause shape stays legal; semantic predicates in v2 = v1's seven + the two annotations. A v1 document never carries an annotation literal.
D4 Annotations (emitted after the matched `guideline_pp` clause, same context, same clause body for rules):
  - `guideline_interval(Context, Event, Role, Quantity, Unit, Anchor)` — pattern I: Anch item `modifier_pp(E,P,Q)` with P a `relation` lemma (role R), Q a time quantity (below); Anchor = A when exactly one same-context Anch item `relation(Q,of,A)` exists, else atom `none`.
  - `guideline_recurrence(Context, Event, Quantity, Unit)` — pattern R: Anch item `modifier_pp(E,P,F)` with (P, lemma of F) a `spacing` pair, F's same-context item `object(F,FL,countable,na,eq,1)`, exactly one same-context `relation(F,of,Q)`, Q a time quantity.
  - Time quantity Q = a DRS variable whose first same-context `object(Q,L,…)` names a `unit` lemma L (Unit = its unit id); its bound must be `countable`, unit `na`, a comparison other than `na`, and a count ≥ 1, else `no_bound`/`zero_bound` (MAIN ruling: a claimed unit lemma never falls back to a plain pp).
  - Same-context = equality of the Anch items' context terms within one sentence's flattened items (one box), never list membership: APE nests an upper-bound group (`at most`) as a sub-list while `object(Q)`/`relation(Q,of,A)` sit in the parent list. Primitive clauses (pp, entity, cardinality, operator edges, NAF) stay exactly as v1 emits them; ref(N)/box(B)/witness numbering = the v1 traversal.
  - `relation/3` is legal only as the `of` link consumed by one pattern match; every other `relation/3` rejects as in v1 (`condition_shape(relation(...))`).
D5 Rejects (class `unsupported`, exit 1; first violation in pass order = pp annotations left to right, then shared claims, then NAF payload scopes — MAIN ruling, rejects are not certified): `temporal_shape(Why, S)`, Why ∈ {`no_bound` (Op = na), `zero_bound` (N < 1), `duration_anchor` (role duration with an anchor), `anchor_count` (≥2 `of` links on an interval quantity; ≠1 on a spacing frame; any on a recurrence's quantity), `shared_quantity` (a quantity or frame matched by two patterns), `frame_shape` (frame object not `countable,na,eq,1`), `anchor_shape` (the `of` object of a quantity is itself a time quantity or frame)}. Exact detail bytes = tests/red pins.
D6 Denotation (REFERENCE; reified data constraints, never evaluated schedules). Quantity's cardinality clause carries Comparison (`eq|exactly|geq|greater|leq|less`; geq/leq inclusive, greater/less strict) + Count (integer ≥ 1); Unit = calendar label, no conversion (month/year calendar, not fixed day counts). Roles: `duration` = the length of Event; `after` = Event occurs that long after Anchor; `before` = Event occurs that long before Anchor; `within` = the distance between Event and Anchor, direction unstated (CQL-symmetric reading); Anchor `none` = the sentence names no reference point (never "now"). Recurrence = successive occurrences of Event are spaced by that long (`leq 3 month` = at most 3 months apart); first occurrence, end, and count per window stay unstated. Two annotations on one Event = conjunction (a range = same-anchor pair). Matching stays exact Horn structure: `geq 30` does not entail `geq 20` (comparison semantics = the separate numeric-threshold class).
D7 Composition. A loaded composition holds one schema version (all v1 or all v2); mixed → `ckc v1 <mode>` rejects with a pinned `check_load` detail. `ckc v1 <mode>` (the codec family) reads v1 and v2 documents; v1 inputs keep byte-identical outputs + rejects. v2 questions follow D9; a v1 question keeps the v1 law (no annotation predicates; `relation/3` rejects); v1 questions answer + trace over v2 compositions; replay/aggregate/recursion/trace cover annotation clauses.
D8 Custody. Certification takes the raw temporal bytes: `certify_doc` v2 = custody (record digests incl. temporal) + v2 projection with the parsed table + payload; `ckc compile`, `ckc certify`, `certify-one`, `--cases` all pass it. Review bundle v2 policy unchanged (semantic-only: a mapping change that alters annotations alters the clause digest → review stale; an irrelevant table edit leaves reviews valid; fixture proves both). Export: `meta schema` = the corpus schema version(s) instead of the literal `v1`; README-dist schema extraction keeps the v2 subsection (REFERENCE § Compiled Prolog schema gains `### Schema v2` inside the same H2).
D9 Temporal questions. A guideline with temporal.tsv compiles every question in v2: argv `question v2 <tree> <qid> <temporal.tsv> [<ulex>]`; record `'$guideline_query'(v2, QId, ace_sha256(H), ulex(none|sha256(H)), temporal(sha256(H)))` (/5); projection term unchanged in shape. v2 question law = v1 law + nested condition lists admitted (an upper-bound determiner's group, flattened into its box; a marker inside a group rejects `condition_shape`) + `relation/3` leaves admitted + the D4 annotate pass over the flattened goal items (same patterns, same rejects; a leftover `relation/3` rejects). Answer + trace: goal whitelist by query version (v1 query = the seven v1 predicates; v2 query = + the two annotations); a v2 query over a v1 composition rejects `check_load` (pinned detail); a v1 query runs over v1 or v2 compositions; an empty composition accepts either. Answers/traces artifact records keep their `v1` token (artifact format unchanged). `certify_query` v2 takes the temporal bytes: custody (version 2 record + temporal digest) + v2 question projection.
D10 Reviewer UI timing table. A document page whose pl parses (K1) as a v2 document with ≥1 annotation literal gains one section after the ACE section: heading `Timing as compiled`, one table, columns `Sentence | Part | Action | Timing | Reference point`; every other page stays byte-identical. Rows = annotation literals in document order (bundle → clause → head, then body items left to right, NAF goals included); a row repeating an earlier row of the same bundle (rendered cells equal) is skipped (MAIN ruling: body goals repeat per clause and split variants repeat heads). Part = `statement` (head) | `condition` (positive body goal) | `excluded condition` (inside a NAF goal). Action = the lemma of the first `guideline_event(_, E, L)` sharing the annotation's event term — search the annotation's own clause (head, then body), then every clause head of the document in order. Count + comparison = the first matching `guideline_cardinality(_, Q, _, C, N)`; reference noun = the first matching `guideline_entity(_, A, Noun, _)` (same search). Timing phrase (fixed copy + decimal): duration `lasts <cmp> N <unit>`; after `<cmp> N <unit> after`; before `<cmp> N <unit> before`; within `within <cmp> N <unit> of`; recurrence `repeats <cmp> N <unit> apart`; cmp: eq → (none), exactly `exactly`, geq `at least`, greater `more than`, leq `at most`, less `less than`; unit word singular iff N = 1. Reference point = the noun | `not stated` (anchor `none`) | empty (duration, recurrence). A failed join renders `not stated`; a lemma or noun renders only when its bytes occur verbatim in the pl (else `not stated`) ⇒ every visible slot is a copied pl span, registry copy, or a canonical decimal. New fixed strings append at the copy-table end; K5 render-fidelity + copy theorems re-verified; `ckc ui check` green; UI fixtures gain one v2 green case + one hostile-join case.
