## Design

- D1 Reach: formula operands alone (da2 D1: a `$guideline_bound` item whose operand is a formula operand; a `some` amount `$guideline_amount`). Every other witness pair stays as today (anchored referents, box contexts, nt1 converted conditions outside formulas, scaled time, the supersession `Date − 1`); a `/6` time comparison cannot match an operand's unit fact in today's grammar, so time witnesses stay fixed.
- D2 Default w0 = da2 D4's witness in exact rational arithmetic: `some` → 1; `exactly N` → N; `geq N` → N, or 1 when N = 0; `leq N` → N, or −1 when N = 0; `greater N` → N + 1, or N + 2 when N + 1 = 0; `less N` → N − 1, or N − 2 when N − 1 = 0 (integer or canonical rational N; for an integer N = da2 D4's value; for a rational strict bound da2 D4 returned N itself, which its own condition refuses — no committed operand has one: D9). Emission's default pairs use w0 (`emit::operand_witness` = `witness::w0`), so the no-winner fallback carries D2's default.
- D3 Boundaries of an operand X: B = {X's own bound, when its condition states one} ∪ {Bound of every `guideline_satisfies(C, D, Op, Bound)` inside a NAF item of the variant that is relevant to X} ∪ {0}. Relevance = a finite existential join over a snapshot of the variant's witness facts fixed before the walk: X's count slot = an open labelled slot, every other operand's count slot = an open unlabelled slot; the item's semantic (non-built-in) goals are matched against those facts under one shared substitution (branch-local bindings, occurs check), built-ins ignored as tests during extraction; the comparison is relevant iff some match keeps X's slot open and makes D end as that slot (a numeric equality with another fact's count is no origin; a match that grounds X's slot gives none either). An irrelevant comparison contributes nothing (over-collection changes the first winner). Candidates = B ∪ {b − 1, b + 1 : b ∈ B} (exact rational arithmetic: `rational(N, D)` ± 1 = `rational(N ± D, D)`, canonical) ∪ {(b_i + b_{i+1}) / 2 : b_i < b_{i+1} consecutive in B by rational order}, kept iff X's own condition admits them (exactly → = N; geq → ≥ N; greater → > N; leq → ≤ N; less → < N; `some` → every value); order = w0 first, then rational ascending, canonical duplicates dropped.
- D4 Tuples: the distinct operand referents of the variant, once across all its formulas, in antecedent DRS order; a constructive lazy odometer (an index vector, the last operand varies fastest, carry to the left; no product allocated); no operand = one empty tuple. Per tuple, the chain nodes evaluate as da2 D4 (DA1 `arith_result`).
- D5 Winner = the first tuple t with Win(P, t) := ChainDefined(t) ∧ heads_proved(witness_db(Facts(t), P), Heads(t)): P = the document's program as the aggregate loads it (`replay::doc_db`: its two record facts, then every clause in file order; no body calls a record); Facts(t) + Heads(t) = da2 D4's obligation under t (facts = positive body goals minus built-ins, heads = bound heads); `witness_db` + `heads_proved` = the existing K2 replay relation (the facts as the reverse-ordered front, a fresh replay_depth/replay_inf budget per head; a positive proof found after a pruned branch counts, as in K2; NAF fail-closed). No new evaluator: the spec reuses its total constructive replay. Spec = `ckc-spec/src/witness.rs` (`win`, `first_win`, `select_group`; certify's tail `emit::certified` derives `obligations(select_doc(ps, doc_db(doc)))`; `Group.sel` = a formula variant's operands + chain, set by `variant`). P = every clause of the document, sentences after the formula included ⇒ emission is two-phase: all clauses first, then each formula variant's selection + payload over the finished P (spec + kernel); the fork's proof mode asserts the complete document before any candidate replay.
- D6 Outcomes (iff): no tuple derives every chain node ⇔ w0's chain fails ⇒ reject `formula_shape(witness, S)` (lemma `contract.rs` `ws_default_chain` over `witness::chain_shape`: w0 is zero only at an operand forced to `exactly 0`, which every tuple shares; fixed zero literals are shared by every tuple; every other operand's w0 is nonzero; a chain fails only at a zero divisor ⇒ any chain-defined tuple implies w0's chain is defined); else the D5 winner when one exists; else the w0 tuple as fallback (w0 is in the searched product, so its replay failed under the same authoritative relation; the compile reports `underivable_obligation`, as today). First-error priority across formulas + every other reject + its order unchanged.
- D7 Completeness (stated in the spec, proved in the kernel): fragment premise = `witness::in_fragment(P, g, sel)` (decidable, conservative; frozen at the seed): the skeleton (the witness facts, each operand count an open slot) holds the slots once each and no other variable; per clause of the variant, its open head (operand counts + chain outputs open) is a predicate call (`head_call`: no comparison, arithmetic, conjunction or negation head, which K2 would decide at the head itself), unifies with exactly its own canonical clause of P, with no skeleton fact, and holds no slot; the walk of that clause's body from the head unification (the clause renamed above the skeleton, as a call renames it; negations walked from the branch's bindings) over the skeleton + P's ground facts: no call unifies with a rule of P (a clause other than a ground fact), no fact match binds a slot, a comparison reads a slot only as its `guideline_satisfies/4` count input against a number of that slot's B, each arithmetic goal = the chain's next node (`arith_ok`: the same operation; an operand count input = that operand's own slot under `exactly`; an exact literal input = itself; an earlier output input + the output pair = variables), no operator goal; the chain has the formula pass's shape (`chain_shape`: products + quotients over operand counts, exact literals and earlier outputs, every operand + output variable distinct); every body literal is a compound primitive (no `,` or `\+` term, no variable goal, inside an item) and every negation item holds at least one goal; every default-pair value is ground; the default pairs bind each operand's comparison to `exactly` and its count (`exact_comparators`: the skeleton = every tuple's facts but for the slots); each body's arithmetic = the chain (it alone reads slots + earlier outputs), outside every negation, no goal outside the chain reads a chain output. Theorems (`contract.rs`): `ws_cell_invariance` — under the premise, tuples whose coordinates share their cells (per operand: the same side of, or equal to, every boundary) give every head the same bounded K2 replay outcome (fuel-outs included), hence the same Win verdict; `ws_complete` — so each nonempty cell is represented by a candidate (b, a midpoint, b_min − 1 or b_max + 1) and a winner exists whenever any admitted rational tuple wins. Round 7 (`arith_ok`): the round-6 walk skipped arithmetic goals unread, so a body goal matching a ground fact of P in place of its operand's skeleton fact fed that constant into the chain and the head's output decided the branch by value equality — `done(Y) :- card(w, S, X), \+ q(S), guideline_product(S, X, exactly, 1, So, Y)` over P = {that rule, `card(w, geq, 2)`, `q(exactly)`}: inside the round-6 premise, B = {0}, Win([2]) = true, Win([3]) = false (an argued document, no fixture: `certify-one doc` refuses its hand-made head); consultant-14's sibling: a comparison head `guideline_satisfies(exactly, Y, geq, 2)` over that body is decided by K2 at the head (B = {0}: [1] fails, [2] wins) ⇒ `head_call`. Outside the premise the selection stays sound (a winner replays by construction), not complete. Win proves the heads (an alternative proof may discharge a head), never the selected variant's body; a composition's other guidelines stay the aggregate's.
- D8 Certification: the certified payload = the spec's (the D5 winner under K2). The fork selects with its own per-document replay = its own bounded interpreter (leftmost goals, one fuel per dispatch), an untrusted producer, its NAF made fail-closed for selection (a depth cut inside a negation = no replay, as K2; consultant-13 round 2: today's fork replay is fail-open there while the native aggregate refuses, and both accept a positive proof found after a pruned branch); on a certified success its payload bytes = the spec's = certify-one's: `ckc certify <id>` (+ its `--cases` battery) runs the fork's `proof` mode per document over the staged snapshots and refuses a fork/K2 disagreement (control, order or fuel) explicitly — `fork_payload_mismatch.` (the bytes differ), `fork_failed(<rc>).` (the fork's run failed; its stderr stays `ckc check`'s law, whose two proof runs per document refuse any stderr byte) — loud: an availability limitation, never silent divergence; `certify-one` runs no SWI-Prolog, and questions carry no witness payload. For a fallback rule the projection succeeds with the fallback payload while the fork reports `underivable_obligation` (`ckc certify`: `fork_failed(1).`) + the native aggregate refuses. Selection = a constructive relation (spec): the kernel's search is proven to refine it; the fork's is checked per document by that comparison.
- D9 Committed products: every committed formula variant (15: s33-01 = 14, 10 with NAF items; s42-15 = 1) keeps w0 as its winner (consultant-13 census) ⇒ every committed payload, answer + trace byte-identical against the unit's base (the CHR pins for s33-01 + s42-15 included).
- D10 Docs: REFERENCE § Formulas in ACE (default-first numeric candidates, exact rational cells, replay-checked selection, fallback + undefined-chain reject, the completeness fragment, the composition boundary), `.claude/rules/compiler.md`, the compiler header.
