# c1 — schema consolidation: one evolving schema (contract)

Row: `.agent/spec.md` Tasks C1 (Decisions: Schema evolution). User rulings (AskUserQuestion, strength-phase orientation, 2026-10-16): versioning = consolidate first — one evolving schema, identifier `1`, the whole corpus + every fixture re-derived at each schema revision, strict versioning + provenance after the first publication; the per-guideline table renamed in the consolidation; goal order (Intent) = executable + combinable KB for CDS use > clinician audit > formal verification. Accept (row): one schema for every document + question; `vocabulary.tsv` + record `vocabulary(none | sha256(_))`; no version selector, version law or mixed-version reject; corpus + every fixture re-derived; `just gate` green. Design review: consultant-1 (`.scratch/agents/str/consultant-1/verdict.md`, direction sound, K2–K9 changes adopted here).

## Tier

`kernel`: `ckc-spec` (v1text codec, vocabulary grammar, emit projection + certification, replay/answers/trace composition law, release meta, ui timing + words) + uninspected `ckc-kernel` impl + proofs + fork compiler (certified per document + question by translation validation) + shell plumbing (fixture tier) + fixture/corpus migration (data tier, graded by an independent churn oracle).

## Design

D1 Identifier. Every document carries `guideline_schema_version(1).`; every question record names `v1`; answers + traces artifacts keep `v1` (their token rejects stay). No other schema identifier exists. Historical labels in archived contracts, commit history and the `bundle v2` review format are untouched.
D2 Document ABI. Line 1 as today; the declaration block = the 15 indicators in today's v3 order (schema_version/1, document/4, entity/4, cardinality/5, event/3, arg/4, pp/4, property/4, operator/3, interval/6, recurrence/4, frequency/5, order/4, recurrence_window/7, range/3), each a `multifile` + `discontiguous` pair; then `guideline_schema_version(1).`; then the record `guideline_document(DocId, ace_sha256(H), ulex(none | sha256(U)), vocabulary(none | sha256(T)))` (T = sha256 of the raw `vocabulary.tsv` bytes; `none` = no table); then the `% S<n>:` bundles. K1 (`ckc v1 check`) accepts any of the 13 semantic indicators in any clause of any document: structure only; certification (D8), not K1, binds annotations to a table. Canonical quoting, arities and the identifier grammar stay as today.
D3 Question ABI. Record `'$guideline_query'(v1, QId, ace_sha256(H), ulex(none | sha256(U)), vocabulary(none | sha256(T)))` (/5 always); the projection term grammar of K1 is unchanged (today's `wf_query`); the 13-predicate goal whitelist belongs to answer/trace query validation (K2/K3), as today.
D4 Vocabulary table. `guidelines/<id>/vocabulary.tsv`, optional (absent = no table, record `vocabulary(none)`). Bytes: header = exactly the line `# format: kind<TAB>lemma<TAB>value` + LF; ≥1 row; final LF; a row whose first byte is `#` rejects `comment at row <n>` (so a pre-C1 two-line table fails at row 1); rows = every kind today's v3 grammar admits (unit, relation, spacing, window, frequency, approximation, range) with today's v3 row law, messages and check order (the version-gated `kind` rejects disappear). Regular-file + UTF-8 laws as today. Messages: `ckc: vocabulary: <path>: <why>[ at row <n>]`; green meter `ckc: vocabulary ok <path> <n> rows`. Retired name: a guideline directory holding `temporal.tsv` (alone or beside `vocabulary.tsv`) is refused by every command that reads a guideline's table (`ckc check`, `compile`, `queries`, `certify`, `release-manifest`, `dist build`, the UI corpus intake) with one pinned message; no command treats such a guideline as table-free.
D5 Compiler argv (exact vectors after `--`): document = `<ape-tree> <docid> <vocabulary.tsv | -> <ulex | ->` (4 tokens) or the same + `proof` (5 tokens); question = `question <ape-tree> <qid> <vocabulary.tsv | -> <ulex | ->` (5 tokens). `-` = none (a file named `-` is unaddressable). `proof` in the vocabulary or ulex slot rejects `usage, vocabulary_arg(proof)` | `usage, ulex_arg(proof)` before any file loads (so the old `<tree> <id> <ulex> proof` form rejects); a leading `v1|v2|v3` token rejects `usage, argv(_)` before any file loads; every other vector (old 2/3-token forms, a 5th document token other than `proof`, any other length) rejects class `usage` rc 2, each shape's exact detail pinned. An unreadable or malformed table = class `vocabulary_load` rc 2 (renamed `temporal_load`), never a fallback to no table.
D6 Annotation law. With a table: the whole q12 + q13 pattern set (interval, recurrence, order, frequency, scoped recurrence, approximation, range) runs in documents and questions, gated only by the rows the table holds (no version gate). Without a table: no pattern runs, a `relation/3` rejects as today, and no-table questions keep today's v1 question law (no nested upper-bound condition lists, no `relation/3` leaves) — table presence keeps gating those syntax decisions exactly as today. Reject classes + details unchanged (`unsupported, temporal_shape(Why, S)`).
D7 Composition. The schema/table-presence incompatibility goes: the `check_load, schema_version(V, DocId)` reject (mixed documents) and the `check_load, query_file(schema_version)` reject (query over an older composition) are removed; documents with and without a vocabulary digest compose, and a query composes whatever its own vocabulary wrapper. Every other composition law stays: distinct document records = manifest rows, manifest grammar, obligation coverage + replay, recursion check, query shape + whitelist, answers/traces laws.
D8 Certification. `certify_doc` / `certify_query`: custody = docid, ACE + ulex + vocabulary digests (`vocabulary(none)` iff no table bytes; a digest iff table bytes, equal to their sha256), one bundle per ACE line; projection = the D6 law over the DRS + the raw table bytes. Error names: `temporal` → `vocabulary`, `unreadable(temporal)` → `unreadable(vocabulary)`; `schema_version` disappears. `ckc certify-one <doc|query> <id> <ace> <ulex|-> <dump> <pl> [<vocabulary>]`.
D9 UI. The timing section renders when its row list is nonempty (no version condition; a range-only document still renders none); a guideline page renders the time words of a `vocabulary.tsv` that parses (rows grouped by kind, file order within each kind, as today); intake refusal `ui: viewmodel: <gid> vocabulary.tsv: <why>`; copy strings unchanged.
D10 Release + export. One `meta schema v1` row (the table input to the schema rows goes); release manifest + dist stage `vocabulary.tsv`; README-dist carries REFERENCE's consolidated schema section, which stays inside the H2 `## Compiled Prolog schema` (dist extraction is H2-bounded).
D11 Shell. The selector + version plumbing go (`common::selector`; the product-functor inventory = one list of 15 indicators; the shell module keeps a name distinct from the table parser). Red/green probe sidecars `<stem>.vocabulary.tsv` (`.temporal.tsv` retires); `<stem>.argv` generalizes to the whole argv vector after `--` (one line, space-separated tokens; `@TREE@` = the staged APE tree, `@ID@` = the stem, `@TABLE@` | `@ULEX@` = the sidecar paths) so tests/red pins every D5 vector; red probe class `vocabulary_load--…` (renamed `temporal_load--…`).
D12 Migration = `.agent/archive/migrations/c1-consolidate.py <repo-root>` (one idempotent script over the C1 base: two fresh base copies → byte-identical trees; a second run on a migrated tree → no change, byte-compared): renames every `temporal.tsv`, `*.temporal.tsv` and `*.temporal.tsv.in` (corpus, red/green sidecars, check-mutant plants, certify-one inputs, UI fixture trees) to the D4 names + rewrites the header; rewrites every hand-made fixture document + question header (tests/v1 inputs + `.tpl.in` templates with their `@@sha256` pins, tests/ui + tests/adjudication trees, the Kani harness constants) from its pre-C1 format to D2/D3, bundles byte-identical; migrates UI input dependencies (review-manifest rows, form bodies, fixture commit ids) by recomputation — a fixture ledger row whose `ace_commit` names a pre-migration fixture commit is re-pinned to the migrated commit and its recorded digest to the post-migration bundle digest, preserving whatever current/outdated relation the case pins; regenerates generated artifacts (corpus, red/green pins, query fixtures, certify-one fixtures through their generator, UI goldens, tests/v1 expectations) through the new compiler + binary. Header-malformed inputs keep their defect inside a D2/D3 envelope (re-targeted by hand, listed).
D13 Churn oracle = `.agent/archive/migrations/c1-churn.py <base-commit> <repo-root>`: scope = the enumerated migration artifacts (every D12 input, generated artifact + coupled fixture source; the enumeration itself checked complete against the tracked tree) — implementation, spec and docs edits stay under normal review + gates; grades each such changed file against the immutable base blobs + an expected transform computed independently of the production codec/emitter: corpus + generated documents byte-equal from the first `% S` marker; query artifacts = projection term unchanged, custody envelope recomputed; answers = result terms unchanged; traces = proof/result trees + clause hashes unchanged, query/answers custody hashes recomputed; K1 rejects = `noncanonical(L,C)` shifted by the header line delta when the reject lies past the header, else a ruled per-case expectation; former-v2-table probes gaining order annotations = an exact per-case ruling (heads, goals, bodies named); UI goldens = the P6 churn; every other change = a listed disposition row. It fails on planted deviations (a changed semantic clause, a wrong digest or offset, an erased reject, an unlisted file, an omitted case) — its own red input in every run.
D14 Disposition map (exhaustive, before any deletion; user approval of the deletion set, then one `.agent/deferred.md` row): every tests/v1 case, red/green probe, check-mutant plant, certify mutant, query fixture, q13 property family and q18 census domain whose distinguishing predicate changes gets one row: `migrated` | `re-targeted` (defect kept in a D2/D3 envelope) | `positive` (a former mixed or table-free reject turned into composition coverage) | `retired` (its only subject = the removed version law). Retained laws are never retired: declaration order/count/arity, non-1 identifiers, record arities, the mandatory vocabulary wrapper, `none` vs `sha256` spelling + length, query version token, answers/traces `v1` token rejects, foreign/variable goal + answer-row failures, fixed-name earliest divergence (13 predicates + the wrapper in both digest states), row grammar + duplicate/conflict order. Generated oracles (q13 properties, q18 census) rebuild their domains from this contract, never by migrating seed bytes; their changed case counts are reported.

## Predicates (acceptance; each seen red on the unfixed revision unless noted)

- P1 codec: `ckc v1 check` accepts D2 documents + D3 questions across ulex none|digest × vocabulary none|digest, every semantic indicator in heads, positive bodies and singleton/grouped NAF; rejects (R9 first divergence, pinned) a pre-C1 v1, v2 and v3 document + question, a `temporal(sha256(_))` wrapper, a missing wrapper, a /3 record, wrong arities, a non-1 identifier, a quoted or wrong query version; `ckc v1 render` emits D2/D3 bytes.
- P2 composition: aggregate-check, recursion-check, answer, trace, trace-check over none-only, table-only, mixed (both orders) and empty compositions with exact answers + trace trees; a query's vocabulary wrapper independent of the documents'; retained rejects (duplicate docid, manifest, obligations, recursion) as controls.
- P3 vocabulary: one `tests/check-mutants` plant per D4 law (header bytes, a `#` row + its precedence, each row-law violation in both row orders, `temporal.tsv` alone + beside `vocabulary.tsv`); raw-byte digest custody.
- P4 compiler: tests/red pins every rejected D5 vector through `.argv` sidecars + `vocabulary_load` (missing, unreadable, malformed table) in product, proof and question modes; tests/green gains a positive proof-mode lane (`<stem>.proof.expect` = the exact proof payload, run beside the product pin, no-table + table-backed probes); tests/green pins a no-table document, a table-backed document (each D6 pattern) and a question of each kind; a former-v2-table probe types order per its D13 ruling.
- P5 certification: tests/certify mutants on documents **and** questions — a `temporal(sha256(_))` wrapper, a digest over a no-table guideline, `vocabulary(none)` over a table-backed one, a wrong table content/digest, an annotation with no table, a changed annotation with primitives retained → each fails with its pinned `<why>`; the clean document + question certify.
- P6 UI: tests/ui goldens differ from pre-C1 only by D13-predicted churn (D2-header pl text, D9 messages, hidden review digests of former v2/v3 documents — their semantic clause stream holds the version line —, fixture commit ids, former-v2 before/after time-word rows now the unquantified-order explanation); exact timing rows + refusals kept; a range-only page renders no timing section; `ckc ui check` green over the corpus.
- P7 release + export: `meta schema v1` single row; the dist archive holds `vocabulary.tsv`, no `temporal.tsv`, and README-dist the complete consolidated schema section (`dist_cases` + exported-member inspection).
- P8 migration: D12 replays byte-identical from two fresh base copies + idempotent on its own output; D13 reports 0 unpredicted changes and fails on each planted deviation; D14 lists every disposition; template `@@sha256` pins, generated-oracle censuses + mutation anchors updated by the contract.
- P9 corpus: CDC `vocabulary.tsv`; 337 documents + 6 questions recompiled (bytes from the first `% S` equal), answers + traces re-derived (custody hashes only), review-manifest re-derived (v2/v3-era documents change digest through the version line), release-manifest regenerated; `ckc certify cdc-2022-opioid` green.
- P10 gates + harness: `just gate` green on the closing committed tree (Verus `--no-cheating` 0 errors 0 warnings, trust-audit re-pinned, tests, check, certify; HEAD-cloning replays — check-mutants, dist — run after the commit); `.agent/archive/generators/replay` + `certify-one-fixtures` byte-identical; Kani harness constants (DOC, QUERIES, QUERY_SHA256, ANSWERS + answers digest, the goal byte offset, the `unwind` bounds) migrated together and checked by a native test (hashes, offset, lengths), `just kani` (its declared three harnesses) green once; the deferred engine/trace harnesses stay deferred.

## Rulings (during the unit)

- R1 (D4, tester-2 G1): "one pinned message" = one refusal per reader in that reader's own error frame, rc ≠ 0, naming `temporal.tsv`, nothing derived: `ckc check`/`compile`/`queries` `ckc: guideline: retired table name: <path> (rename to vocabulary.tsv)` (rc 2), `ckc release-manifest` + `dist build` `ckc: dist: retired table name: <path> (rename to vocabulary.tsv)` (rc 1, the HEAD tree's entry), `ckc certify` `retired_table(temporal.tsv)`, UI intake `ui: viewmodel: <gid> temporal.tsv: retired table name (rename to vocabulary.tsv)`; a dangling `temporal.tsv` symlink counts (reviewer-2 F1).
- R2 (D4, tester-2 G3): regular-file + UTF-8 laws keep today's texts with the name renamed (`ckc: guideline: vocabulary.tsv is not a regular file: <path>`; UI file-level checks `file not UTF-8` / `unsupported control U+NNNN` ahead of the grammar).
- R3 (D5, tester-2 G2): beyond `vocabulary_arg(proof)`, `ulex_arg(proof)` and the leading-schema-word `argv(_)`, every invalid vector's detail = `argv(<the vector>)`, pinned by the tests/red `usage--*` probes (tokens other than the tree, so no stage path leaks into a pin); an unreadable table pins as `vocabulary_load, unserializable` (its I/O error holds a stream handle).
- R4 (P1, tester-1 A12/A13): R9 offsets are uniform over the 13 semantic predicates (a wrong arity diverges at the closing paren or the extra comma, as the annotation predicates already did) and a byte past a canonical query, answers or traces file diverges where it starts; both pre-C1 deviations from the R9 definition, fixed here.
- R5 (D13, tester-4): non-mechanical churn = rows of `.agent/archive/migrations/c1-churn-rulings.tsv` (family, item, path, old, new, count, reason[, base_sha256]; Python bytes escapes; `@whole` | `@new`; `order:` reasons for annotation additions) over the oracle's own mechanical prediction; a missing ruling fails.
- R6 (D12): loose UI pseudo-documents (no line-1 comment, no declaration block) stay byte-identical; q18 seeds are rebuilt from D2/D3 by the census (tester-1), never migrated.

## Out of scope

Strength (S1), hedges (S2); any new typed shape; widening the no-table question law; the published-version policy (first publication).

## Gate identities

`just gate` (`just rust` + `just check` + `just certify`); tests/v1, red, green, certify, check-mutants, queries, ui, dist, certify-one replays inside it; diff-blind tester suite from this contract at the seed commit, red at seed, green at merge; D13 oracle; `just kani` once.

## Flow

Seed `wt/c1` (contract + spec) → tester-1 (diff-blind) → kernel to the new spec (codec + table slice first, pairwise declaration construction kept; no rlimit raised) → certification + composition + UI + release → fork compiler → shell → D12/D13/D14 (disposition map → user approval of the deletion set) → corpus → REFERENCE + rules + README → reviewer per kernel diff + closing review → commit, then HEAD-cloning replays + `just gate` on the committed tree → squash to main. Close ticks C1, archives this contract, rewrites Decisions/Artifacts to the consolidated law.
