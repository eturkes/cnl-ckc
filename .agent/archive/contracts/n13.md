# N13 — tools.lock row bump script (contract; archived at unit close)

Row = refresh find (fddc538d; the user-ruled scripting U2 covered crate, Verus + Kani bumps): `rust.md`'s tool bump = a hand-edited `rust/tools.lock` row → `just tools` → `just rust`, while global `CLAUDE.md` `Authoring` puts a multi-step recipe in a committed script the rule names. Accept: `just bump-tool <tool> <version>` rewrites that row from upstream release data; run on each current row (rustup-init, just, verusfmt, cargo-deny, gitleaks, zizmor, cargo-mutants) it leaves `rust/tools.lock` byte-identical; `rust.md` names it.

## Design

- D1 row derivation: a GitHub row → repo + tag from its URL (`https://github.com/<owner>/<repo>/releases/download/<tag>/<asset>`); new tag = the tag with its trailing old version swapped for `<version>`, new asset = the asset name with each old-version occurrence swapped; sha256 = the release API asset `digest`; URL = its `browser_download_url`. rustup-init → the archive URL with its version segment swapped; sha256 = the first field of the published `<url>.sha256`.
- D2 fail-closed before the row changes: an unknown tool, a URL outside both sources, a tag not ending in the old version, a missing release/asset/digest, a download whose sha256 differs → nonzero rc, `tools.lock` untouched. The verified download lands in the toolchain's `dl/`, the cache `just tools` reuses after its own sha256 check.
- D3 then `just tools` installs the row (pin binding reinstalls).
- D4 `rust.md` names it in the dependency bullet's tool-bump clause; spec `Artifacts` lists it.

## Tier

shell (tooling); shallow ⇒ MAIN alone + self-review. N14 ports a mocked fail-closed check into the gate.

## Predicates (acceptance = the row's check)

- P1 each current row: `just bump-tool <tool> <its version>` rc 0, `rust/tools.lock` cmp-equal to HEAD (seven rows).
- P2 history: `just bump-tool verusfmt 0.7.2` + `just bump-tool rustup-init 1.29.0` → those rows byte-equal to `git show 67fcdcd0^:rust/tools.lock`'s; back to 0.7.4 + 1.29.1 → cmp-equal to HEAD.
- P3 failure: an unknown tool and an absent upstream version → nonzero rc, `tools.lock` cmp-equal to HEAD.
- P4 `rust.md` + spec name it; full `just gate` green at the unit commit.
