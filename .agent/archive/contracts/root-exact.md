# root-exact — exact values in ACE root facts (contract; archived at unit close)

Row = fidelity-leads review find (`.agent/deferred.md` exact-root row); user ruling (AskUserQuestion, this session): "Compiler change" — admit `exactly N` in root facts as data, then re-author the corpus sentences. Today the compiler (`v1_tag_condition`, last clause) + the emission spec (`emit.rs` `tag` → `tags` None → `root_condition`) reject every root condition that is a list. APE delivers an upper-bounded quantifier (`exactly`, `at most`, `less than`) as a nested list holding the conditions in its scope (measured: `A scheduled-opioid-example uses exactly 1 tablet at an interval of exactly 4 hours.` → `[modifier_pp, predicate(use), [relation(of), object(hour,…,exactly,4)], object(interval,…,eq,1), object(tablet,…,exactly,1)]`). The schema + engine already carry exact values as data (REFERENCE § Comparison conditions: a measured patient value takes `exactly`; rule heads + questions already flatten these lists).

## Tier

`kernel`: fork (`vendor/ape/prolog/ace_to_pl.pl`, document mode) + human-read spec (`ckc-spec/src/emit.rs` root tagging) + AI-authored kernel exec mirror + proofs (`ckc-kernel` M6 root tagging) + certification; corpus re-authoring rides it (data). ## Design

- D1 Admission (one law, fork + spec): a root condition that is a nonempty proper list is an *exact group* iff (a) every `object/6` among its root-context anchored leaves — reached through list spines alone (nested lists included), never descending into an operator box, NAF, rule or disjunction, whose own law the flatten keeps — whose comparison is `exactly`, `leq` or `less` has comparison `exactly` and an integer count ≥ 1, (b) at least one such `exactly` leaf occurs, and (c) the whole group's anchors (nested constructs included: `inner_sentence`) name one sentence. An exact group is tagged like an operator box (fork `boxed(List)`, spec + kernel `Root::Boxed(c)`) and joins its sentence's root fact cluster; the existing flatten (fork `v1_flatten_cond` list clause, spec `flatten_list`) turns its members into ordinary root items in order, an inner operator box into its usual edge + payload. Why `exactly` alone: `exactly N` (N ≥ 1) implies the counted things exist, so asserting the scope's conditions is sound; `at most N` / `less than N` / `exactly 0` admit zero ⇒ keep `root_condition` (red probe `unsupported--v1-root-at-most`, nt1-surface `root-leq` / `root-less` unchanged), as does a root-context list mixing `exactly` with `leq` / `less` (`A man sees exactly 2 dogs that chase at most 3 cats.`). Admission is a gate, not a semantic operator: an admitted group's disjunction, scoped rule, NAF placement, unsupported relation leaf, approximate exact bound or asserted attenuating adverb still rejects downstream.
- D2 Output: flattened primitives emit through the existing fact pipeline in their retained contexts (root facts keep literals as data: `guideline_cardinality(actual,R,na,exactly,N)`); time patterns consume their recognized `of` links and emit their annotations + `guideline_unit`; every unrecognized relation leaf still rejects; the strength pass runs unchanged on the flattened items; the exact-list wrapper adds no context edge, no box ordinal and no comparison built-in.
- D3 Certification: `ckc certify` re-derives such documents through the amended `project` (spec) = kernel exec; an emitted `exactly` changed to `eq`, or its count changed (source + custody fields unchanged), fails certification at that sentence's clauses.
- D4 Rules + docs: REFERENCE § Compiled Prolog schema upper-bound paragraph (~359–369: the root rule + the false "inside a rule or box carries no group" → nested groups flatten inside their context) + § Comparison conditions root-fact sentence (~904–906) state the new law (an exact positive count states at an asserted root; `at most` / `less than` / `exactly 0` at the root reject because they admit zero; operator contexts + table-gated question lists unchanged); compiler header + `compiler.md` + `corpus.md` (authoring: an exact source value in a root fact → `exactly N`). The archived nt1 contract stays historical.
- D5 Corpus (the row's sentences): rec01-imp03 S2 + s22-05 S3 `… contains exactly 5 hydrocodone-milligrams and contains exactly 325 acetaminophen-milligrams and uses exactly 1 tablet at an interval of at least 4 hours for a moderate-to-severe-pain.`; rec01-imp03 S3 + s22-05 S4 `A scheduled-opioid-example uses exactly 1 tablet at an interval of exactly 4 hours.`; s30-07 S2 `A medication-combination-example includes exactly 2 nonopioid-medications that differ in a mechanism-of-action.`; notes (the plain-count clause → exact values), align tables, review manifest, `just amend-manifest`; the demo query tablet-use-spacing asks `What uses exactly 1 tablet at an interval of at least 4 hours?` (a plain-number question condition matches `eq` facts structurally (nt1), so `1 tablet` no longer meets `exactly 1`; `exactly 1` compares by value) → 4 solutions.

## Predicates
