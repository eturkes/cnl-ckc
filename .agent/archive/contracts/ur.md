D3 Reading rows of a table (`vocabulary::parse_vocabulary` = `Ok(t)`), in this order, each kind in file order: strength rows, evidence rows, preference rows, alternative rows, qualifier rows, the scope row, the exclusion row. Reading `R` of a row (fixed copy; kind words = the user-ruled qualifier labels, today's registry rows):

- qualifier `usuality` | `ideality` | `focus` | `manner` | `force` | `possibility` | `applicability` → `a qualifier: ` + `How often` | `Best case` | `Emphasis` | `Manner` | `Strength of wording` | `Possibility` | `Condition of use`;

- exclusion → `the verb of a scope exclusion: when its condition holds, no recommendation of this guideline applies to the patient` (user-approved plain-language copy for the CS1 gate, which blocks the should, must and may edges of the guideline; `can` edges and plain data still derive — REFERENCE § Scope exclusions states the exact law).
The reading of a lemma `L` = `R` of the first reading row (this order) whose lemma is `L`. A lemma renders as text only when its bytes stand verbatim in the table bytes (`pl_word` law; always true for a parsed table, which keeps the proof local).

D4 Word meanings (guideline page): when the guideline has a table that parses and holds ≥ 1 reading row: `<section>`, `<h2>Word meanings</h2>`, the paragraph `<p>The compiler reads each word in this table as shown, in every document of this guideline. No table, a table without reading rows → no section (a table that fails to parse never reaches the renderer: intake, D2).

D5 Reading words (document page). Domain: the guideline has a table `t` that parses; the document's ACE bytes are valid UTF-8 (intake guarantees it); otherwise the page has no reading word.
- Tokens: the function-word scan of today's ACE rendering, over characters: from position `i`, a token starts at an ASCII letter or digit and extends over ASCII letters and digits and over each hyphen followed by an ASCII letter or digit; any other character is skipped alone. Tokens never contain a line feed.
- Exclusion sentence (scope pair only): `t` holds the scope pair with key `K`; the document's Prolog parses as a canonical document (`v1text::accepts` + `replay::the_v1` = `V1File::Doc`); a bundle with sentence number `s` holds ≥ 1 clause whose head is `guideline_exclusion(K)` (`emit::exclusion_record(K)`, `K` the scope row's key); the `s`-th nonempty LF-delimited line of the ACE bytes (`emit::nonempty_lines`, the certification line law) exists and equals the bundle's sentence text. That line = an exclusion sentence. A record keyed to another key, a sentence comment that differs from its line, a Prolog file that does not parse → no exclusion sentence (the other reading words stay).
- A token with bytes `w` is a reading word with lemma `L` when, first match wins: `w` equals the lemma of a strength, evidence, preference, alternative or qualifier row (`L = w`, anywhere in the text); inside an exclusion sentence, `w` equals the scope noun (`L = w`); inside an exclusion sentence, `w` equals the exclusion verb `V`, `V + "s"`, `V + "es"`, or — when `V` ends in `y` — `V` without its last byte `+ "ies"` (`L = V`; these spelled forms are display lookups for the table lemma `V`, not a claim that the token compiled with lemma `V`: an irregular form gets no reading, and the line names `V`, never the token). A token matches a lemma byte for byte only: `Usually` ≠ `usually`, `category-A-recommendations` ≠ `category-A-recommendation` (uppercase bytes inside a lemma, as in `category-A-recommendation`, match themselves); a token that merely contains a lemma (`first-line-therapy` ≠ `first-line`) never matches.
- Rendering (ACE section only; the passage never carries reading words): a page with ≥ 1 reading word renders the ACE text as pieces split at the reading words: the text before, between and after the words renders as today's highlight rendering of that piece (marks clipped to the piece, function-word spans on unmarked text); each reading word renders as `<button type="button" class="rw" aria-pressed="false" data-w="` + `L` (attribute-escaped) + `">` + the highlight rendering of the word's own characters + `</button>`. Clipping: for a piece `[a, b)` each mark `[s, e)` (alignment order) clips to `lo = max(s, a)`, `hi = min(e, b)` and renders inside the piece over `[lo, hi)` iff `lo < hi`, with its group class (`t<index>` below 48, a bare `<mark>` otherwise); a piece with `a = b` renders nothing. A mark that crosses a word boundary therefore renders as one mark element on each side of the boundary, same group; a mark inside a word renders inside its button; a word inside a mark renders between two parts of that mark. Function words inside a piece render as today (`<span class="kw">` outside marks).
- A page with no reading word renders its ACE section byte-identical to today (same function, same branch).

D6 Reserved line: a page with ≥ 1 reading word holds, on the line after the ACE `</pre>` and before the ACE `</section>`, `<p class="reading" aria-live="polite">` + `<span data-w="">Select a word with a solid underline to see how the compiler reads it.</span>` + for each distinct lemma in first-occurrence order `<span data-w="` + `L` (attribute-escaped) + `" hidden>In this guideline, the compiler reads ` + `L` (text) + ` as ` + the reading of `L` (D3) + `.</span>` + `</p>`. ## UI design plan

Within the approved design system; no new color or face.
- Colors: text `#111827`, link + cue `#1d4ed8`, muted hint `#4b5563`, rules `#e5e7eb`; marks keep their twelve tints.

```

+--------------------------------------------------------------+
| A recommendation is a category-B-recommendation and is an     |
|                       _________________________ (1px cue)     |
| evidence-type-3-recommendation.                               |
| ______________________________                                |
+--------------------------------------------------------------+
Select a word with a solid underline to see how the compiler reads it.   (muted)
→ after a click: In this guideline, the compiler reads category-B-recommendation as a
  conditional recommendation.                       (the word's cue: 3px)
```

- Principles: one quiet cue (the link underline already means "select"); state = thickness + `aria-pressed`, never color alone; no motion; a selection keeps the ACE box still (the line below it reserves one line and may grow for a long reading); print hides the line + cue (the guideline page's table prints the full mapping).
