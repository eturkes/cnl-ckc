# Q7 — K3 negation certificate = the call-time instance (contract)

Defect (review R-14 / CL-09; `.agent/deferred.md` K3 row): `node_valid` (`rust/ckc-spec/src/trace.rs`) accepts a naf leaf whose frozen payload `t` is ANY finitely failing generalization of the site goal (`exists s. apply(t, s) == apply(args[0], th)`). Finite failure is not closed under instantiation once the called program negates: db `p(b). q(X) :- \+ p(X). r(c) :- \+ q(a).` → `forest_valid(db, r(c), [Clause(r-rule, [Naf(q(X))])])` holds (th = [], s = [X→a]) while q(a) is provable.

Row acceptance: node_valid requires the payload to be the call-time instance (or k3_sound gains a safe-negation hypothesis), `k3_sound` re-verified under `--no-cheating`, and the counterexample forest rejected by an executable probe.

## Tier

kernel — judgment-bearing spec (trace.rs) + kernel proofs; full battery: contract-first, diff-blind `tester`, 2 blind `reviewer`s on the kernel diff, Verus `--no-cheating`, `just gate`.

## Design (MAIN ruling, plan P7)

- Call-time instance = exact: a naf leaf's payload must EQUAL the site goal under the forest's answer substitution `th`. That equality holds for a derived forest iff no later binding touches a free variable of the call — the call is safe.
- Safe call: no variable of the negated goal occurs in any goal of the rest of its own search level (the stack up to the next naf cut; a deeper level's bindings are discarded, and a safe outer call keeps its inner level's variables apart from the outer rest, so this equals the whole-stack test on every reachable state). Free variables that occur only inside the negation stay legal (box-local existentials: the corpus emits `\+ (guideline_entity(actual,B,…), guideline_arg(actual,C,1,A), …)` with A bound and B, C local).
- Unsafe call: the trace machine cuts that branch exactly like an exhausted depth bound (prune flag set, search continues); a row whose every proof needs an unsafe call ends `unproved(limit)`. No new result atom, no artifact grammar change.
- K2 (answer engine) unchanged (legacy SWI `\+` parity; out of this row's scope) → register entry + deferred row candidate: K2 still answers through unsafe negation.

## Predicates (acceptance)

- P1 spec relation: `node_valid` naf case = `name == naf_name() && args.len() == 1 && t == apply(args[0], th) && naf_fails(db, t)`; the comment states the certificate = finite failure of the goal exactly as called.
- P2 spec machine: new `naf_safe(inner: Term, rest: Seq<TGoal>) -> bool` = no variable of `inner` occurs in `tgoal_term(rest[i])` for any i before the first naf cut of `rest` (`shares` = some variable occurs in both terms); `tstep` naf branch: `!naf_safe(args[0], rest)` → `tfail(TCfg { pruned: true, ..c })`, else the existing frame push.
- P3 theorem: `contract::k3_sound` statement unchanged (requires `bodies_wf(db)`, `goal_walk(goal) is None`, `derived_forest(db, goal) is Some`; ensures `forest_valid`), verified against P1 + P2 under `--no-cheating`; no new hypothesis.
- P4 executable probe: binding `ckc_kernel::contract::k3_naf_counterexample() -> (rejected: bool)` with `ensures rejected ==> !forest_valid(cx_db(), cx_lit(atom("c"), "r"), cx_forest())` (witness = `trace.rs` § R-14 regression witness); its kernel exec body builds the counterexample's site goal `q(a)` and naf payload `q(X)` (canonical v1 vocabulary) and evaluates the P1 leaf equality on them: a ground site never equals a nonground payload under any `th` (`site ground ∧ payload nonground`, exec `ground_root` ×2), so the leaf — and with it the forest — fails P1 for every `th`, `naf_fails` included or not; the `ensures` binds `true` to `!forest_valid` of the exact R-14 forest. A committed cargo test asserts `true`. Red on the unfixed spec = the same ensures fails verification against the old relation (old relation admits the leaf with s = [X→a]).

(a), (b), (d) red on the unfixed binary; (c) green on both.
