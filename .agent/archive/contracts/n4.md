# N4 — release manifest keyed on input content (contract; user-approved O1; archived at unit close)

Row = `.agent/deferred.md` "Release manifest keyed on input content". Defect: `release-manifest.tsv` row `meta head` = the last commit touching a release input (`rust/ckc/src/check/pipeline_release.rs` `derive`: `git log -1 HEAD -- guidelines vendor/ape/prolog/ace_to_pl.pl vendor/clex/clex_lexicon.pl`); a commit's id hashes its manifest ⇒ no commit touching an input can name itself ⇒ `ckc check` manifest freshness + `dist_cases` d07 read red at it until a manifest-only follow-up commit. Every other manifest row = HEAD content.

## Design (O1)

- Trusted spec `rust/ckc-spec/src/release.rs`: `meta_block(compiler, lexicon)` = the current block minus the `meta\thead\t<head>\n` line; `release_manifest(compiler, lexicon, staged, profiles, urls, labels, tags)` (no `head`).
- Kernel: `release_rows::meta(compiler, lexicon)`, `release_impl::release_manifest_impl` + binding `contract.rs::release_manifest` drop `head`; Verus `--no-cheating` proves them against the new spec.
- Shell `derive`: the input head stays = archive name + bag root `cnl-ckc-kb-g<head12>` (root directory inside the tar) + epoch (its committer time); it no longer reaches the manifest. README-dist prose names the archive name and its root directory as the source-commit record.
- Workflow: a commit that changes release inputs carries its own manifest = commit → `ckc release-manifest` → `git commit --amend` (fixed point: the manifest reads HEAD content only, never itself). Docs + rules follow (`docs/REFERENCE.md` § Operating step 5 + § Export, `README.md`, `.claude/rules/{ops,corpus,upstream-sync}.md`).
- `release-manifest.tsv` regenerated inside the unit commit.

## Tier

kernel: trusted spec + kernel + binding ⇒ diff-blind `tester` (red suite from this contract + an independent manifest oracle) + `reviewer` on the kernel diff before commit.

## Predicates (acceptance = the row's check)

- P1 one commit carries changed release inputs + their regenerated manifest and passes `ckc check`'s dist section at its own SHA: new `dist_cases` case (fixture repo: input change committed → `ckc release-manifest` → amend → `ckc check` passes the dist section, ending at the missing-swipl stop as d07 does); red on the unfixed binary (`release manifest stale`).
- P2 the export names its source state: archive name + bag root = `cnl-ckc-kb-g<input-head12>` (a01 checks kept).

- P4 manifest bytes = spec: no `meta\thead` row; every other row byte-identical to the unfixed derivation of the same tree (live repo + dist_cases fixtures), except the `README-dist.md` member row (its prose stops naming `meta head`).
