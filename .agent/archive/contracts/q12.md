## Design

D1 Version + table. Schema v3 = v2 + this contract; every v1 + v2 byte, reject and committed case stays unchanged. The `temporal.tsv` header selects the version: the v2 header → schema v2 exactly as today; the v3 header → schema v3. v3 header = 2 pinned lines: `# format: kind<TAB>lemma<TAB>value` + `# kind: unit (value: second|minute|hour|day|week|month|year) | relation (value: duration|within|after|before) | spacing (value: frame noun lemma) | window (value: frame noun lemma) | frequency (value: period) | approximation (value: about) | range (value: minimum)`. v3 rows (Q12) = v2 kinds + `window<TAB>P<TAB>F` (preposition + frame noun of a scoped recurrence) + `frequency<TAB>P<TAB>period`; the header names `approximation` + `range` (frozen bytes) but their rows reject `kind at row N` until Q13 adds them to the grammar. Row law = v2's + a preposition occurs in at most one `frequency` row and never in a `relation` row; a (P, F) pair occurs in at most one `spacing` or `window` row (not both); a window frame noun is never a unit lemma. Violations reject in `ckc check` + `ckc compile` with pinned messages (v2 messages unchanged). Compiler argv `v3 <tree> <docid> <temporal.tsv> [<ulex>] [proof]` + `question v3 <tree> <qid> <temporal.tsv> [<ulex>]`; a v3 table under `v2` argv, or a v2 table under `v3` argv, fails `temporal_load` (exit 2). The shell selects the argv from the header.
D2 ABI. v3 document = header `guideline_schema_version(3).` + record `guideline_document/4` (v2 shape; temporal digest = sha256 of the raw v3 table) + declaration block = v2's 11 indicators then `guideline_frequency/5`, `guideline_order/4`, `guideline_recurrence_window/7`, `guideline_range/3` (15). v3 comparison domain = v1's + `about` (produced from Q13). v3 question record `'$guideline_query'(v3, QId, ace_sha256(H), ulex(none|sha256(H)), temporal(sha256(T)))`. A v1/v2 document carries no v3 indicator (per-version indicator law). Reader comparison grammar stays as published (no value narrowing): the guarantee that `about` appears only in v3 = v1/v2 compile + certify never produce or certify it (consultant C8). In Q12 no compile produces `about` at all: a hand-edited corpus pl carrying it fails `just check`'s fresh compile + `git diff --quiet -- guidelines/` and `ckc certify`.
D3 Referent classification. A v3 pattern classifies a referent R by R's `object/6` condition anywhere in the document DRS (every sentence and box: antecedent, consequent, operator, NAF): APE builds one DRS per text, introduces each discourse referent by exactly one condition and resolves every reference — within a sentence or across sentences, as v1 already compiles (probe: `after the therapy-start` in sentence 2 → pp object = sentence 1's ref) — to an accessible referent, so variable identity (`==`) finds the declaration without a box walk. R must be a DRS variable with an `object/6` condition; anything else (a non-variable such as `int(3,d)`, an event) never classifies. Group referents never reach a pattern: their `has_part` conditions reject `condition_shape` (probed). Class = time quantity (noun = a unit lemma), frame (noun = a spacing or window frame lemma), or plain (any other noun). v2 patterns keep their same-context lookups unchanged.
D4 Order. A `modifier_pp(E, P, X)` that no interval/recurrence/window/frequency pattern claims, whose P is a `relation` lemma with role before|after and whose X classifies plain (D3) → `guideline_order(Ctx, E, Role, X)` right after the pp. X unclassifiable (no accessible object, non-variable) → plain pp, as v2. Pattern priority: interval + spacing first with their v2 rejects (a claimed time quantity or frame never gains order). Order never rejects. Denotation: each occurrence of Event lies before (after) the reference referent; no metric bound, no inferred start/end point, no immediacy.
D5 Frequency. A `modifier_pp(E, P, W)` with P a `frequency` lemma and W a same-context time quantity → `guideline_frequency(Ctx, E, C, W, Unit)` right after the pp, where C = the second participant of E = the 4th argument of E's same-context `predicate/4|5` condition. W: v2 bound rules + comparison `eq` + no of-link. C: a variable classifying plain whose accessible object is `countable`, unit `na`, comparison ≠ `na`, count ≥ 1. P with a non-quantity object → plain pp (not a candidate). Rejects `temporal_shape(frequency_shape, S)`: no same-context `predicate/4|5` for E, C fails its bound, W comparison ≠ eq, W anchored. W and C are claims (exclusive; reuse → `shared_quantity`). Denotation: the stated count (C's comparison + count) of C's items (C's noun) per stated period (W's count + Unit); no calendar bucket, sliding window, phase, minimum gap or first occurrence follows.
D6 Scoped recurrence. A `modifier_pp(E, P, F)` with (P, noun(F)) a `window` pair: F frame-shaped (countable, na, eq, 1), exactly one same-context of-link F→L with L a same-context time quantity (v2 bound rules), exactly one same-context of-link L→A with A classifying plain (D3). E must carry ≥ 1 recurrence (spacing) match in the same scope; each such recurrence emits `guideline_recurrence_window(Ctx, E, Q, QUnit, A, L, LUnit)` right after its own pp in place of `guideline_recurrence` (a scoped event carries no unscoped recurrence). Of-links F→L and L→A are consumed; every other primitive stays as v1 emits it. Rejects `temporal_shape(window_shape, S)`: F not frame-shaped, link counts ≠ 1, L not a quantity, A not plain, E without a recurrence, two window pps on one E. F, L are claims. Denotation: for each pair of consecutive occurrences of Event that both lie inside the window — from the reference point A for L's comparison + count of LUnit — the gap satisfies Q's comparison + count of QUnit; the window supplies no first occurrence and says nothing about occurrences outside it.
D7 Reject order. v2's order (pp annotations left to right, then shared claims, then NAF scopes); window + frequency checks run at their own pp in that left-to-right pass; the window's recurrence requirement runs after the pass (first violation in item order).
D8 Measurement nouns (probe conclusion; no schema change). APE: bare `for 3 d` → `modifier_pp(C,for,int(3,d))` → compile rejects `unresolved_argument`; `for at most 3 d` → parse error; `3 d of <noun>` → measured object (unit in the cardinality Unit field) → compiles untyped. A corpus ulex count noun (`noun_sg(d,d,neutr)` + `noun_pl(d,d,neutr)`) + a table row `unit d day` type `for at most 3 d` and `within 3 d of a X` as ordinary intervals (data only). Native measured terms stay unsupported.
D9 Questions. v3 question law = v2 law + D3–D6 over the flattened goal items (same patterns + rejects). Version matrix: empty composition → v1/v2/v3 queries; v1 → v1; v2 → v1, v2; v3 → v1, v2, v3; mixed → reject (pinned details). Goal whitelist by query version (v3 = v2's 9 + the 4 v3 predicates). Answers/traces artifact formats unchanged.
D10 Certification. emit.rs v3 projection = v2 projection + D3–D6 re-derived from the DRS + the raw v3 table; certify_doc/certify_query v3 bind the v3 record + digest. `about` and `guideline_range/3` are never derived in Q12 ⇒ a document carrying them fails certification until Q13 (reserved).
D11 UI (K5). The timing table (m7t D10) renders v3 documents; v1/v2 pages stay byte-identical. v3 rows: order — Timing `before` | `after`, Reference point = anchor noun; frequency — Timing `<cmp>N per <count><unit>, counted item: ` + C's noun, Reference point empty; scoped recurrence — Timing `repeats <cmp>N<unit> apart during <cmp>M<unit> from`, Reference point = A's noun. Reserved shapes render no row (`guideline_range/3`) or `not stated` (an `about` comparison, as any unknown comparison today). Words via `pl_word` (verbatim pl spans), fixed strings appended to the copy table, decimals canonical; unit words singular iff the count is 1. Time words (q14): v3 tables list window + frequency rows with plain-language explanations, and a v3 table's before/after explanation covers both the timed and the unquantified reading; v2 tables keep today's bytes.
D12 Corpus. `guidelines/cdc-2022-opioid/temporal.tsv` → v3 header + v2 rows + `window during window` + `frequency per period`; `lexicon.ulex` + `prep(per, per)` (+ nouns the re-authoring needs). Every document + question recompiles under v3 (reported: header-only, gained order/frequency/window annotations without an ACE change, re-authored). s60-14 re-authored with the example kept as an example (source: "temporarily increasing the buprenorphine dosing frequency (e.g., to twice per day)") using a counted-administration frequency; s44-04 re-authored with a scoped recurrence anchored on the methadone start/increase; their align + projection-notes rows updated; `ckc certify cdc-2022-opioid` green; queries re-derived (churn diffed + explained); review-manifest + release-manifest regenerated.
