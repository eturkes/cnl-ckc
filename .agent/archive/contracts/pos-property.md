# pos-property — one positive-property lookup per layer (contract; archived at unit close)

Row = S1 review find (reviewer-5 F2): the approximation marker (q13 D3) and the preference adjective (s1 D4) are one lookup — a same-context `property(X, A, pos)` item whose adjective A is in a table lemma list — written twice in each layer: spec `rust/ckc-spec/src/emit.rs` `approximate` (tab.approximations) + `preferred_prop` (tab.preferences); kernel `m7_q12.rs` `approximate_exec` + `m7_strength.rs` `preferred_prop`; compiler `vendor/ape/prolog/ace_to_pl.pl` `v3_approximate` (member + cut) + `s1_preferred_prop` (if-then-else recursion). Accept (the row's): one lookup parameterized by the lemma set in each layer (named wrappers allowed), Verus `--no-cheating` 0/0, `ckc certify` + suites green, byte-identical corpus.

## Tier

`kernel`: human-read spec (`emit.rs`, the M6 emission correspondence) + uninspected kernel impl + proofs (`m7_q12`, `m7_strength`, their callers' proofs that unfold the lookups) + the fork's emitter (`ace_to_pl.pl`, a release input). The corpus, certification and suites detect exercised behavioral changes (certification checks against a spec edited in the same unit, so it cannot catch every regression alone); D1's exact extraction, the tester's discriminating cases and review carry the wider preservation claim; the refactor itself carries no new semantics.

## Design

- D1 Spec: `pub open spec fn pos_property(lemmas: Seq<Seq<u8>>, items: Seq<Item>, ctx: Term, x: Term) -> bool` = the current recursion with `lemmas.contains(name_of(arg(inner, 1)))`; `approximate(tab, items, ctx, r)` = `pos_property(tab.approximations, items, ctx, r)`, `preferred_prop(tab, items, ctx, p)` = `pos_property(tab.preferences, items, ctx, p)` (named wrappers; every call site unchanged).
- D2 Kernel: one exec `pos_property_exec(arena, lemmas: &Vec<Vec<u8>>, items, ctx, x) -> (out: bool)` ensuring `out == spec::pos_property(crate::m7_temporal::lemmas_view(lemmas@), item_models(items@), ctx@, x@)` under the current arena / item / context / referent validity preconditions (no added atom-only guard or nonempty-lemma precondition: `name_of` / `atom_bytes` of a non-atom = empty bytes, kept); the loop + its two recursive-fuel reveals move into it (beside `preferred_prop` in `m7_strength.rs`, which already imports m7_q12 helpers); `approximate_exec` + `preferred_prop` stay as named wrappers with their current ensures, so `approx_why_exec`, `range_ann_exec`, `eq_approx_exec` + `preference_of` keep their call contracts.
- D3 Compiler: one predicate `pos_property(Lemmas, Items, Ctx, X)` (deterministic: first match, then cut) with the union of the current guards, the cut after every guard (a cut on item selection would fail a late match) — item `anchored(C, Inner)` nonvar via `s1_anchored`, `C == Ctx`, `Inner` = `property/3`, arg 1 `== X` (read via `arg/3` + `==`, never binding a referent), arg 3 `== pos`, arg 2 an atom in `Lemmas` (`memberchk`); input mode = today's: ground lemma lists built from the table bytes, finite scope lists; `v3_approximate(T, Scope, Ctx, R)` = one clause `T = t(_, _, _, _, _, Ap, _), pos_property(Ap, Scope, Ctx, R)`; `s1_preferred_prop(Items, Prefs, Ctx, P)` = one clause `pos_property(Prefs, Items, Ctx, P)` (both names stay as wrappers: call sites unchanged, and direct probes address the same predicates before and after). Truth value per call = today's (both current forms are deterministic boolean tests; `v3_approximate` ends in a cut; its callers' disjunction / negation / if-then-else contexts see the same success set).
- D4 Unchanged: every compiled document, question, answer, trace, review manifest + existing fixture byte; the fork notice (write-once date kept); every existing theorem + exec entrypoint contract (the new helper gains its own); certification verdicts. Changed by intent, nothing else: the release manifest's compiler-digest row (the fork file's bytes change: commit, then `just amend-manifest`) + the `spec-manifest.tsv` emit.rs row (trusted surface, re-pinned after final formatting); both diffs inspected.
