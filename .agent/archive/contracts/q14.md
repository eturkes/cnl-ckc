## Design

D1 Model. `Guideline.temporal: Option<Bytes>` = the raw bytes of the committed `guidelines/<gid>/temporal.tsv`, `None` when absent; `EGuideline.temporal: Option<Vec<u8>>` + view. `corpus_bytes` (and the kernel's `k5_sound_corpus::inputs`) append the table bytes as one more input after the documents, so table words are copied corpus spans.
D2 Placement. `guideline_html` = Status section, then `words_section(g.temporal)`, then Documents + Passages without ACE (the Documents table runs to hundreds of rows; the word list stays above it). `words_section` is empty unless the table is present and `temporal::parse_temporal` accepts it ⇒ the guideline page of a guideline without `temporal.tsv`, and every index, records, document + source page, stay byte-identical.
D3 Bytes. Section lines (joined by the page's `\n`, like the other guideline sections):
```
<section>
<h2>Time words</h2>
<p>The compiler reads a time limit from the ACE text only through the words in this table. The table applies to every document in this guideline. Each time limit that the compiler read appears on its document page under Timing as compiled.</p>
<table class="compact">
<thead><tr><th>Word</th><th>Read as</th></tr></thead>
<tbody><tr>…</tr>
<tr>…</tr></tbody>
</table>
</section>
```
Rows = every `unit` row, then every `relation` row, then every `spacing` row, each kind in file order (the parsed `Temporal` lists), one `<tr><td>A</td><td>B</td></tr>` each:
  - unit (L, U): A = word(L); B = `unit of time:` + the singular unit word of the timing table (` second` … ` year`, the `unit_html(U, true)` copy) → `unit of time: hour`.
  - relation (P, R): A = word(P); B by role: duration `how long the action lasts`; within `how far the action lies from a reference point, before or after it`; after `how long after a reference point the action occurs`; before `how long before a reference point the action occurs`.
  - spacing (P, F): A = word(P) + ` (` + `with ` + word(F) + `)` → `at (with interval)`; B = `how far apart repeats of the action lie`.
  - word(w) = `pl_word(raw, w)`: the escaped word when its bytes occur in the table bytes, else `not stated` (MAIN ruling: the D10 provenance device — dead for an accepted table, it makes each slot a copied span by construction). A unit or role id outside the parse grammar (unreachable) renders `not stated`.
D4 Copy. Appended at the copy-table end (indices 276–285, in this order): `<h2>Time words</h2>`; the intro `<p>…</p>` of D3; `<thead><tr><th>Word</th><th>Read as</th></tr></thead>`; `unit of time:`; the four role phrases (duration, within, after, before); `how far apart repeats of the action lie`; `with `. Reused entries: section/table/tbody chrome, `table_open_2` (`compact`), ` (`, `)`, `not stated`, the singular unit words. Every new entry passes the copy register (K5 `copy_ok`); the archived k5-sound generators assert the new table size (286) and replay `identical`.
D5 Proof shape. The row list is a `#[verifier::opaque]` spec fn (as `u::timing_rows`): unhidden, the temporal grammar would enter every guideline-page query. Kernel exec renders through `m7_temporal::parse_temporal_exec`; theorems re-verified: `page` (`out@ == u::guideline_html(g@)`), `guideline_sound_proof` (well-escaped + visible bytes from corpus + registry), `copy_ok`.
D6 Intake (shell). `guidelines/<gid>/temporal.tsv` read when `is_file()` (the align-file rule), through `load_text` (UTF-8 + control refusals as for every intake file), then validated by the kernel's `check_temporal(b"temporal.tsv", bytes)`; a `Fail` refuses the corpus load with `ui: viewmodel: <gid> <detail>` = `ui: viewmodel: <gid> temporal.tsv: <why>` (`<why>` = the `parse_temporal` violation, e.g. `kind at row 2`). Committed-corpus law unchanged (the HEAD archive carries the table).
D7 Docs. `docs/REFERENCE.md` § Reviewer interface: one paragraph on the time-word list; `.claude/rules/ui.md`: one law line (section, placement, opaque rows, fixture).
