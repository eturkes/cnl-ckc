# SUP4 — supersession on the review pages (contract)

Row = spec Tasks SUP4; Decisions `Supersession` (user ruling, SUP orientation, AskUserQuestion "Notice (Recommended)": "Document page: one paragraph with the superseding source and date, stating that the page keeps the statement as the guideline states it. Guideline page: a table of every superseded passage, also those without ACE. This extends the `Review UI` ruling, and you see each claim during your review. It is a kernel UI unit."). Data = the guideline's `vocabulary.tsv` at the rendered snapshot (SUP1 kinds `supersession <docid> <value>`, `superseded <region> <value>`, value = `<YYYYMMDD> <url> <citation>`; grammar = spec `vocabulary::superseding`). The UI intake checks the table grammar alone (`check_vocabulary`); the coverage law (`sup_violation`: a `supersession` key names a document, a `superseded` key a region without one) runs in `ckc check` ⇒ the renderer is total over tables that break it, and its copy claims nothing that law decides. Census (`.agent/archive/sup-census/rulings.md`, contract sup1 D13): a `supersession` row retires its whole ACE document, which need not represent every statement of its passage; three `superseded` passages are superseded in part ⇒ no copy claims a whole passage.

## Tier

`kernel` (precedent ur, rd): `ckc-spec` ui.rs (copy rows, `document_html`, `guideline_html`, the row scan) + uninspected `ckc-kernel` impl + proofs (K5 page render fidelity, page soundness = every text slot a corpus span or canonical decimal, escaping, copy soundness) + the shell page invariant (fixture-gated) + goldens (data).

## Design

- D1 Copy rows, appended at the `copy_table!` end in this order (registry 287 → 294; names = convention, final spelling = the implementer's, literals binding):
  - `section_open_superseded` = `<section class="superseded">`
  - `p_open_on_sp` = `<p>On `
  - `hyphen` = `-`
  - `sp_superseded_the_guideline_statements` = ` superseded the guideline statements that this page represents. This page shows the original passage and its ACE representation for review.</p>`
  - `h2_open_superseded_passages_h2_close` = `<h2>Superseded passages</h2>`
  - `p_open_later_law_regulation_or_guidance` = `<p>Later law, regulation or guidance superseded all or part of each passage in this table.</p>`
  - `thead_open_tr_open_th_open_passage_th_close_th_open_document_superseded` = `<thead><tr><th>Passage</th><th>Document</th><th>Superseded by</th><th>Superseded on</th></tr></thead>`
  Reuse, no new row: `comma_sep` (`, `), `section_open`, `section_close`, `table_open_2`, `tbody_open`, `tbody_close`, `table_close`, `link` pieces, `row` + `cell` (an empty cell = `<td></td>`). No new stylesheet rule (`section.stale` precedent) ⇒ chrome, CSS + script byte-identical, CSP hash unchanged. `ckc ui copy-check` over every new literal rc 0; no internal term (table, row, TSV, digest, docid, schema functor, guard, evaluation date); sentence case.
- D2 Row scan (spec): `sup_rows(raw)` = the lines of `raw` (the guideline's table bytes) whose field 1 is `supersession` or `superseded`, in file order, each → (kind, key = field 2, date = value bytes 0..8, url, citation), split exactly as `vocabulary::superseding` splits the value (url = the bytes after the date's space up to the next space; citation = the rest). Empty unless `vocabulary::parse_vocabulary(raw)` accepts `raw` (the `meanings_section` gate); empty for a guideline without a table. `iso(date)` = `text(date[0..4]) + hyphen + text(date[4..6]) + hyphen + text(date[6..8])`: three table spans + registry copy, never one assembled span. Escaping: citation → `text`, url → `attr` via `link` (url bytes 0x21–0x7E may hold `"`, `&`, `<`, `>`, `'`).
- D3 Document page: `document_html(g, d, …)` renders, iff a `supersession` row of D2 has key = `d.bundle.docid` (the first such row; the grammar's `duplicate supersession` law leaves at most one), three `lines` items: `section_open_superseded` / `p_open_on_sp + iso(date) + comma_sep + link(url, text(citation)) + sp_superseded_the_guideline_statements` / `section_close`, placed after the tally paragraph + the optional stale section (k = 3) and before the highlight note | script branch ⇒ the passage and ACE sections follow it. The link = a plain anchor (no `target`, no `rel`), same as `version_link`; the HTTP shell's `Referrer-Policy: no-referrer` (`ui/request.rs`) stays. Print shows the notice (no print rule hides `.superseded`).
- D4 Guideline page: `guideline_html(g)` renders, iff D2 yields ≥ 1 row, one section after `meanings_section(g.vocabulary)` (= after Status when no Word meanings) and before Documents: `section_open` / `h2_open_superseded_passages_h2_close` / `p_open_later_law_regulation_or_guidance` / `table_open_2` / the D1 thead / `tbody_open + lines(rows) + tbody_close` / `table_close` / `section_close`; one row per D2 row in file order: `row([cell(passage), cell(document), cell(link(url, text(citation))), cell(iso(date))])` where
  - `supersession` row: passage = `text(coverage_field(g, key, 0))` (the document's region; empty when the coverage holds no row for the key); document = `link(document_dir + url_seg(key) + html_ext, text(document_title(g, key)))` when `docids(g)` contains key, else empty;
  - `superseded` row: passage = `text(key)`; document = empty.
  An empty cell claims nothing, so no row shows a raw document id or an absence claim the coverage law decides. Index, records, error, refusal, session + 303 bodies byte-identical (every refusal + 303 = its own `error_page`).
- D5 Kernel inventory (consultant-3 C6; exact sites = the implementer's, every mirror required):
  - row scan + `iso`: constructive exec mirrors of the D2 helpers + span lemmas (key, the three date components, url, citation = substrings of the table input), isolated from the page proofs (own module or opaque helpers);
  - `k5_document.rs`: `body_spec`, `decomposition` (its `original` body), `leading_spec`, `body_groups`, executable `leading`, page composition + hiding — the notice term for term at the D3 place; the form, passage + compiled blocks unchanged;
  - `k5_guideline.rs` `page`: the section after meanings + the final body-equality sequence;
  - `k5_sound_document.rs`: `head_parts`, `head_sound`, the page fact inventory — a separate notice-sound lemma (the existing `head_sound` runs at rlimit 20);
  - `k5_sound_guideline.rs` `page`: a section-sound lemma + the `head + meanings + superseded + tail` composition (the unsplit query already exceeded its limit);
  - the raw table input = the existing `k5_sound_corpus::vocabulary` source (no new corpus input);
  - generated `k5_sound_literals.rs` + `k5_sound_registry.rs` from ui.rs, generator size assertions (`.agent/archive/generators/k5-sound-literals`, `k5-sound-registry`) 287 → 294; replay all six registered generators (`k5_sound_{chrome,encoding,patterns}.rs` byte-identical);
  - `ckc trust-audit --write rust` after formatting, its diff reviewed.
  Proof budget: a proof over its rlimit → rust.md remedies (split, hide, short pieces), never a bigger rlimit.
- D6 Shell page invariant (`ui/pages.rs` `invariant`, ruling R3): every anchor href (`hrefs`) that opens with `http` either opens with `COMMIT_BASE` or equals the attribute-escaped url of a D2 row of the page's own guideline; every other external href still fails `external-href`; the check reads anchor hrefs, never page substrings (reviewer-3 F1: text escaping keeps `"`, so a citation can spell `href="http` as text). No rendered tree can carry a foreign external href (the renderer emits table urls + commit links alone), so the red input = a `#[cfg(test)]` unit test of `invariant` in `ui/pages.rs` (precedent `ui/common.rs`): a page holding an external href that no row of its guideline names → `external-href`; the same href named by the table → pass; a `COMMIT_BASE` href → pass (the pre-existing check's first firing input); a second unit test runs the whole `invariant` over a kernel-rendered page whose citation spells `href="https://…"` (passes) + a planted foreign anchor (fires).
- D7 Fixtures (amended, R5: UR's frozen P7 oracle `tests/ur-ui/legacy.rs` admits no file under `tests/ui` outside its pre-UR archive, and `sup4_ui` pins the bytes ⇒ no new `tests/ui` case): a layout tree `tests/sup4-ui/mobile/tree` (`.pl.in`, materialized by the mobile recipe like the reading tree) (one guideline, ≥ 3 documents; a `supersession` row on one; `superseded` rows on a `restates` region + an `uncovered` region, interleaved in file order with the `supersession` row; a citation with `&`, `<`, `"` + non-ASCII; a url with `&` + `'`; a date in a leap February; a long citation with spaces) ; edge cases (each its own green case or rows): a `supersession` key naming no document (passage + document cells empty), a `superseded` key naming a region that has a document (document cell empty), a table holding only SUP rows (renders; the row-removal control removes the file). `just mobile` renders it beside HEAD + `tests/ur-ui/browser/tree` (justfile recipe). Every existing golden + expect byte-identical (census: 262 tracked tables + the 4 frozen UR inputs hold 0 SUP rows).
- D8 Dependent suite (consultant-3 C4, ruling R4): `tests/sup1-surface/table.rs` `p1_ui_new_rows_have_no_reading_or_guideline_page_effect` compares the whole guideline response with its no-row baseline; SUP4 re-contracts only that page-byte assertion to "baseline + exactly the D4 section" (its grammar, intake + no-reading-word checks unchanged) and renames the test to `p1_ui_new_rows_have_no_reading_and_add_the_superseded_section`; the original assertion's firing on the SUP4 renderer recorded in the unit commit.
- D9 Docs: REFERENCE § Reviewer interface (the notice + the section, places, conditions, the external-href law), § Superseded statements regains "the reviewer interface lists it" (SUP1 F2); README § Reviewing one sentence; `ui.md` (registry size 294, the section law, the D6 invariant + its unit test, the D7 mobile tree); `rust.md` generator size 294 + the harness counts the new fixtures move; Decisions `Review UI` lists the notice + the section among the page sections. A long unbroken citation (no space, wider than 390 px) overflows the notice paragraph (no `overflow-wrap` rule; a stylesheet change re-pins every golden) → `.agent/deferred.md` row, acceptance = a fixture with a 120-character unbroken citation passes `just mobile`.

## Rulings

- R1 (user, SUP orientation) notice + table, passages without ACE included.
- R2 (MAIN, consultant-3 C2/C3/C8) the notice states what the row records (source, date, the statements the page represents: "page", since a clinician can read "document" as the guideline PDF) + that the page shows the passage and its ACE for review; no sentence on what the knowledge base derives (unrequested; the consumer's evaluation date ≠ a care date); "all or part" on the guideline page; empty cells over absence labels; file order across both kinds (the table author orders by passage).
- R3 (MAIN, consultant-3 C10) source links are admitted by the D6 invariant per guideline table; no new-tab, no `rel`, the shell's no-referrer header covers them.
- R4 (MAIN) the user's page ruling (R1) approves the D8 re-contract: SUP1's page-identity assertion pinned SUP1 alone, before this unit's ruled page change.
- R5 (MAIN, implementation finds) D7's tree moves out of `tests/ui` (the UR oracle's file census fired: `P7 committed goldens unexpected file green/superseded/…`); `rd_disclosure` t5's two count pins move 287 → 294 (its row-286 literal pin stays), as `copy_registry.rs`'s.
