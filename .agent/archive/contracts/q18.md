# q18 — R9 offsets at fixed-name slots (contract)

Row: `.agent/deferred.md` R9 offsets at fixed-name slots (Q17 residual + census). Accept (row): a generated census over every fixed-name slot of the four classes (last-byte substitution + quote wrap per slot) reports zero deviations from the law; tests/v1 rows (one per slot kind) red on the unfixed revision; every committed tests/v1 row byte-stable.

## Tier

`kernel` exec code in K1 (`rust/ckc-kernel/src/v1_term_impl.rs`). The payload is an R9 position diagnostic (m5u2 R9: pinned by fixtures, outside the theorems); each quote pre-check carries the proof that canonical input never takes it (accept ⟺ WellFormed intact).

## Slots (the census domain)

- S1 record wrappers (canonically quoted): answers `'$guideline_answers'`, traces `'$guideline_traces'`, query `'$guideline_query'`, projection `'$guideline_query_projection'`.
- S2 answers record: `query_sha256`, `result`.
- S3 traces record: `query_sha256`, `answers_sha256`, `result`.
- S4 query record: `ace_sha256`, `ulex`, the ulex value (`none` | `sha256`), `temporal` + its `sha256` (v2/v3 queries).
- S5 projection: `goal`, `answers`.
- S6 document record: `guideline_document`, `ace_sha256`, `ulex`, the ulex value, `temporal` + its `sha256` (v2/v3 documents).
- S7 document clause heads + body literals (NAF-inner literals included): the predicate-name slot; candidates = the semantic predicates of the file's schema version.
- S8 back-referenced names: the record qid (answers, traces, query) = the qid of line 1; the document record docid = the docid of line 1. Canonical spelling = `atom_bytes(<line-1 name>)` + the next byte (`,`).

Controls (already law-exact, census rows expected green on both revisions): version atoms (Q15/Q17), literal-matched bytes (comment lines, declarations, the schema-version line).
Shape slots (outside Q18): digests = 64 lowercase hex (dq4 law); a census control replacing a digest uses another valid digest, and a control replacing an S8 name replaces it on line 1 too.

## Design

- D1 Law: at each slot, a name mismatch rejects `check_load,noncanonical(L,C)` at the first byte past the longest prefix shared with a canonical candidate: `atom_bytes(name)` + its next byte (S7: every candidate predicate name + `(`, plus the `%` comment and `\+` alternatives where a canonical file carries them). A quote at a bare-name slot = the opening quote; a last-byte substitution = that byte.
- D2 Mechanism: one exec LCP helper (diagnostic, ensures r ≤ len) on every name-mismatch path; a quote pre-check before each bare fixed-name parse whose canonical first byte is provably not a quote (any failed or foreign atom at the slot raises the LCP offset in place of the atom reader's own offset; a canonical slot never takes that path).
- D3 Free slots (literal arguments incl. clause ids, goal/answers/result contents, answers/traces bodies), shape slots (digests) and arity mismatches keep their current diagnostics; a name the file version declares, read as a bare atom (`guideline_entity.`), = an arity-zero use: its start (ruling on reviewer-6 Q18-R2).

## Predicates (acceptance)

- P1 tests/v1 rows (mode `check`, rc 2, one stderr line), ≥ 1 per slot kind S1–S8 with misspelled and quoted variants across the set; pins = D1; red on the unfixed revision.
- P2 a committed census harness under `rust/ckc/tests/`: every S1–S8 slot of canonical files of each class (answers, traces, query v1 + v2|v3, document v1 + v2|v3), last-byte substitution + quote wrap (bare names) → the reported (L,C) equals D1 from an independent oracle keyed on the mutation offset; zero deviations on the fixed binary, deviations > 0 on the base binary.
- P3 every committed tests/v1 row byte-stable; `just gate` green.
