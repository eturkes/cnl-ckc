## R3 Spike spec — align-TSV render-side validator

Identity target: `hl_parse_align` (tools/ui.emm → ui.py) semantics,
byte-exact on error details. Scope = render-side validation ONLY
(author-side `goal.py align` resolver = M5.4). FORMAL AUTHORITY =
committed `rust/ckc-spec/src/align.rs` (MAIN-authored trusted spec;
verified 13/0) + binding `rust/ckc-kernel/src/contract.rs`
(`align_check` ensures `r@ == align_outcome(align@, src@, ace@)`).
Settled law the spec encodes (map-m5u1 A/B, anchored there):
- Inputs = code-point sequences; offsets/lengths count code points
  (h-2 diacritic fixture = intent witness). Shell decodes UTF-8
  (allowlisted std axiom).
- Row columns: `group<TAB>side<TAB>start<TAB>span`.
- Order: trailing-LF → (strip one LF) empty-file → per-row in physical
  order (1-based): 4-fields → group canonical → start canonical →
  empty-span → side vocab → range (end = start+len(span) > len(text)
  rejects; == is valid) → span == text.subrange(start,end); then
  group-set equality src==ace (NotBothSided) → src overlap → ace
  overlap (pairwise-intersection over row-instance multiset; touching
  spans legal).
- Canonical decimal = nonempty ASCII digits, no leading zero unless
  `0`, UNBOUNDED (spec int; exec must stay faithful for huge values —
  digit-string keys, length-then-lex ordering). RULED (rev-m5u1 R03
  caveat): identity target = legacy under unbounded int parsing; stock
  Python rejects >4300-digit int() as a host-configurable DoS guard
  (`sys.set_int_max_str_digits`), a runtime artifact, not grammar —
  every legacy-driving harness lifts it (`set_int_max_str_digits(0)`);
  Rust accepts unbounded = ruled semantic identity, divergence vs a
  default-configured Python host documented here.
- Success model: dense display indexes 0.. by first-ACE-span order in
  sorted (start,end,group); per-side lists sorted (start,end,index);
  authored group ids discarded.
- Error details byte-exact per map B inventory (12 strings; `row <N>: `
  prefix, N = 1-based canonical decimal).
- CLI seam `ckc align-check <align.tsv> <src.txt> <ace.txt>`: mirrors
  legacy loader on the align file first — invalid UTF-8 → stdout
  `loader not-utf8` rc1; banned control (first offender; permitted =
  TAB/LF; banned = other C0, DEL, U+202A-202E, U+2066-2069) → stdout
  `loader control U+<04X-uppercase>` rc1 (classes = ui.py
  load_text/control_violation 129-162); then kernel verdict: rc0
  `ok count=<n> src=<s:e:i,...> ace=<...>` | rc1 `err <detail>`;
  io/usage rc2 on stderr. src/ace files read verbatim (parser-lane
  semantics, no control scan).

## R6 Trust-audit v0 (`ckc trust-audit`)

Committed gate, MAIN-authored, std+sha2 only. Scans workspace member
sources (never `vendor/`):
- Escape tokens, word-boundary regexless scan (fixed byte tokens), 15:
  `unsafe`, `assume`, `admit`, `external_body`, `assume_specification`,
  `external_fn_specification`, `verifier::external`,
  `exec_spec_unverified`, `assume_termination`,
  `external_type_specification`, `external_trait_specification`,
  `external_trait_blanket`, `exec_allows_no_decreases_clause`,
  `accept_recursive_types`, `external` (bare ident = safety net closing
  comment-split attribute forms — comments cannot split an identifier;
  MAIN probe: `#[verifier /*c*/ :: /*c*/ external]` caught rc1);
  raw-substring tokens, 5: `#[path`,
  `include!`, `include_str!`, `include_bytes!`, `verifier(external`
  (legacy paren attr form — still accepted by pinned Verus, MAIN probe).
  Split-token obfuscation pass (RULED after rev-m5u1 P0): punctuation-
  joined sequences accept interior whitespace/newlines/comments →
  per-file whitespace-collapsed count vs per-line plain total for
  `verifier::external`, `verifier(external`, `#[path`, `include!`,
  `include_str!`, `include_bytes!`; surplus = violation, never
  allowlistable. Residual (documented, accepted): comment-split
  INCLUSION vectors only (`#`+comment+`[path`, `include`+comment+`!`)
  — every other family closes via atomic-ident tokens; pulled bytes
  still verify under `--no-cheating` and trusted files stay
  manifest-pinned, so the residual cannot smuggle an unverified axiom.
  Comments count
  (member comments must avoid token words). Every occurrence must match
  `rust/trust/escape-allowlist.tsv` (`path<TAB>token<TAB>count<TAB>
  trimmed-line`); multiset-exact both directions (extra occurrence of
  an allowed line = violation).
- Structure: kernel crates (ckc-spec, ckc-kernel) carry
  `[package.metadata.verus] verify = true`; no `build.rs` any member;
  no `proc-macro = true` any member; `unsafe` allowlist stays empty
  workspace-wide.
- Deps: Cargo.lock package set (name+version) ==
  `rust/trust/deps-allowlist.tsv` exactly, both directions.
- Spec-surface manifest `rust/trust/spec-manifest.tsv`
  (`sha256<TAB>path`): recompute + compare; coverage = every file under
  `ckc-spec/src/` + `ckc-kernel/src/contract.rs` + the two allowlists +
  `rust/verus.lock` + `rust-toolchain.toml` + (RULED after rev-m5u1
  R37/R47: `[lib] path` redirect / same-name+version source swap
