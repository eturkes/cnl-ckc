# DCC — deontic census + re-authoring (contract)

Row: Tasks DCC. Rulings: Decisions Deontic conditions (Corpus: a census of the meanings the reopened shapes newly carry — not keyword matches — each candidate's disposition recorded, confirmed ones re-authored under `.claude/rules/corpus.md`; seed S37-19: `may delay` approximates `tapering does not need to occur immediately`; the release line stays untouched), Authoring principle (type everything the schema can carry; MAIN's best attempt, its interpretation in the projection notes; no judgment note reaches clinicians), Prohibitions (a source prohibition = SHOULD over a negation; `should not` stays only where the source denies an obligation), Condition scope (absence conditions = `does not provably`; exclusions only), contract dc (D1 the reopened shapes: a should|must|may box in a rule condition, under a classical negation in a consequent, in a root fact of a scoped document; D2 the whole-statement guard; E1 exclusion statements take no guard; E2 a box inside `does not provably` stays `deferred_operator`; D7: a composition holding an exclusion head + a body naming a should|must|may goal refuses `scope_condition` until TA merges).

## Tier

data (corpus law): the product = re-authored ACE documents of `guidelines/cdc-2022-opioid/` + their compiled products. Re-checked downstream by the clinician review of the ACE (Intent), `ckc check` + `ckc certify` and TA's admission ⇒ one structural validator (the census table) + a live spot-check + the corpus round's closing `reviewer` (L0–L6, `.claude/rules/corpus.md`); MAIN drafts every ACE document + rules every candidate (teammate rows = leads).

## Design

- D1 Population = every region of `guidelines/cdc-2022-opioid/coverage.tsv` (927: 492 `ace`, 246 `restates`, 189 `uncovered`): an `ace` region read as its source passage + its document's ACE + its projection-notes row; a `restates` region as its passage beside its target's ACE (a candidate = a meaning the target lacks); an `uncovered` region as its passage + class (a candidate = a passage a reopened shape makes expressible as a directive). Passage = the region's payload in `source/*-extraction.txt` (`[<id> | p<n> | <section>]` blocks; Box 3 = its 16 payload lines in file order).
- D2 Criterion (meaning; the reader judges what the source states, never a word list). A candidate = a source statement one reopened shape carries more exactly than the current ACE:
  - (A) deontic condition: a directive, recommendation or permission conditioned on another directive's status — that the clinician should|must|may do something, or that the guideline recommends, requires or permits it, classically negated statuses included (`if it is false that the clinician should …`; dc D2: a condition box under `-` or `can` is admitted) — authored today as an actual event, a finding or a judgment fact, or dropped. Test: the consequent binds while the antecedent action is owed but not yet done ⇒ a status (A); it binds only during or after the action ⇒ an event (none: `If a decision is made to increase dosage, clinicians should …` = the decision event, S32-15). A status this corpus types as applicability (the vocabulary table's `qualifier … applicability` rows: appropriate, feasible, possible, needed, indicated, warranted) stays a copula guard unless the source attributes the status to this guideline's own recommendation;
  - (B) denied obligation: the source denies that an action is required or recommended, or withdraws a recommendation (`does not need to`, `need not`, `is not required`, `is not necessary`, `does not have to`, `is no longer recommended`) → ¬SHOULD (spec Decisions Prohibitions: `it is false that … should …`); ¬MUST only where the source denies a requirement this corpus states with `must` (s12-03, rec05-imp24, rec08-imp17, s60-11) — authored today as a permission, a softened directive, folded into a prohibition, or dropped (S37-19). Surface = DCC-Q1;
  - (C) root deontic: an unconditional directive whose current ACE adds a condition the source does not state to avoid a root fact (a universal `Every clinician should …` = the faithful form; it is no candidate).
  Not candidates (each a ruled boundary): a box inside `does not provably` (dc E2: stays `deferred_operator`); a prohibition (already SHOULD over a negation); applicability (`as appropriate`, `when feasible`, `as needed` → a copula guard, corpus.md Hedges); a clinical judgment or need (`when opioids are needed for acute pain` = the clinician's clinical judgment, a fact condition) unless the source makes it the guideline's own directive; hedged advice (`might consider` → `may`).
- DCC-Q1 (ruled by the user, AskUserQuestion: "It is false that … should (Recommended)"; spec Decisions Prohibitions): the ACE surface of ¬SHOULD. `X should not V` compiles to ¬SHOULD (Decisions Prohibitions) but reads to a clinician as a prohibition (`every clinician should not immediately taper …` beside `tapering does not need to occur immediately`); `If … and there is a clinician then it is false that the clinician should V …, and …` reads as a denial and compiles to the same clauses (S37-19 seed: byte-identical to the `should not` form's, the S1 comment + the document record's ACE digest aside); `it is false that every clinician should V` = ¬∀ (no candidate surface). MAIN's recommendation = the `it is false that` surface (the Intent's easiest audit), the ruling's meaning unchanged. Ruling: `it is false that … should …`; a denied must-level requirement = `it is false that … must …`.
- DCC-Q2 (ruled by the user, AskUserQuestion: "Rewrite as a denial (Recommended)"; spec Decisions Deontic conditions): S24-13 (+ S28-02, restating it) = `This does not mean that patients should be required to sequentially fail … or be required to use any specific treatment before proceeding to opioid therapy`; the Prohibitions migration (e9bcdb68, under the user's Prohibitions ruling; reviewer-16 pass) re-authored its `Every clinician should not impose …` (¬SHOULD) as SHOULD over a negation; the text states a denial of the requirement ⇒ keep the prohibition (consumer-visible) or re-author as the denial — a reversal of a ruled migration's output = the user's call.
- D3 Disposition per candidate: `re-author` (the shape carries the source meaning; MAIN drafts) | `keep` + reason (the current ACE already carries it; the shape would distort it; a ruled boundary of D2; an exclusion whose condition would read its own guideline's guarded box = a negative cycle TA refuses → the Decisions D13 route, a user ruling) — MAIN rules every candidate; a teammate's class + lead = input.
- D4 Re-authoring (corpus law): MAIN drafts each `re-author` document; its projection-notes row updated (kept + dropped); its align table re-authored (`ckc align`, `.claude/rules/corpus.md`); a newly covered `uncovered` region's `coverage.tsv` row → `ace(<docid>)`; vocabulary rows where a new word appears; touched documents recompiled; queries re-derived; the review manifest recomputed (labels of re-authored documents go stale: Decisions IMP accepted risks; the user's review on `release/kb-2026-10-29` untouched).
- D5 Branch + grading: drafts on `wt/dcc` off `wt/dc` (fe710eca), rebased with DC onto TA's merge. Classes (B) + (C) compile, certify + check on `wt/dc` (heads only, no body goal naming a box); class (A) puts a box in a body ⇒ `scope_condition` until TA (dc D7) ⇒ grades on the rebased branch. The prototype B1 checker (`prototype/sb1/tacheck`, `--already-shaped`) on the drafted composition = an early, non-grading admit signal. Evidence on the re-authored tip (`wt/dcc` 527e871c, dc's ckc): compile, queries, check (recursion-check 15,643 rule clauses), certify, certify cases, `ckc ui check`, `check_mutants`, `consumer_recipe` + `sgw_acceptance` green; re-pins with the diff: `table-repin.py` (the vocabulary table's sha256 + row count), `check-mutant-repin.py` (the derived-entities row count), `derived-entity-unruled`'s read-by count (344 → 346 = s59-16 + s59-17).
- D6 Release line untouched (Decisions Publication scope).

## Predicates

- P1 Census completeness: `.agent/archive/dcc-census/check.py` (committed with its planted reds: a missing region, a candidate without disposition, a `re-author` without its document diff) → `census.tsv` = one row per D1 region: region, status, class (A | B | C | none), disposition (`re-author` | `keep` | `-`), rationale; `rulings.md` = the counts + every candidate's ruling.
- P2 Seed: S37-19 re-authored as class (B) (`tapering does not need to occur immediately` → a denied obligation), its projection note updated.
- P3 Corpus gates on the rebased tip: `ckc compile` + `ckc queries` + `ckc check` + `ckc certify cdc-2022-opioid` green; `cargo test --test consumer_recipe --test sgw_acceptance`; TA admits the exact final clause set (else the D13 route).
- P4 Churn: only re-authored documents' products change (`pl/`, `align/`, proof payloads, answers + traces of the queries they reach), each change traced to its document diff; every other product byte-identical outside its digests: a vocabulary-table change re-digests every document's `guideline_document` record (each binds the table's sha256) + every query's, answer's + trace's digests (re-authored tip: the 489 other documents + 18 query files changed in 64-hex digests alone); review + release manifests = their recomputation.
- P5 Review: the corpus round's closing `reviewer` (L0–L6) over every re-authored document + the census rulings; MAIN re-reads a fixed-seed sample of 20 `none` rows + every `keep` row's rationale.

## Gate identities

The census = `census.tsv` + `rulings.md` + `check.py` under `.agent/archive/dcc-census/`; the corpus = `just gate` on the merged tip (the `ckc check` + `ckc certify` steps carry P3 + P4).
