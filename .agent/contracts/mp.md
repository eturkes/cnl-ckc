## Design (core)

- D1 Surfaces. `ckc v1 model <manifest>` prints the verified model (D3); `ckc v1 model <manifest> <question>` prints the question's answers file (D3); `ckc v1 model-check <manifest> <model> <certificate>` checks any engine's model + certificate and prints its meter line (D3); any other argv = the v1 usage line (extended by these shapes), rc 2. Manifest = the v1 grammar (`contract::v1_manifest`: rows `<pl>\t<payload>`; zero rows admitted; a one-field row, a blank line or any other row shape = the existing `check_load` reject, rc 2) + its load stage; the payload cell read as `recursion-check` reads it, never parsed; load order = row order; every row = knowledge (R1: patient = rows.len(), facts = [], as ta D1(a)). Question = a query file under the existing custody law (mc D3). Every input = one regular-file read before any later stage (v1 R18: else `check_load` unreadable, rc 2); the manifest, documents + question keep the v1 load law (invalid UTF-8, noncanonical → `check_load`, rc 2); the model + certificate bytes take no UTF-8 or canonical check at load: every content defect of theirs (invalid UTF-8 included) = the `envelope` stage, after admission (mc D9; ACC a6's garbage holds `\xff`).
- D2 Outcome matrix. Bytes: the kernel's for the checker rows, the shell's for the shell rows (argv, knobs, host, stdout loss, signals); stderr line 1 of a checker row = `replay::error_line(<class>, <detail>)` = `ace_to_pl_error(<class>,<detail>).` + LF; later stderr lines = diagnostics, unfrozen; stderr empty when verified. Decisions' "nothing printed short of verified" = stdout, the answer channel: rows before publication print nothing on stdout; a refusal's line 1 may quote unverified input (a model fact, a derivable head) as its diagnostic item, never as an answer.

  `<docid>` = the document's `guideline_document/4` id; `<ordinal>` = 0-based among the document's `replay::db_of` entries, its two records included (ta D1(a), frozen); `<k>` = the claim's 1-based position in the certificate's claim sequence (mc's 0-based position + 1); `<n>` = mc D9's 1-based goal position | answer-row ordinal; terms in canonical spelling. Precedence (the first applicable row wins): argv → knobs → load (manifest, documents in row order, question, model, certificate) → custody → admission (G1 shape, safety, TA's analysis) → the question stage → [`model`: scratch → version probe → producer → capture] → envelope → identity → coverage → claim → closure → cleanup (D5 (d), (e)) → publication. Within the producer phase, what ckc did first decides: its deadline kill (`resource(deadline)`) → its cap kill (`protocol`) → a foreign signal (`signal(<n>)`) → exit 1 with a valid report (the report's kind) → another nonzero exit (`exit(<rc>)`) → rc 0 with a protocol breach (`protocol`) → success. Version probe: not found or not startable = `missing`; nonzero rc, a signal, over cap or the guard's words absent = `version`. The deadline + ckc's received signals end any phase; `model-check` never reaches a producer row.
- D3 Printed bytes. Model (`model`, verified, no question): every fact of M — derived facts + the documents' records — one line each = its canonical spelling (the verified writer, `term_bytes`) + `.` + LF, standard order of terms, no duplicates, nothing else; M = ∅ (e.g. zero rows) prints nothing, rc 0 (R4: this contract owns the printed grammar). Answers (`model` + question, verified): mc D7's `print_answers` over (qid (custody), qsha = sha256 of the raw question bytes, MC-T3's result) = the committed answers-file format (`'$guideline_answers'(v1, …)`: ID2 left answers unchanged; ACC a2: the dose answers byte-equal). Meter (`model-check`, verified) = `ace_to_pl model ok <n> documents <m> facts` + LF, n = manifest rows, m = |M| (the sibling manifest checks' form: `ace_to_pl recursion ok …`, `ace_to_pl aggregate ok …`).
- D4 Producer. One hand-authored SWI-Prolog program in the repo, embedded in the `ckc` shell crate at build time (`include_bytes!` = one `rust/trust/escape-allowlist.tsv` row: an untrusted payload, outside the kernel crates), written into the call's scratch per call (the CLI runs from any cwd; the producer is version-bound to the binary). Input = files ckc writes into the scratch alone, never the manifest's paths (no read-after-check race); their form — the read documents' bytes + the kernel's schema bytes `contract::schema_file()`, or a question's slice (ta D7) — = the amendment's. Run as `<swipl> -q -f none -F none <limit flags> -s <scratch>/producer.pl -g <entry> -t 'halt(9)' -- <scratch args>`, stdin = /dev/null, cwd = the scratch. Success = rc 0 + empty stdout + empty stderr + the files `model` + `certificate` in the scratch as regular files (opened without following links) ⇒ the kernel reads them. Failure report = rc 1 + stderr = exactly one line `ckc_model_producer(<kind>).` + LF, kind ∈ {`undefined`, `resource(memory)`, `resource(term_size)`, `resource(number_size)`}; any other rc-1 stderr = no report (`exit(1)`); an undefined atom = the producer's own failure, never a model; a report only selects among indeterminate reasons. Location: `SWIPL` (a value holding `/` = that file; else a PATH lookup of the value) | `swipl` on PATH (the `check/process.rs` law). Version probe = `<swipl> --version` under D5's supervision (group, deadline, caps); guard = rc 0 + its stdout's first three whitespace-separated words `SWI-Prolog`, `version`, `10.0.2` (the `check/process.rs` predicate) = operability, not a trust boundary (an unguarded producer can only lose a verified outcome, never forge one). The algorithm (supports recorded during derivation) + the wire writer = the amendment's (mc D5).
- D5 Process law (shell). (a) Deadline: one wall clock from ckc's start to its last stdout byte, over every phase, both commands; a watchdog owns expiry, with one publish-or-expire state (whichever claims it first wins; publication = the publisher's claim, made after cleanup, before its first stdout byte: every "before" or "after publication" in this contract names that claim): expiry before publication → the producer group reaped, the scratch removed, rc 3 `resource(deadline)`, stdout empty; expiry after publication → the stdout-loss row (`ckc: stdout: deadline`, rc 2, a prefix — possibly empty — may remain); the watchdog covers load, admission + the kernel check as well as the producer; the default = the amendment's; `CKC_MODEL_DEADLINE_S=<seconds>` (a positive decimal integer, no leading zero; read by both commands) replaces it; a malformed value = rc 2 before any read. (b) SWI limits: the producer runs under SWI's stack + table-space limits + its own term- and number-size checks, values = the amendment's; their trips reach ckc only as the producer's report (D4). (c) Pipe caps: each pipe of the producer + the version probe (stdout, stderr) is read into at most 65,536 B; one byte more → the group killed (`protocol` | `version`). (d) Reaping: the producer + the probe each run in their own process group; on every exit path ckc controls (a verdict, a failure, the deadline, a received SIGINT, SIGTERM or SIGHUP) the group receives SIGKILL and its leader is waited before cleanup completes; scope = every process in the group (a descendant that leaves the group is outside the guarantee). Stated limits: SIGKILL or an OOM kill of ckc itself, power loss = no rc, no reaping, no immediate scratch removal (the next call's sweep = recovery). (e) Scratch: one directory per call under `$TMPDIR` (else `/tmp`: `std::env::temp_dir`), created atomically with mode 0700 (never chmod after creation), named for ckc's pid + a counter (a taken name → the next counter); removed before publication and on every controlled exit; a later call sweeps only directories owned by its own uid whose creator pid is gone, never following a symbolic link; it holds one patient's facts + model (privacy: no other reader). (f) Capture (replay surface: tests, replay, regenerating committed fixtures; no export: R3), `model` only: `CKC_MODEL_CAPTURE=<dir>` names a directory that must not exist (else rc 2 before any read); ckc creates it with mode 0700 at start; after the producer ends (any producer outcome) and before the kernel check, inside the deadline, it writes the inventory in this order, each file created exclusively (never through an existing name) with mode 0600: `producer.status` (`exit <rc>` | `signal <n>` | `killed deadline` | `killed cap` | `killed signal <n>` + LF), `producer.stderr` (the captured bytes), `model` + `certificate` (each when the producer left it as a regular file); a producer that never started leaves the directory empty; a deadline expiry or a received SIGINT, SIGTERM or SIGHUP ends the capture: files complete at that moment stay, a file being written is removed, and cleanup writes, from memory alone (one status line + ≤ 65,536 B), the `producer.status` + `producer.stderr` of a started producer not yet written (`killed deadline` when the watchdog killed it; `killed signal <n>` when ckc killed it on receiving signal n) — never `model` or `certificate` after that moment; a write failure in that step leaves the deadline row, or the re-raised signal, in force; a capture write failure = rc 2 `ckc: capture: cannot write`, stdout empty; capture never changes a verdict it does not prevent.
- D6 `model-check`: never locates, probes or runs SWI (verifies with `SWIPL` naming a missing file + a PATH without `swipl`); its stages = load → admission (TA's analysis included) → envelope → identity → coverage → claim → closure (mc D9): a malformed or empty certificate never preempts an admission refusal (ACC a3 + a6).
- D7 Library: the checked-program value (mc D1, ta D1(c)) = a public surface: built from knowledge documents + an explicit patient boundary + direct facts (the patient-fact API), running admission once (G1, safety, G3 on the suffix + the facts, TA's analysis); its check + answer calls = mc's `check_model` + `answer` over it; no producer flag trusted; it runs no producer (the CLI's producer + shell rows have no library counterpart). The CLI = this value with patient = rows.len(), facts = [] (R1). Its executable signature + the TA seam = the amendment's.
- D8 Consumer-world gate (form): each gate run drives `ckc v1 model` over CDC + each `tests/consumer` world (adult, minor, cancer) + the dose world (`tests/queries/green/dose-arithmetic/tree/guidelines/fx`), the world's documents as rows after CDC's; verified model = the REFERENCE recipe's set = the well-founded rerun's (0 undefined) (ACC a1's oracle). The verdict through committed producer bytes = mc amendment P2.

## Predicates (core)

- P1 Outcome matrix, in three parts: (i) shell rows (argv, knobs, host, stdout loss, received signals) — exact line-1 bytes from D2 (a write error's `<io error>` text: prefix `ckc: stdout: ` alone); (ii) checker rows (refused + `resource(deadline)`) through decoded fixtures — a single-fault fixture per row for its exact item, membership in the stage's failing items where several fail (mc D9); the kernel's own `resource(memory|term_size|number_size)` rows = pending to the amendment (no blind construction through the core's surfaces); (iii) producer rows through `SWIPL` hook scripts: not found; not startable; a failing or wrong version probe; a probe over cap; rc ≠ 0 with and without a valid report; each report kind; a report naming a kind outside the closed set; a foreign signal; a pipe over cap; stdout or stderr bytes at rc 0; an output absent, a directory, a symbolic link; a sleeper past a small `CKC_MODEL_DEADLINE_S` (the deadline beats its eventual exit). Every row before publication: stdout empty + no ckc-owned file outside the scratch + the capture (a hook's own files are the test's).
- P2 Conformance (the real producer; outcome classes): correlated NAF locals (ACC a8), generated stratified programs vs an independent reduct oracle (ACC a7), a positive cycle without external support (absent from M), the consumer worlds (D8) → verified = the oracle (green at the merge). Wire faults (an omitted fact → closure, a forged fact → claim | coverage, a truncated file from an rc-0 producer → envelope) = the amendment's fixtures.
- P3 Process law: a deadline expiry before publication (in the probe, the producer, load or the kernel check), a SIGTERM, SIGINT or SIGHUP mid-producer → no process of the group survives (a hook records its pid + a same-group child's; `/proc/<pid>` probed after ckc exits) + no scratch remains; a received signal re-raised (the parent sees that signal); a stalled stdout reader past the deadline → `ckc: stdout: deadline`, rc 2; a dead pid's leftover scratch of this uid is swept, another uid's + a symbolic link are left alone; modes (0700 directories, 0600 capture files); the capture inventory per outcome (empty when the producer never started; `producer.status` = `killed deadline` + `producer.stderr` alone when the deadline killed the producer; `killed signal <n>` + `producer.stderr` alone when ckc received signal n mid-producer); a capture write failure → rc 2, stdout empty.
- P4 Standalone `model-check`: `SWIPL` = a missing path + PATH without `swipl` ⇒ the same verdict as with SWI present; admission precedes an empty or malformed certificate, invalid UTF-8 included (ACC a3 + a6).
- P5 Determinism: two fresh processes on the same inputs + equivalent initial state (a fresh capture root each) → byte-equal rc, stdout + stderr line 1 (every P1 row but signals + the stdout-loss rows: a write error or the deadline after publication leaves a varying prefix).
- P6 Library parity at the shared semantic boundary: the same admitted composition, selection, decoded model + certificate + question ⇒ the library's mc/ta outcome = the CLI's, and the CLI prints D2's rendering of it (every P2 case + every checker-row fixture of P1 (ii)); the shell + producer rows have no library counterpart (D7); mc P5's G3 plants through the library render as D2's `namespace_collision` bytes with the frozen ordinal.
