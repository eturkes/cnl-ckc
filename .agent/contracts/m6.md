# M6 — emission certification by translation validation (contract)

Rulings (user, 2026-09-08): relation = DRS→v1 projection + proof-payload
correspondence + source custody; acceptance-only; DRS supplied by a thin
trusted upstream-APE driver at check time; nothing new committed to the
corpus. Design input = `.scratch/agents/map-m6.md` (S1–S7).

## Tier

`kernel`: `ckc-spec/src/emit.rs` (MAIN-authored, human-read: DRS model +
projection relation + payload law + custody) + uninspected
`ckc-kernel` checker impl+proofs + trusted Prolog driver
`rust/ckc/prolog/drs_dump.pl` (human-read, ≤60 lines, upstream APE API
only, spec-manifest-pinned) + shell `ckc certify <guideline-id>`.

## The certified relation (`emit.rs`)

Inputs per document `d`: raw ACE bytes `A`, optional ulex bytes `U`,
docid `D` (= file stem, `name_ok`), the driver's DRS dump `Δ` (canonical
term text: `sentences(Ss).` `drs(Drs).` `messages(Ms).`, one numbervars
pass, quoted/ignore_ops), the committed document bytes `P`, the committed
proof payload derivation (kernel-side, no file), shell digests `sha(A)`,
`sha(U)`.

`certify_doc(A, U, D, Δ, P, sha(A), sha(U)) = ok ⟺`
1. custody: `P` accepts as `Doc(doc)` (K1) with `doc.docid = D`,
   `doc.ace = hex(sha(A))`, `doc.ulex = U ↦ Some(hex(sha(U))) | None`;
   `Ms = []`; `|Ss| = |lines(A)| = |doc.bundles|`; bundle `s` text =
   line `s` of `A` (LF-split, empty lines dropped, CR kept — legacy
   `input_lines`).
2. projection: `project(Drs, D) = Ok(bundles)` and `bundles ==
   doc.bundles` (clause sequences equal as `Term` models, variables
   canonical per line) where `project` = the S2 law as a total spec fn
   over the DRS model: sentence partition by anchors (`-(Inner, S/T)`),
   `v1_sentence` (fact cluster | rule with currying + one top-level
   disjunction split | reject), flatten (operator boxes with preorder
   `box(B)`, top-level antecedent NAF, anchors), first-occurrence
   referent enumeration + `ref(N)` minting + document map threading,
   condition expansion (object → entity+cardinality; predicate → event +
   args; modifier_pp → pp; property/pos → property), consequent locals →
   Skolem `'$guideline_id'(product, D, S, ref(N), Deps)`, contexts
   `'$guideline_id'(context, D, S, box(B), Deps)`, safety (head vars
   bound positively; NAF nonlocals bound earlier; NAF locals confined).
3. payload: `obligations(Drs, D) = obs` where each group yields
   `'$guideline_proof'(D, S, variant(K), witness(Facts), prove(Heads))`
   under the witness substitution (`ref(N)`/`box(B)` witness identities,
   variant K), ground; and `obs` = the payload the kernel replays at
   aggregate time (K2 `agg_body` over `obs` = ok). Completeness: every
   group of every sentence has exactly one obligation (closes the
   "missing last variant" gap).
Queries: `certify_query(A, U, Q, Δ, P, …)` mirrors question mode
(root `drs([],[question(Q)])`, blocker scan, marker/answer manifest law,
projection without minted identities, `% Q1:` = the one ACE line).

Rejections are NOT certified (acceptance-only): a document the fork
rejected has no committed artifact; `certify` never emits legacy reject
classes. Unsupported DRS shapes make `project` return `Err` → the
committed document cannot certify → `certify` fails closed with
`ckc: certify: <docid>: <why>` rc1.

Out of scope (recorded): ACE→DRS (APE = trusted oracle, pinned by
`vendor/ape/PROVENANCE` + Clex manifest digest); semantic interpretation
of modality/cardinality (v1 reifies them — REFERENCE § schema); ruled
K1 narrowings (floats excluded R21, non-ASCII quoted R22): a document
whose emission needs them cannot be canonical and never reached the
corpus.

## Trusted driver `drs_dump.pl`

Loads `<stage>/prolog/parser/ace_to_drs.pl` + `lexicon/ulex.pl` (upstream
modules of the vendored tree, staged with Clex + grammar exactly as
`goal.py stage_ape` does today — the shell reuses that staging), reads
ulex bytes (strict UTF-8) → `ulex:read_ulex`, reads ACE bytes (strict
UTF-8) → `acetext_to_drs(Text, off, off, Ss, _, Drs, Ms, _)`, prints
three canonical term lines (copy + `numbervars(0)` + `write_term
[quoted, character_escapes, ignore_ops, numbervars]`). No fork
predicate is loaded. Probe: `.scratch/m6/drs_driver.pl` over rec01 =
1.7 s, 2.2 KB; rec05 (NAF), rec01-imp06 (two-variant split) dump fine.
Determinism: APE's own (no gensym; numbervars canonical) — the
`certify` shell runs the driver twice and requires byte equality
(shell-tier assumption, fixture-gated).

## Predicates (acceptance)

- P1 `just verify` green with `emit.rs` + kernel `certify_doc_impl`,
  `certify_query_impl` bound in `contract.rs`; no new escape sites.
- P2 `just trust` green (manifest += `emit.rs`, `drs_dump.pl`).
- P3 corpus: `ckc certify cdc-2022-opioid` = every committed document
  (337) + query (4) certifies; meter `ckc: certify ok <id> <n> documents
  <q> queries`; wall ≤ 15 min (≈337 × 2 driver runs × 1.7 s dominated by
  swipl start).
- P4 mutation: 12 hostile edits of committed documents (drop a clause,
  swap `ref(2)`/`ref(3)`, change a lemma, add a clause, alter a Deps
  list, change `box(1)`→`box(2)`, drop a bundle, reorder two clauses,
  change ace_sha256, change the `% S1:` text, drop a NAF body item,
  change `should`→`must`) each fail `certify` with a `<why>` naming the
  sentence; the unmodified document certifies (differential on the
  spec, not on the fork).
- P5 fixtures: `tests/red` unaffected (rejections out of scope);
  `tests/certify/` NEW battery = the 12 mutants + 4 query mutants with
  pinned stderr (data tier).
- P6 REFERENCE § Audit story rewritten: `ace_to_pl.pl` leaves the
  human-read trust story; certification claim wording per Decisions;
  `vendor/ape/PROVENANCE` posture updated; `just legacy` green.
- P7 CI: `just certify` in the `rust` job (needs the pinned swipl →
  the rust job gains the swipl container step OR certify moves to the
  `check` job with the ckc binary built there; ruling at implementation).

## Rulings

- R40 relation scope = Intent (1)+(2): projection + payload + custody,
  acceptance-only (user ruling).
- R41 DRS acquisition = trusted upstream-APE driver at check time; the
  fork is never loaded by the certifier (user ruling).
- R42 `emit.rs` size budget: ≤ ~1.2K lines; the M5 spec audit (R-01/
  R-02) adjudicates against minimality; DRS constructs outside the fork's
  accepted subset are `Err` leaves, not modelled.
- R43 `nonground_obligation` stays an emission-validity guard (fork,
  shell tier: a nonground payload never reaches the corpus); M5.4's fork
  shrink moves derivability only (map-m6 S7 Q8).
