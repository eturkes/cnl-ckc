# Contract sgw — anonymous variables in clause lines (Tasks SGW)

Tier: kernel (trusted spec reading law + verified reader) + data (corpus re-emission). Gate identity: `just gate` (CI gate `just ci sgw`); fast gate = `just verify`, `cargo test --test v1_suite --test da2_acceptance --test consumer_recipe --test certify_one --test bf_emission`, `ckc compile cdc-2022-opioid`, `ckc queries cdc-2022-opioid`, `ckc check`, `ckc certify cdc-2022-opioid`.

## Problem

SWI-Prolog 10.0.2 prints `Warning: … Singleton variables: [F,G]` 65 times consulting `guidelines/cdc-2022-opioid/pl/cdc2022-opioid-s33-01.pl` (56 lines) + `-s42-15.pl` (9 lines): a formula rule's non-target clauses share the rule body, whose computed outputs (`guideline_product(D,E,exactly,rational(1,2),F,G)`) occur once in them. REFERENCE § Compiled Prolog schema promises that any set of documents "co-loads into one engine in any order with no warnings"; `consumer_recipe` fails only on `ERROR` lines. Prolog's own spelling of a variable that occurs once is `_` (each `_` reads as a new variable); the v1 codec has no `_` spelling (`v1text::var_bytes`, `wf_clause`).

## Design (rulings)

- D1 Emission (fork `ace_to_pl.pl`): every DOCUMENT clause line (rule or fact) spells each variable that occurs exactly once in the PRINTED line `_` (counted after `v1_wrap_goals`: the `naf/2` binder argument is not printed). Every other variable keeps the letter of its number in first-occurrence order counted over ALL variables of the line, `_`s included: `p(A,_,C) :- q(A,C)`, never `p(A,_,B)` (SWI's `numbervars/4` `singletons(true)` renumbers the rest and is NOT the law). Document facts render through a document-only path; question files, proof payloads + error lines keep the shared writer, unchanged.
- D2 Reading law (trusted spec `v1text`), total: `read_v1(bytes)` = the letter spelling, line by line (LF-separated, state reset at each LF): a line that opens with `%` reads as written; on every other line, outside quoted atoms (`'` opens one, `\` escapes the next byte inside it, `'` closes it), each maximal run of identifier bytes (`a-z A-Z 0-9 _`) is read in order: the run `_` becomes `var_bytes(n)`, n = the number of distinct variable runs met so far on its line (distinct runs opening with `A-Z` + every earlier `_`); a run opening with `A-Z` that equals a spelling some earlier `_` of its line became reads as that many NUL bytes (0x00, a byte no canonical file holds), so the file rejects there or at an earlier divergence; every other byte + run reads as written. Applies to every v1 class.
- D3 Acceptance: the old law becomes `canonical_v1(bytes)` (`∃ f. wf_v1(f) ∧ print_v1(f) == bytes`); `accepts(bytes) = canonical_v1(read_v1(bytes))`; `the_v1(bytes)` = the canonical file of `read_v1(bytes)`. Parsed V1 models (engine, answers, traces, certification, K5 classification) are the models of the read bytes. RAW bytes stay the input of: the K4 review clause digest (`check::semantic_input` → review bundle v2), raw query + answers custody digests, `ckc v1 render` output, the UI's displayed Prolog ⇒ the two CDC documents' review + release digests change; their K3 trace clause digests do not.
- D4 Model identity: for every document the fork emits, `read_v1(new bytes) ==` its pre-SGW bytes (D1 inverts D2 on emitter output) ⇒ parsed models, certification verdicts, answers, traces + their clause digests (`sha256` of the canonical letter re-render) stay byte-identical.
- D5 Reject offsets (R9 = a deterministic diagnostic outside the theorems): the core parser's first divergence over the read bytes, mapped back to raw bytes: an unchanged byte → its raw offset; any byte inside a replacement spelling → its `_`; read EOF → raw EOF. So the earliest divergence wins (`!` + LF + `guideline_event(_,A,x).` rejects at 0), and a refused letter run reports its first byte (scoped policy: the longest canonical raw prefix can reach into such a run, as `A1` refused where `A` names a letter variable). `at <= bytes.len()` stays proven.
- D6 Kernel: an exec reader proven equal to `read_v1` + the offset map; `v1_parse` + `v1_check_impl` read first, then the unchanged canonical parser; `v1_parse` keeps every current ensures (acceptance ⟺ `accepts(bytes@)`, `p@ == the_v1(bytes@)`, metadata + root facts) with `parsed_v1_ok` stated over the read bytes; the `parsed_term_count` callers (`k2_answers`, `k3_front`) take the read bytes' length; public binding `contract::v1_read(bytes)` = the read image (the tester's seam; no production CLI).
- D7 Consumer gate: `consumer_recipe` requires rc 0 + empty stderr (UTF-8 locale) consulting schema + every committed document + each consumer world; a warning line fails it like an error line.
- D8 Text: REFERENCE § Compiled Prolog schema (the `_` spelling), § Question projection (a question file also reads `_` aliases; `ckc queries` writes letters), § Proof traces (the clause digest hashes the canonical letter re-render, not the literal `_` line); the compiler header; `.claude/rules/compiler.md` writer bullet; `.claude/rules/queries.md` trace-digest note.
- Ruled out: a `_` token inside the term parser (its span proofs equate raw bytes to `term_bytes`; needs a surface-printer relation through the parser), a reserved variable-index range (K2 allocates through the maximum index; changes canonical re-renders), dropping unused-output computations (they filter applicability: a zero divisor fails the body), loader-side `style_check` (hides the warning; runtime-specific), `_A`-style prefixes (no advantage, same collision law).

## Testable predicates

- P1 Warning-free load: SWI-Prolog 10.0.2 `-f none -F none` consults `guidelines/schema.pl` + every committed document + every consumer world with rc 0 + empty stderr; 258ddc44's corpus prints `Warning:` lines (red).
- P2 Emission: for every document the fork emits (corpus, compiled fixture trees, `tests/green` pins, generated emission cases): `read_v1(emitted) ==` the letter spelling of the same clauses (pre-SGW emission, or `contract::v1_trace_lines` canonical lines), and no letter variable occurs once in an emitted line. Emission cases cover a nonterminal singleton (`p(A,_,C) :- q(A,C)` shape), several gaps on one line, a gap crossing `Z`/`A1`. Plants: an emitter anonymizing both uses of a shared variable; SWI's `singletons(true)` numbering — each fails.
- P3 Read identity (corpus replay): `read_v1` of each committed SGW document equals its 258ddc44 bytes; every document without `_` reads to itself.
- P4 Reading law, two layers: (a) `contract::v1_read` over generated lines equals an independent reference reader byte for byte; (b) generated full v1 files through `ckc v1 check` (verdict + offset) and, for accepted documents, `contract::v1_trace_lines` lines equal the independently built letter spelling, and SWI `read_term` gives a variant of that clause. Negative controls: omitted refusal (`guideline_event(_,A,x)` is no SWI variant of `guideline_event(A,A,x)`), an anonymized repeated variable, a wrong count, quote/backslash state, state carried across LF, a rewritten `%` line, `_a` / `_X` / `__` / `a_` (no replacement), a `_` in ground answers/traces (reject), quoted `'_'` data (accept), a raw question alias (accepted; its raw custody digest differs from the letter spelling's).
- P5 Kernel = spec: `just verify` (`--no-cheating`) proves the exec reader, the offset map's bound and the `v1_parse` / `v1_check_impl` ensures.
- P6 Unchanged verdicts: every existing suite + `ckc check` + `ckc certify` + `just mobile` stays green; old letter-singleton reader fixtures + canonical-letter trace pins unchanged; only emitter-output bytes change, with their raw custody consequences (the two CDC documents, their review + release manifest digests, compiled fixture documents, `tests/green` pins, the archive); frozen BF baselines stay frozen.
- P7 Offsets: the early-error/late-collision file → 0; EOF truncation right after an expansion; a non-ASCII quoted atom before an expansion; several expansions incl. a ≥ 2-byte spelling (`A1`); a refused run → its first byte.
- P8 Consumer gate: the actual `consumer_recipe` assertion rejects a pre-fix document, naming the warning + its file; the pre-fix gate (ERROR lines only), planted, passes the same input.
