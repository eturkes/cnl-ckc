## Design

- D1 Estimand. Load (reported, not gated; its memory stays charged) = I/O + parse/materialize of the knowledge base + its program admission (safety + compiler-shaped terms + the typed analysis under the every-feature patient abstraction: patient-independent) + indices = the checked-program value of Decisions Patient answers, built once per knowledge-base identity, verified per process (§ Carried rulings: typed analysis at load). Score = the per-call path for one patient + one question: the patient's facts admitted (fact grammar + composition identity) + the question's relevant slice (typed reachability from its call patterns, the concrete patient's facts giving their own features) + SWI evaluation of the slice's clauses (recipe tabling, fresh per-call tables) + certificate production + transport + check over the slice (support levels, existential-NAF anti-joins, closure over every enabled slice instance, canonical sort + dedup) + output serialization to the frozen sink; the scored interval ends when that sink is complete (answers flushed + closed).
