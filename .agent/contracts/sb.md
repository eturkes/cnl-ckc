## Design

- D1 Estimand. Score = the post-load path for one patient: fresh admission (safety + compiler-shaped terms + typed analysis + relevant slice) + SWI evaluation (recipe tabling, fresh per-patient tables) + certificate production + transport + check (support levels, existential-NAF anti-joins, closure over every enabled instance, canonical sort + dedup) + output serialization to the frozen sink. Queries frozen as files under `bench/sb/queries/`: (q-all) every should/must/may context = `guideline_operator(actual, C, O)`, O ∈ {should, must, may}, projected to (C, O) + each C's payload goals (the driver enumeration of `tests/consumer/driver.pl.in`, columns + serialization fixed in the file); (q-one) one guideline's own question (its nouns; a committed question of that guideline); (q-patient) a patient-constant question = relevance diagnostic, graded on the family budget alone. Load = I/O + parse/materialize of the composition: reported, not gated; loaded memory stays charged. Operational deadline (whole invocation) is separate from the scored post-load interval. Memory = the sampled maximum of summed live RSS over the owned process tree (GB = 10^9 B) + each process's high-water mark. Outcomes verified | refused | indeterminate (timeout, memory, size), never scored as fast completes; complete empty answers count. Question ratio R = median(T_q-one, 100) / median(T_q-one, 1) over paired blocks, its uncertainty = a predeclared one-sided 95 % bootstrap upper bound resampling whole pairs (10,000 resamples, fixed seed); graded on F1b (strict dormancy), F1a reported beside it. Query files, payload traversal, serialization, sink + deadline values: frozen during construction, identical across semantics, interfaces + harness.
- D2 Families. Each defines its full ×100 endpoint first (its (G, k, graph, depth, degrees) vector in the annex), then nested subsets that keep its mechanism; loaded G and active k scale independently; a point that cannot hold the mechanism (k > G) is smoke-only.
  - F1 dormant (CDC active + 99 copies): F1a common-role residue = copies keep the shared patient + clinician interface, every other lexical position renamed; their unconditional clinician-only statements (e.g. rec08's six should edges: scientist-3 C2 probe) fire as real unrelated guidelines would under exclusions-only scope ⇒ oracle = CDC's answers ∪ each copy's isolated contribution (computed copy by copy, nonempty, exact); F1b strict isolation control = every lexical position renamed (clinician included) ⇒ oracle = CDC's deontic answers exactly + each copy's isolated non-deontic facts. Both require a compositional noninterference check (no cross-copy producer → consumer or NAF path) before any union oracle; suppressing edges or adding eligibility conditions without a source is excluded. Condition-gated dormant material = a named variant only where the annex cites source-gated statements.
  - F2 independent active: a named, source-supported high-load scenario (annex: patient profile, guideline document list, count k; a mechanism-isolation workload, never a clinical translation of those diseases): k transformed CDC copies over shared read-only patient facts with private derived signatures (every head-produced lexical value + identity renamed per copy) + (100 − k) F1 copies. Static isolation check over head/body argument positions, variable-headed clauses + NAF; a planted cross-copy bridge and a planted NAF read must fail it. Oracle: each active copy's isolated full model, computed separately; union + shared facts = the model (exact), checked independently of the static check.
  - F3 shared vocabulary: a sparse overlap graph frozen in the annex from extracted source overlaps (titles = a sampling frame alone): fully qualified bridge ids (report + row), each bridge's exact source passage → ACE → compiled clause links (ACE compiled through the fork; benchmark fixtures under `bench/sb/`, never KB content), scopes, clusters, hubs, ×100 padding + activation, a joint patient profile activating the bridge. Oracle: SWI reference (recipe + `tnot` rerun, 0 undefined) + the bridge's exact intermediate + endpoint facts + a contrast that removes every alternative support of the target.
  - F4 deep chain: one concrete composable path from source passages (annex: each link's excerpt, derived state, condition that reads it, hops + rule steps), ACE-compiled; executable depth, strata, term depth + per-frontier fact counts measured. Oracle: every expected intermediate + endpoint set; missing-seed + broken-link controls. No concatenation of unrelated bridge pairs; no realistic path ⇒ the user's coverage ruling, never invented depth.
  - F5 join fan-out: a named, actually enabled medication-join mechanism (its CDC clauses, input relation = prescribed, expected enabled valuations + exact identities; a probe shows the join fires beyond unused facts) over the source snapshots F5a (Mayo Patient 1) + F5b (the two-opioid home list), kept apart; operative window = each source's named snapshot/visit identity (CMS460v2 = an unapplied reference: no supply dates exist); repeated pain-duration degree 1 (none-found). Large-record coverage (the Decisions' large patient records): a source-backed large current-snapshot instance with a faithful intake map, or the user's narrower F5 ruling — before grading. Oracle: exact enabled valuations + context identities; negative controls (out-of-snapshot values, a removed join partner).
  - MX: one documented correlated mixed case inside F3/F5 + matched one-factor contrasts (drop one bridge | one repeated key | one active shard; identities frozen by MAIN before timing, G held fixed); control perturbations labelled apart from realistic positives; its joint clinical profile passes a source-backed coherence assessment before grading, else the claim changes with the user.
  - Development vs holdout: each family freezes a development instance (tuning) + a holdout realistic instance graded in one predeclared confirmation campaign after tuning; at SB2 a used holdout = a fixed regression instance.
- D3 Calibration annex `bench/sb/annex/` (`sources.tsv` + excerpt files + the family vectors): per parameter its chosen value, derivation/mapping, source locator + sha256, verbatim excerpt, population/window/unit, evidence class (clinical data | user capacity target | engineering setting); no composite of independent marginal percentiles; load-bearing rows pass a scientist review before grading; a parameter without a row fails the generator's manifest check.
- D4 Generator `ckc bench gen` (Rust, the `ckc` shell, dev tooling beside `ckc check`): an injective, position-aware map over parsed terms — renames entity/object nouns, event lemmas, property lemmas, docids (+ document records, supersession records, scope keys) per copy namespace; keeps schema operators, units, comparison words, numbers, grade + qualifier classes, prepositions, schema markers, ref/box slot kinds + integers, variable structure; identity links consistent across clauses, facts, queries + oracle values; outputs canonical documents, compositions + a manifest (input sha256s, transform version, seeds); deterministic.
- D5 Oracles (committed under `rust/ckc/tests/`): (1) constructed + metamorphic (D2's exact sets; renaming + file-order invariance; support-choice permutations); (2) an independent finite-program oracle by a diff-blind tester from a declarative semantic annex (`bench/sb/semantics.md`: the ruled built-in + NAF meanings) over a frozen enumeration manifest (atoms, predicate arities, rule + variable counts, positive/negative body forms, built-in numeric set, term depth; exact case counts + exclusions; "exhaustive" = that domain) → ground reduct → least fixpoint → exact model; it serves MC as its exhaustive finite-program oracle; (3) certificates: positive controls (recursion with a base + a cyclic alternative support, equivalent founded supports, correct correlated NAF) + refusal plants (omitted head, unsupported fact, unfounded cycle, nondecreasing level, wrong valuation, wrong built-in, violated correlated NAF, truncated).
- D6 Harness `ckc bench run`: an exclusive critical-path interval ledger per phase (orchestration gaps explicit; concurrent subprocess walls never summed) + CPU; work counters — logical cardinalities (deterministic: clauses + term bytes, patient facts, model facts, successful joins, support incidences + levels, graph nodes + edges, certificate + output bytes, term depth + number widths) apart from runtime counters (candidate + failed joins, NAF scans, feature insertions, comparisons; reported, not equated across runs); RSS sampler (period, start, process-lifetime tracking frozen); SWI table + stack limits, size caps, one deadline. Protocol: the reference workstation, one named holder through `heavy`, nothing else heavy locally; fixed affinity + thread limits; fresh per-patient state; an exploratory pilot of 7 randomized paired blocks, then 20 predeclared confirmation blocks (same executable + input hashes); every raw sample kept; median + IQR + max; host state recorded (CPU, governor, kernel, binary hashes, swap, temperature where readable); external-interference exclusion criteria frozen before viewing latencies, a rejected block rerun whole, a slow run never discarded.
- D7 Thin path (`prototype/sb1/`): producer = the SWI 10.0.2 recipe → model + certificate: candidate ground instances against the proposed model, agenda propagation of support levels over positive prerequisites, NAF against the fixed proposed model, unfounded residuals detected; every pass charged. Checker = a Rust prototype with representative structures (interned terms with their construction + serialization charged, per-predicate + bound-pattern indices) over the intended ground valuations. Admission = safety + shape scans + the typed analysis, timed in Rust wherever it can bind the budget. The representation candidate is chosen after ×1/×2/×4/×10.
- D8 Typed-analysis census (against the candidate): frozen plant identities (L1–L5 negative cycles + growth cycles, each with its expected sign + refusal) + positive expectations; the CDC typed graph with the DC whole-statement guard shape; enforced admission on every graded endpoint, MX instance + query slice; minimal cycle witnesses kept with edge/feature provenance; costs (feature insertions, candidate pairs, edges, SCC/worklist). An unresolved CDC negative cycle = no admission of the target program.
- D9 Verus spike (against the candidate): the representative lemmas, parameter domains + assumptions frozen before proof work — (a) correlated existential NAF + built-ins in support + closure ⇒ least model of the reduct; (b) signed-edge coverage ⇒ rank ⇒ local stratification ⇒ unique WFM; (c) relevant-slice preservation for both question shapes; (d) substitution closure with nested Deps + finite grounding; each machine-checked under the pinned verifier (`--no-cheating`), resources recorded; unspiked production obligations listed apart; a failed spike = HOLD/REDESIGN evidence.
- D10 Scale points: ×1/×2 smoke + diagnosis; ×4/×10 curvature (nested subsets; dormant growth with k fixed only where G ≥ k); the realistic ×100 endpoint per family + MX on the thin path; ×25/×50 only where counters show a transition; a censored run stops cleanly + stays in the record.
- D11 Decision (predeclared): GO = every frozen family, MX + holdout instance correct at ×100; every valid confirmation run ≤ 45 s + ≤ 24 GB under the declared memory-uncertainty policy (sampling uncertainty that can cross 24 GB = HOLD); R's upper bound ≤ 1.5; every required positive composition admitted by the representative algorithm, any required CDC ruling resolved + rerun; every predeclared spike lemma passes the pinned verifier; every scored phase executed or its conservative charged bound justified by measurements ⇒ `mc` + `ta` freeze on the measured representation. HOLD = missing realism, oracle, endpoint, an unresolved ruling or material unmeasured work. REDESIGN = an observed wall of this representation (not of the architecture). Thresholds = engineering selection guards under the user's unchanged 60 s / 32 GB / 2×; a HOLD/REDESIGN that moves a Decisions entry = the user's ruling.

## Predicates

- P1 Families: every D2 instance generated twice byte-identical; every document passes the D4 validator; plants fire — a removed annex row (manifest check), a non-injective rename, a dropped condition, a changed number (semantic transform checks); calibration units checked.
- P2 Oracles: the independent oracle = the prototype checker's accepted model on the frozen domain (exact) + = SWI there; constructed sets = SWI's recipe model on every development instance (exact sets, not counts); positive certificates accepted, plants refused.
- P3 Harness: the interval ledger accounts the critical path with explicit gaps; the RSS sampler sees planted touched allocations across several phase offsets + lifetimes, and reports a shorter-than-period spike as missed; a planted timeout + memory cap read indeterminate with no partial output.
- P4 Thin path: development runs at ×1/×2/×4/×10 accepted + plants refused; the confirmation campaign separate; endpoint correctness (the exact frozen output) required.
- P5 Runs: raw samples + both counter kinds of every point in the record; D6 followed.
- P6 Census + spike: D8's plants + positive expectations met on every graded composition; D9's lemmas checked — asserted, not merely reported.
- P7 Decision: D11's conditions asserted with their evidence + the `mc`/`ta` representation.

## Grading authorization

The graded campaign (pilot + confirmation blocks of D6) starts only once: the tooling + preflight controls (P1–P4) pass; the frozen instances exist with the annex run manifest complete (development + holdout ids, query hashes, oracle bytes, per-shard sizes, run settings); F5's enabled join + large-record coverage (or the user's narrower ruling) and MX's coherence assessment are closed; scientist-3 has passed those closures. Construction (generator, harness, oracle, thin path, small fixtures) proceeds before it.

Gate identity: `just gate` + its chain unchanged; small mechanism-complete fixtures (e.g. a two-shard bridge with two shards) join `just test` (generator, oracles, harness controls); ×100 + timing = reference-workstation runs with a committed rerun command + raw artifacts, never CI.
