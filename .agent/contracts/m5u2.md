(`ace_to_pl.pl` consumption modes + goal.py trace validation) — the dual-run
differential replaces a separate `orc` build. MAIN authors ckc-spec + this

(S1-S8, anchored), `map-m5u2-2.md` (K3 40-obligation table S6, fixture census
S5), `res-m5u2-vest.md` (Q1-Q4), `test-m5u2.md` (phase-1 C1-C9).

- R25 K2 term arena + K1→K2 bridge (lead ruling; supersedes the k2-1 brief's
  "children by index range"): ONE exec term representation for K2 =
  `ETermArena { nodes: Vec<ENode> }`, view = `Seq<Term>`, leaves as k2_term.rs

  discharged by calling the K1 parsers with `expected = Ghost(Some(the_v1(bytes)))`
