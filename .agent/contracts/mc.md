## Design (core)

- D1 Surface (decoded values). Program value P = the composition's ORIGINAL admitted clause sequence (knowledge documents in load order, then the patient suffix), each clause with its original ClauseId = (document index, clause ordinal) ↦ a dense position; document provenance (clause ↦ document, document ↦ docid) + the composition identity value. A selection `select(P, S)` (S = a set of original clause ids) = a labelled view: the same clauses, ids, provenance + root identity, the active ids S ∩ P's; never a renumbered subsequence (`bench/sb/interfaces.md` slice mode: "ids are those of the original composition"). `accepted` ranges over P or a selection of it, never over TA's certified sequence: TA certifies a NAF-extension Q of P (the DC-shaped sequence; spike `envelope::naf_extends`) and hands MC two conclusions as explicit hypotheses, never computed inside MC's proofs — H1 (whole program) = `two_valued(P)`: lower(P) = upper(P) (from `naf_extension_wfm`'s ensures; MC proves uniqueness itself, MC-T1b); H2 (question q over slice S) = `two_valued(select(P, S))` ∧ the answer set of q over lower(select(P, S)) = over lower(P) (from `pruned_selected_wfm_queries`'s ensures). Calls: `check_model(P, M, C) -> Outcome`: M = a finite set of G2 ground literals; C = the certificate's identity value + a sequence of claims (fact, original clause id, valuation, level) — a sequence, so malformed coverage stays representable. `answer(P, S, M, C, q) -> Outcome`: `check_model(select(P, S), M, C)`, then MC-T3 over M. Test + bench surface: each term as v1 term text read by the existing verified reader, claims as structured tuples; the amendment's envelope reader yields the same tuples. No producer flag, provider claim or receipt is trusted: every public path (MP's two commands, the library) reaches `accepted` through this value.
- D2 Grammars. G1 program terms = atoms, integers, canonical `rational(N, D)` (D ≥ 2, gcd(|N|, D) = 1), `'$guideline_id'(Kind, Doc, S, Slot, Deps)` (Kind, Doc atoms; S an integer; Slot `ref(N)` | `box(N)`; Deps a list of variables, `[]` in facts), variables; metadata compounds at their fixed positions alone (`guideline_document/4`, `guideline_supersession/4`; `bench/sb/semantics.md` § Syntax). Literals = the 22 schema indicators + the four built-ins + negations of conjunctions (§ Syntax). G2 ground terms = G1 without variables, Deps = a list of ground terms (nested identities). G3 patient suffix = facts alone (compiled patient documents + facts supplied directly through a patient-fact API, § Syntax): ground schema literals over atoms, numbers (integers, canonical rationals), identities with Deps `[]` + the patient documents' own metadata records, under the namespace boundary: KBNamespaces(P) = every Doc argument of a `'$guideline_id'/5` + every docid of a `guideline_document/4` occurring anywhere in a knowledge clause (head, positive goal, built-in, negation); a patient fact admits iff no subterm of it (bare atoms included) equals a member of KBNamespaces (the census's `validate_patient_boundary`, `prototype/sb1/ta/src/source.rs`). Evidence (corrects Decisions' "atoms + numbers"): `tests/consumer/{adult,cancer,minor}.pl.in` + the dose world `tests/queries/green/dose-arithmetic/tree/guidelines/fx/pl/world.pl` = ground facts alone (0 rules, 0 variables), each under its own `guideline_document(<world>, …)` with `'$guideline_id'(product, <world>, S, ref(N), [])` identities; ACC `wt/tester-2` A1 requires those worlds verified. TA's rigid-root premise (a question constant equal to a KB origin = that origin; every other constant = patient-top) rests on this boundary ⇒ MC owns its admission check + the separation lemma (D10).
- D3 Admission. Program (MC half): G1 shape on every program term; G3 on the patient suffix; left-to-right safety (§ Syntax): every head variable occurs in a positive schema literal or a built-in output; every built-in input + every variable a negation shares with the clause outside it occurs in an earlier positive literal or built-in output; inside a negation `\+ (G1, …, Gm)` (m ≥ 1, no nested negation) the same left-to-right rule continues from the outer bound set (a built-in input = an outer variable bound earlier or a variable an earlier goal of the same conjunction binds) — what makes D6's existential witness search finite (prototype `program.rs` `safe_goals`). 18,845/18,845 committed clauses + 33,632/33,632 committed terms pass (Decisions). A refusal names the document + the clause. TA adds the typed analysis (no negative cycle, no growth cycle) to the same value. Question: the existing query custody law (`ckc_spec::answers::custody`: the `QueryFile` record, the goal walk, the answer rows; its rejects stay its existing `Out` values — unreadable, noncanonical, a goal-walk witness, `answers_list`, a row's shape, variable or descriptor — returned before any core Outcome) + on a custody-accepted question, left-to-right safety over its goal list (as above) + every answer-row (projection) variable bound by a goal ⇒ finitely many answers over a finite M.
- D6 Spec semantics (`ckc-spec` `model.rs`, over decoded values; § Meaning). Ground instance Cθ (θ maps every non-local variable of C to a ground G2 term (the spec's encoding: R4); non-local = every variable except one occurring inside a single negation alone). `holds(I, L)`: a schema literal ∈ I; a built-in = the schema relation of REFERENCE § Comparison conditions + § Arithmetic built-ins (the existing `compare::holds`); a negation = no ground σ over its locals with every conjunct holding in M (one correlated witness for the whole conjunction; σ ranges over every ground term). `T_M(I)` = heads of the active instances whose positive schema literals ∈ I, built-ins hold + negations hold under M. `lfp(T_M)` = the intersection of every closed set; stable(P, M) ⇔ M = lfp(T_M). Well-founded model = the alternating fixpoint: lower(P) = lfp(Γ∘Γ) (the intersection of its pre-fixed points), upper(P) = Γ(lower(P)), Γ(X) = lfp(T_X); two_valued(P) ⇔ lower = upper. Claim (fact F, clause id i, valuation θ, level ℓ ∈ ℕ) is valid iff i is active, θ a valuation of clause i, head(i)θ = F, its body holds in M, every positive schema literal of the instance has a claim in C at a level < ℓ, and ℓ = 0 when clause i is a fact, ℓ ≥ 1 otherwise (§ Answers: "facts of P: level 0; an instance without positive body literals: any level ≥ 1"; levels are never required minimal). Coverage: every fact of M claimed exactly once, every claimed fact ∈ M. `accepted(P, M, C)` = identity(C) = identity(P) (an abstract equality; its bytes = D4) ∧ coverage ∧ every claim valid ∧ T_M(M) ⊆ M over the active clauses.
- D7 Theorems. MC-T1 `accepted(P, M, C) ⇒ stable(P, M)` (spike `support::support_closure_lfp` = its abstract form). MC-T1b `stable(P, M) ⇒ lower(P) ⊆ M ⊆ upper(P)` ⇒ with H1, M = lower(P) = WFM(P) (Decisions' claim) and P's only stable model. MC-T2 (core half) the refinement: the kernel's `check_model` = `verified` ⇒ `accepted` of the spec over the same decoded values; the decoder's soundness (decode ∘ canonical write = id on G2) = the amendment's codec half. MC-T3 the question: for an admitted question (D3) over M, the result = `yes` | `no(finite_failure)` for a question without answer rows (some valuation of its goal list holds in M, or none), else `solutions(L)` with L = the standard-order, duplicate-free list (`engine::sort_unique`) of `sol(Row)` over every valuation whose goals hold in M (one ground term per goal variable, G2 or not: R4; computed built-in outputs included, members of M or not) — the existing result vocabulary of `answers::answer_result`, the model replacing bounded SLD (no `indeterminate(limit)` term: resources = D9's indeterminate outcome); via `answer` + H2 ⇒ that result = the result over WFM(P). The answers file = the existing `print_answers` over `{qid (custody), qsha (sha256 of the raw query bytes, the shell's digest law), result}`, composed at MP. MC's statements carry H1 + H2 as hypotheses (no `assume`; `--no-cheating`).
- D9 Outcomes (library): `verified(model | result)` | `refused(stage, item)` | `indeterminate(reason)` (term or number size, memory, deadline — the caller's); each distinct from a complete empty answer; no model or answer payload unless verified. Stages in precedence: admission (item = document + clause) → question (a custody-accepted question; item = goal position | answer-row ordinal, 1-based as custody numbers its rows) → identity (item = the composition) → coverage (item = an unclaimed fact of M | a claim position whose fact ∉ M | the later position of a duplicated fact) → claim (item = claim position) → closure (item = an active clause id + a derivable ground head ∉ M); the amendment adds envelope (before identity). The reported stage = the first stage with a failing item (exact); the item = one failing item of that stage (tests check membership; two fresh runs return the same item). MP freezes rc + stdout + stderr per outcome.
- D10 Obligation table (contract-owned, current at every checkpoint commit): theorem/lemma → dependencies → last checked commit + command → next step; rows = MC-T1, MC-T1b, MC-T2 (per check), MC-T3 (valuation-enumeration completeness over the admitted question domain; yes/no vs wh folding; projection order; canonical order + dedup), the built-in bridge (`compare::holds`), the selection bridge (labels, provenance + root identity preserved by `select`), G3's separation lemma (an admitted patient fact holds no KB namespace atom ⇒ TA-D7's rigid-root premise), each production obligation MC owns (grammars; levels; joins + anti-joins under safety; resource limits), H1 + H2 named as TA's hypotheses.

## Predicates (core)

- P3 Refusal battery (decoded claims; byte fixtures with the amendment), each refused at its stage with its item ∈ that stage's failing items: a level not strictly above a positive body literal's claim; a rule instance at level 0; a clause id out of range; a clause id valid in P but outside S; a valuation whose instance's head ≠ the fact; a NAF whose witness lies in M (correlated locals: a witness split across two conjuncts' separate σ must not refuse); a failing built-in; an unsupported extra fact; a missing derivable fact (closure); a self-supporting positive loop without external support; a wrong root identity; a fact claimed twice; a fact of M never claimed; a claimed fact ∉ M. Selections: an omitted prefix + gaps keep every original id valid.
- P4 Independent oracle (three properties kept apart): soundness — accepted(P, M, C) ⇒ M = oracle(P) for every C, valid, malformed or adversarial; model completeness — M = oracle(P) ⇒ some valid certificate is accepted; certificate completeness — every C with the right identity, exact coverage + valid founded support for oracle(P) (arbitrary non-minimal levels, alternate founded supports) is accepted, while an invalid C is refused for the same M. Domains: (i) contract sb D5 (2)'s frozen exhaustive finite-program domain (its enumeration manifest + exclusions, replayed; the oracle reads its permitted sources alone, `semantics.md` line 3); (ii) generated programs through the Test form harness (fixed seed, shrinking: shared atoms, correlated NAF, alternative founded + cyclic supports, built-ins with computed outputs) complementing (i), never replacing it. Questions: MC-T3's result = the oracle's over the same M on both domains (a computed output absent from M included).
- P5 Admission: unsafe head | built-in | NAF (an unbound outer variable; a local used only as a built-in input) + foreign-head fixtures (ACC `wt/tester-2`) refused, document + clause named; G3 plants refused: a patient rule, a patient identity whose Doc is a namespace mentioned only by a knowledge identity, a bare atom equal to a knowledge docid, a knowledge document-record id; question plants refused: an arithmetic built-in with an unbound input (`guideline_product(exactly, X, exactly, 1, exactly, Y)` projecting X, Y), an unbound answer-row variable, a negation's unbound outer variable; the committed corpus admits 18,845/18,845 clauses; the four consumer worlds' patient suffixes admit.
- P6 Proofs: MC-T1, MC-T1b, MC-T2 (core), MC-T3 verify under the pinned Verus `--no-cheating`; resources recorded; the obligation table current.
