# M5.4 — pipeline commands + fork shrink (contract)

Unit = `ckc compile | queries | align | review-manifest | derive-review-manifest |
release-manifest | ledger-validate` replacing the legacy `goal.py` pipeline modes
(map-4 R3 = the byte-parity target: inputs, outputs, paths, meters), with M5.8
folded in: the fork `ace_to_pl.pl` loses its in-compile replay (emission-only
closure); the pipeline = swipl emit → kernel replay/certify → write-after-green.
Legacy stays CI-authoritative until M5.7.

## Tier

- kernel: align resolver (`align.rs` § resolve: occurrence-form stdin TSV →
  span offsets; nth non-overlapping literal occurrence, paired group sets, no
  same-side overlaps; canonical sort) — what the clinician sees aligned;
  release-manifest derivation (`release.rs`: meta/member/source/label rows,
  sorted, from shell-supplied member digests + rights profile classes) — the
  consumer's `sha256sum -c` anchor; review-manifest derivation + ledger
  validation = the M5.3 bindings; compiled-output acceptance = K1 `v1_check`
  + K2 aggregate/recursion replay + M6 `certify` on the freshly emitted bytes.
- shell (enumerated, fixture-gated): APE staging (`stage_ape` = vendored
  APE + Clex + grammar into a scratch stage), swipl subprocess (`-q -f none
  -F none -g main -t halt(9)`, 300 s process-group wall), atomic directory
  swap (scratch pl-new → rename), git reads for release derivation
  (`ls-tree`/`archive`/`show`, source-head = last commit touching
  guidelines/fork/clex), rights profiles (legal validators), stdout/stderr
  meters, argv/exit codes.

## Scope

Commands and their exact legacy contracts (map-4 R3, anchors tools/goal.py):
compile <gid> (1665: all documents compile into memory, then one swap of
`guidelines/<gid>/pl`; `goal: wrote …` per doc, `goal: compile ok N documents`);
queries <gid> (1598: question compile → answer → trace per sorted qid, then
replace `queries/{pl,answers,traces}`; `goal: queries ok N queries`);
align <gid> <docid> (4674: stdin TSV `group\tside\toccurrence\tspan` →
`guidelines/<gid>/align/<docid>.tsv` rows `group\tside\tstart\tspan`; `goal:

`audit/review-manifest.tsv`) + derive-review-manifest <dir> (3191: same bytes

release-manifest N guidelines M members`); ledger-validate <ledger>
<manifest> <label> (3212: no ODB check; `goal: adjudication <label>
approved=… decisions=…`). rc law: V → stdout rc1, F → stderr rc2, R relays.

- P1 `just verify` green with `align.rs` resolver items + `release.rs`
  derivation items bound in `contract.rs`; no new escape sites.
- P2 `just trust` green (manifest += `release.rs`).
- P3 corpus reproduction: `ckc compile cdc-2022-opioid` + `ckc queries
  cdc-2022-opioid` reproduce every committed `pl/*.pl`, `queries/{pl,answers,
  traces}/*.pl` byte-identically (`git diff --quiet -- guidelines/`); meters

  occurrence-form input reconstructed from it re-resolves to the identical

  overlap, one-sided) = red probes rc2 + exact stderr (closes the
  `.agent/deferred.md` align fail-path row).

  `release-manifest` byte-identical to legacy on HEAD (stdout + files + rc);
  the 42R/9G adjudication fixtures replay through `ckc ledger-validate`.
- P6 fork shrink: `ace_to_pl.pl` retains emission (compile/proof/question)
  only; check/aggregate/recursion/answer/trace modes removed; header +
  REFERENCE compile contract + `vendor/ape/PROVENANCE` posture updated

  the shrunk pipeline; proof-class red probes re-pinned (FC2, enumerated).
- P7 `just rust` + `just legacy` green at close; corpus byte-stable.

## Rulings

- R65 write-after-green: a pipeline command writes into `guidelines/` only
  after every emitted artifact passed the kernel acceptance (K1 check, K2
  replay, K3 trace-check, M6 certify) — the legacy "all compiles succeed,
  then swap" law strengthened to include certification.
- R66 M5.8 folds here: the fork's replay predicates die in this unit; the
  legacy `check` section that replays through the fork (documents/queries)
  is re-pinned to the kernel replay at M5.7 (R44 mechanical re-pin).
