## Carrier facts (APE probes `.scratch/str/s2/probe/{a,b,c}.ace`; consultant-3 probes)

- An ACE adverb modifies one event: `modifier_adv(E, Adv, Degree)`, Degree ∈ {pos, comp, sup} (`more carefully` → comp), in the box of E's `predicate` condition, before it (pre-verb; a copula's complement `property` conditions may stand between: `A dog especially is feasible and preferred.`) or after it (VP-final; after E's pp conditions too: `A man should see a dog carefully for 2 hours.` → predicate, pp, adverb); one event takes both; copula, passive, antecedent, NAF and operator-box events take adverbs; `should not routinely prescribe` = `-(should(… modifier_adv …))`; `X is usually effective` is not ACE, `X usually is effective` is. Hyphenated ulex adverbs parse as one token.
- A copula with an adjective: `property(P, Adj, pos)` then `predicate(E, be, X, P)` (+ `modifier_pp(E, for, Y)` for `is appropriate for the patient`); `needed`, `indicated` parse as adjectives (Clex). `is feasible and appropriate` = two properties on one P under one `be`; `is a feasible category-A-recommendation` = an `object` + a `property` on one complement referent (consultant-3 r2 probes); current S1 emits grade + preference together for `is a preferred category-A-recommendation`. Existing corpus guards: `is appropriate` (s29-20, s47-06), `is feasible` (rec09-imp04, s60-18), `is possible` (rec01-imp04, s22-08, s26-01), `is needed` (rec06, s22-04, s30-05), `is indicated` (s25-04), `is likely` (rec09-imp21), `is addressable` (rec10-imp05).
- `can`: `If … then it is possible that the patient needs …` and `… then the patient can need …` give the same `can` box; `can possibly need`, `can frequently have` keep the adverb inside it; nested `can` → `must` compiles; a universal directly inside `It is possible that` rejects `operator_scoped_rule(can, S)`.
- Today: every `modifier_adv` rejects — documents `unsupported, condition_shape(modifier_adv(A,ideally,pos))`, questions `unsupported, query_unsupported(leaf(/(modifier_adv,3)),1)`; copula adjectives compile as primitives.
- Assertion (consultant-3 K9, native answers): a claim in context `actual` is asserted — an ordinary query and another document's rule consume it whatever data accompanies it; the same claim under `can` answers `no` to both while the modal query answers `yes`; deleting an applicability guard turns a guarded `should review` from `no` into `yes`.

## Design

D1 Indicator. One semantic predicate joins the schema; 18 declared indicators (2 records + 16 semantic); declaration order = S1's 17, then:
- `guideline_qualifier(Context, Event, Class, Word)`: in `Context`, the source qualifies the event `Event` with the word `Word`, of function class `Class` ∈ {`usuality`, `ideality`, `focus`, `manner`, `force`, `possibility`, `applicability`}; `Word` = the qualifier lemma (an adverb, or the adjective of a copula), an opaque source atom.
The adverb lemma is a lemma slot of the C1 reserved-name scan (`modifier_adv/3` arg 2, beside object, predicate, property, modifier_pp): a reserved adverb lemma rejects `reserved_name_collision` in documents and questions before any other check. Codec = arity + canonical term form: any well-formed argument terms load; the class domain + argument identities are certification law (D6), never reader law. Legal in any document head, body + NAF group and any raw question goal; identifier stays `1`; document + question records unchanged.
Class = the function of the source wording: usuality = how usual or how often (typically, usually, generally, often, frequently, routinely, regularly, periodically, occasionally, sometimes, rarely); ideality = the ideal or best-case form (ideally, optimally, preferably); focus = emphasis for its scope (particularly, especially, importantly); manner = how the event is carried out (carefully, closely, cautiously, gradually, …); force = the strength of the advice's wording (strongly); possibility = a possible or likely claim (possibly, potentially, likely); applicability = the fitness of an action or thing for the case (appropriate, feasible, possible, needed, indicated); as a condition it is a judgment that someone must establish. Assertion + eligibility are carried by the context, the operator path and the antecedents the ACE states, never by the class (D3.6, D3.7).

D2 Vocabulary kind. `vocabulary.tsv` gains `qualifier <lemma> <class>`, class ∈ the seven; C1 + S1 row law stays (exact header; `#` row rejects `comment`; three fields; final newline; checks in row order: comment, field count, lemma, kind, value, duplicates). A lemma occurs in at most one `qualifier` row (the later row reports `duplicate qualifier at row <n>`); a qualifier lemma is never an `approximation` or `preference` lemma, in either row order (the later row reports `duplicate adjective at row <n>`: those kinds + the copula carrier read the same `property` conditions); a bad class reports `qualifier value at row <n>` ahead of that row's duplicate checks. Other kinds key nouns + prepositions, which no qualifier carrier reads: a qualifier lemma spelled like one is legal. Messages extend C1's (`ckc: vocabulary: <path>: <why> at row <n>` / compiler class `vocabulary_load`).

D3 Qualifier patterns (documents with a table; questions never).
1. Adverb carrier: each `modifier_adv(E, A, D)` whose lemma A has a `qualifier` row of class K, D = `pos`, is replaced in place by `guideline_qualifier(Ctx, E, K, A)`, Ctx = the condition's flattened context: the clause stands where the adverb stood in the condition order. A mapped adverb with D ∈ {`comp`, `sup`} → `unsupported, qualifier_shape(degree, S)`. An adverb without a `qualifier` row stays a `modifier_adv` condition and the expansion rejects it exactly as today (`condition_shape(…)`, byte-identical detail).
2. Copula carrier: a `be` event E whose complement (arg 2) P names no thing — P has no `object` declaration anywhere in the document (spec `property_only`) — emits one `guideline_qualifier(Ctx, E, K, Adj)` per same-context `property(P, Adj, pos)` whose Adj is a `qualifier` lemma of class K, in condition order, right after E's arg-2 clause; the property clauses stay. A qualifier adjective on a noun (`a feasible option`, also as a copula complement) emits nothing: it qualifies a thing.
3. Contexts, both carriers: root fact (a fact), rule antecedent (a body goal of every clause of the rule, every Horn-split variant included), consequent (a head), operator box (the box context), top-level antecedent NAF group (inside its `\+`). Several adverbs on one event → one literal each, in condition order; E may be any predicate, `be` included. S1's carriers keep their behavior + insertion points and may co-occur with qualifiers on one `be` event (grade + preference already do): emission order at a predicate item = item, grade, copula qualifiers, no-alternative preference; an alternative-bearing preference still follows its pp.
4. Order (= the compiler's sentence pipeline + spec emit.rs `flatten_doc`): per scope in sentence order — root; or the concatenated antecedent segments, then the consequent; Horn split: shared, arm 1, arm 2, then the consequent of each variant — flatten, its C1 time checks, then the strength pass in item order (the S1 decisions + D3.2 at each predicate item, D3.1 + D3.7 at each adverb item, a NAF group's payload where its item stands); then expansion (an unmapped adverb's `condition_shape` fires here, after every scope's passes); then the sentence's grade-dimension check. The first violation rejects (consultant-3 `r2-guard-order`: an adverb before its predicate's alternative pp rejects `qualifier_shape(asserted, S)` ahead of that predicate's `preference_shape(no_preferred, S)`).
5. Referent ordinals unchanged by construction: ordinals enumerate primitive conditions only (`object`, `predicate`, `modifier_pp`, `property`; compiler `v1_cond_refs`, spec `cond_refs`); neither a `modifier_adv` condition nor a qualifier term holds a slot.
6. A qualifier adds no policy beyond its authored literal: as an antecedent goal it constrains which facts match (a fact without the same qualifier does not satisfy it); inside NAF it joins the negated conjunction; no class generates an extra condition, rank, frequency, probability, priority, obligation or change of assertion.
7. Assertion guard (adverb carrier), checked at its D3.1 decision: an adverb qualifier whose class is `usuality`, `ideality`, `possibility` or `applicability` on an asserted head rejects `unsupported, qualifier_shape(asserted, S)`. Asserted head = a root fact or a rule-consequent head whose context path from `actual` holds no modal operator (`should`, `must`, `can`, `may`): `actual` itself, or classical negations alone (`The patient does not usually take an opioid.` feeds another document's `If a patient does not take an opioid then …` rule: consultant-3 `r2-negative-{plain,can}.answer`). Antecedent + NAF qualifiers are conditions, exempt. Authors put such a claim under a modal (`can` for a possible or usual descriptive claim, keeping the source polarity under it; the source's deontic operator for advice). Focus, manner + force adverbs and the copula carrier are exempt: they do not weaken what the clause asserts (a copula qualifier's property is the asserted content: `the risk is likely`). Reclassification: when the old and the new table both compile a document, only the Class argument + custody digests differ; otherwise the new table meets this reject.
Projection preservation: erasing every qualifier literal (heads + body goals) from an S2 compile's ordered clause projection before proof-obligation discharge yields the projection of the same ACE with every mapped adverb's word deleted, under the table minus its `qualifier` rows (+ one inert row of an old kind when no other row remains, as S1 D4) — explicit operators, antecedent guards + copula adjective primitives stay on both sides; when both full compiles succeed, their rendered documents are byte-equal after the erasure apart from the record's `ace_sha256` + table digest and the `% S<n>:` sentence-comment lines. No claim of equal consequences or proof outcomes: deleting `usually` from `If a patient takes an opioid and it is not provable that the patient usually takes the opioid then …` makes the NAF body contradictory and the erased compile rejects `proof, underivable_obligation(1, variant(1))` (consultant-3 `r2-naf-erased`).
8. A qualifier belongs to its event's description: a negation or an operator covers the event together with its qualifiers, and a consumer that matches the event must match its qualifiers too (REFERENCE); e.g. `should not abruptly discontinue` prohibits abrupt discontinuation, not discontinuation.
Worked examples:
- `Every clinician should ideally review a record.` ⇒ in box(1): `guideline_qualifier(Box, E, ideality, ideally)` before `guideline_event(Box, E, review)`.
- `If a patient has a prolonged-opioid-use then the patient can possibly need a prophylactic-pharmacologic-bowel-therapy.` ⇒ heads `guideline_operator(actual, Box, can)`, the `need` event + args in Box, `guideline_qualifier(Box, E, possibility, possibly)`.
- `If a patient has a chronic-pain then the patient possibly needs a …` ⇒ `qualifier_shape(asserted, 1)`.
- `If … and a pain-care-clinician-treatment is feasible then …` ⇒ body goal `guideline_qualifier(actual, F, applicability, feasible)` after `guideline_arg(actual, F, 2, P)`, in every clause.
- `Every clinician should more carefully review a record.` ⇒ `qualifier_shape(degree, 1)`.

D4 No table, or a table with no `qualifier` row: no adverb is consumed (every adverb rejects as today) and no copula adjective emits a qualifier; such documents compile byte-identical to S1 apart from the D1 declaration block (+2 lines). Unused qualifier rows stay legal (no liveness check).

D5 Questions. The goal whitelist = the 16 semantic predicates. Question mode never runs the strength pass: an ACE question with an adverb (a lemma outside the reserved names, D1) rejects exactly as under S1 (`query_unsupported(leaf(/(modifier_adv,3)), S)`); every other question compiles byte-identical to S1 apart from the record's table digest (a copula adjective stays a primitive). Typed queries naming `guideline_qualifier/4` reach the records (CDS consumers; canonical tests/v1 fixtures, P4). Certification rejects a qualifier goal in a committed ACE question (no ACE derivation exists).

D6 Certification. `certify_doc` re-derives D3 from the DRS + the raw table bytes (record digest checked as in C1). A changed, dropped, added, misplaced or duplicated qualifier literal — wrong Context, Event, Class or Word — fails as `clauses(S)` | `projection`; a document compiled without a table that carries a qualifier fails; a raw qualifier with out-of-domain Class/Word loads at the codec yet certifies against no derivation; primitives unchanged in every mutation case.

D10 Corpus (`.claude/rules/corpus.md` law; S2c commits, batched, each batch `ckc compile` + `ckc queries` + `ckc check` green with align + projection-notes current = a resume point).
- Table: CDC `vocabulary.tsv` gains one `qualifier` row per word the corpus uses (adverbs: usuality, ideality, focus, manner, force, possibility words; adjectives: appropriate, feasible, possible, needed, indicated, addressable → applicability, likely → possibility); a word no document uses gets no row; the table change re-pins the certify digest mutants + check-mutants row pins (corpus.md). The adjective rows type the existing guards without an ACE change.
- Census (closed inventory; archived beside the contract at close): `regions.tsv` = every `ace` (339) + `restates` (260) region, each `reviewed`, with its row count; `census.tsv` = one row per hedge occurrence (key = region + cue, `#n` for a repeated cue): docid | restates target, verbatim hedge, qualified proposition, current ACE treatment (span | dropped | approximated), class | none, disposition ∈ {`typed` (word + event, ACE sketch), `other-carrier` (time annotation, preference, operator, explicit content condition: named), `entity` (qualifies a thing, incl. attributive phrases + restrictive relative clauses), `not-qualifier` (comparative, purpose, scope declaration, schedule noun, attribution, embedded content of a communication act or question: named), `restated` (the target's document types the same qualified proposition + scope), `new-document` (tagged `qualified-restatement:` | `extra-claim:`), `inexpressible` (reason → gap taxonomy)}. Readers: researcher-3 (Box 3 + front matter + rec01-05 ace), researcher-4 (rec06-12 ace), researcher-5 (restates); MAIN rules every row.
- Authoring policy (MAIN's best attempt per row; interpretation in `audit/projection-notes.tsv`):
  - The qualifier sits on the event of the action or claim the source qualifies, never on a substituted action.
  - `might` + other truth-attenuating hedges (possibility; usuality on a descriptive claim) → the restored proposition under `can` with the adverb inside (`can possibly need`, `can frequently have`); no `may` remains standing for an epistemic `might`; existing inner negation + necessity stay under the box (`can` → `must`).
  - Softened advice (`might consider`, `might want to`, `can consider` in the optional-suggestion reading) → `may <verb>` (the operator carries the option; no qualifier).
  - Applicability → a guard: an antecedent copula on the thing whose fitness the source judges (`If a nonopioid-therapy is appropriate for a patient then …`; `when possible avoid X` judges the avoidance); an existing guard stays (refined where wrongly targeted, never deleted); an explicit content condition (`if the newborn needs additional treatment`) stays an ordinary antecedent.
  - Focus, manner, force keep the claim's own context + operator (`especially is important`; `should carefully monitor`); a focused subgroup rule carries the focus adverb beside the unchanged general rule.
  - A nominalized qualified action (careful monitoring, cautious titration) becomes the verb + adverb where ACE states the action; a qualifier of a thing stays in its noun.
  - Usuality frequency words never become a time bound; `periodically` stays its own word; `daily`-type schedules are not qualifiers.
  - Statement-level salience (`Importantly, …`): typed on the event + operator path that carry the emphasized statement after restoring the source predication; where no event carries the whole statement, the residual is named in the census + taxonomy (K11).
  - `new-document`: `qualified-restatement` regions become documents (coverage `restates` → `ace`); `extra-claim` regions are counted and ruled (scope ruling at harvest; a claim outside S2's hedge scope → a `.agent/deferred.md` coverage row with its acceptance check).
