# M5.6 — export (dist) (contract)

Unit = `ckc dist build [<dest>]` replacing `tools/dist.py` (map-4 R5 = the
byte-level target: BagIt bag under one root, six tag files, deterministic
tar + gzip, digest sidecar, refusal law). Grading (plan § Verification line):
archive assembly = shell tier over a pinned mature dependency; the verified
release-manifest derivation (M5.4 `release.rs`) + member digests already
anchor the consumer's `sha256sum -c`, so a verified tar writer is optional.

## Tier

- kernel: none new — `release_manifest` (M5.4) derives the manifest; member
  digests = shell sha256 (R3); `manifest-sha256.txt` / `tagmanifest-sha256.txt`
  layouts = two small spec fns added to `release.rs` (sorted `<sha>  <path>`
  lines, tagmanifest excludes itself).
- shell (enumerated, fixture-gated): committed-HEAD reads (source head = last
  commit touching guidelines / fork / clex; epoch = its commit time), rights
  profiles + held-back summary, README-dist/NOTICE prose builders, tar
  writer (sorted members, mode 0644, uid/gid 0, empty names, GNU LongLink
  > 100 bytes, two EOF blocks, 10240-byte records) + gzip level 9 mtime 0
  via the allowlisted dep (`rust/trust/deps-allowlist.tsv` += the one
  crate; `flate2`-class, no-default-features closure), publish = exact-byte
  collision refusal + temp + `os.replace` semantics + sidecar, meters
  `dist: ok` / `dist: sha256`, refusal `dist: <detail>` rc1, usage rc2.
