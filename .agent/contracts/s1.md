## Design

D1 Indicators. Two semantic predicates join the schema; 17 declared indicators (2 records + 15 semantic); declaration order = C1's 15, then these two:
- `guideline_grade(Context, Rec, Dimension, Value, Label)`: the recommendation referent `Rec` carries, in `Dimension` ∈ {`strength`, `evidence`}, the common value `Value` (strength `strong` | `conditional`; evidence `high` | `moderate` | `low` | `very_low`); `Label` = the referent whose noun is the source's own grade label.
- `guideline_preference(Context, Event, Preferred, Alternative)`: in `Event`, the source prefers the option `Preferred`; `Alternative` = the option it is preferred to, or `none` when the source names none.
Codec (K1) = arity + canonical term form, as for the time annotations: any well-formed argument terms load; value domains + argument identities are certification law (D7), never reader law. Either predicate is legal in any document head, body + NAF group and in any raw question goal (C1 D2); identifier stays `1`; document + question records unchanged.

D2 Vocabulary kinds. `vocabulary.tsv` gains four row kinds; C1 law stays (exact one-line header; a row whose first byte is `#` rejects `comment`; three fields; final newline; checks in row order: comment, field count, lemma, kind, value, duplicates):
- `strength <noun> strong|conditional`, `evidence <noun> high|moderate|low|very_low`: a noun occurs in at most one strength|evidence row (across both kinds) and is never a `unit` noun or a `spacing`|`window` frame noun.
- `preference <adjective> preferred`: at most one row per adjective; never an `approximation` adjective.
- `alternative <preposition> alternative`: at most one row per preposition; never the lemma of a `relation`, `frequency`, `range`, `spacing` or `window` row (disjoint prepositions ⇒ no time pattern + preference pattern share a pp).
Each conflict fires in both row orders (the later row reports `duplicate <noun|adjective|preposition>` at its row); a row with a bad value reports `<kind> value` ahead of any duplicate check of that row. Messages extend C1's: `ckc: vocabulary: <path>: <why> at row <n>` / compiler class `vocabulary_load`.

D3 Grade pattern (documents with a table; questions never). A `be` event in context `actual` of a sentence that compiles to facts alone (no rule clause), whose arg 1 = a referent R and arg 2 = an entity L whose noun maps to (Dimension, Value) emits `guideline_grade(actual, R, Dimension, Value, L)` right after that event's arg-2 clause. At most one grade per dimension per document: a second (same or later sentence, same or other R, identical value included) → `unsupported, grade_shape(duplicate_dimension, S)`. A grade noun in any other position (rule, operator box, NAF, question, a non-`be` event, `be` arg 1) emits no grade; its primitive clauses stay as C1 emits them.
Binding: R + L = root-fact referents `'$guideline_id'(product, DocId, S, ref(N), [])` ⇒ the grade's DocId = R's second argument; it rates every statement of that document = every clause whose identity terms (event + referent products, operator contexts) carry that DocId. `Context = actual` is shared across documents and binds nothing. No grade is inherited by another document (an implementation-consideration document stays ungraded) and no rating turns a statement into a recommendation or an obligation.
Worked example (CDC rec03): `A recommendation is a category-A-recommendation and is an evidence-type-4-recommendation.` = one sentence, two `be` events on one R → `guideline_grade(actual, R, strength, strong, A)` + `guideline_grade(actual, R, evidence, very_low, E)`.

D4 Preference patterns (documents with a table; questions never). One decision per event E (any context: root, antecedent, consequent, operator box, NAF group); a pattern's conditions lie in one flattened scope (as the time patterns'):
1. Alternatives = E's `guideline_pp` clauses whose preposition maps to `alternative`, in E's own context; ≥2 → `preference_shape(alternative_count, S)`.
2. Preference copula = a `be` event whose arg 2 is a property whose adjective maps to `preference` (`pos`): Preferred = arg 1.
3. Otherwise, when E has one alternative: Preferred = arg 2 of E (transitive, passive + copula-with-entity alike); no arg 2 → `preference_shape(no_preferred, S)`.
4. Alternative = the one alternative pp's object, else `none` (preference copula alone; an event with neither a preference property nor an alternative pp emits nothing).
5. Endpoints = plain entity referents: a property, a time quantity or a frame noun as Preferred or Alternative → `preference_shape(endpoint, S)`.
6. Emission: one `guideline_preference(Ctx, E, Preferred, Alternative)` in E's context, right after the alternative pp clause when one exists, else right after E's arg-2 clause; in a rule antecedent it is a body goal (every clause of the rule carries it); inside NAF it joins that `\+` group; no pairing across NAF groups or contexts.
7. Order (= spec emit.rs `flatten_doc`): per scope, its C1 time checks (C1 order, its NAF groups' time checks included), then its D4 checks in item order — a violation reports at the event's predicate condition, and a NAF group's payload runs the same D4 pass where the NAF item stands in that order (a parent predicate before a later NAF group reports first); after a sentence's scopes, the D3 duplicate check over that sentence's grade literals against the document's earlier ones; the first violation rejects.
Attributive `preferred` (a noun modifier) emits nothing. Annotations are data: no ranking, transitivity, inverse, prohibition of the alternative or obligation is inferred.
Projection preservation (replaces "primitive clauses byte-identical"): erasing every grade + preference literal (heads + body goals) from an S1 compile yields C1's compile of the same ACE with the table minus its S1 rows — plus one inert old-kind row (a lemma that occurs nowhere in the DRS) when no other row remains, since C1 refuses a header-only table (`vocabulary(no_rows)`) and table presence gates C1 syntax — byte for byte, the 4 added declaration lines + the table digest in the record aside. An annotation in an antecedent therefore adds a goal to each consequent clause; full clause bytes change by that goal alone.
Worked examples (C1 compiler shapes, consultant-2 probes):
- bare `An nsaid is preferred.` → entity N, property P `preferred`, `be` E, arg1 N, arg2 P ⇒ + `guideline_preference(actual, E, N, none)` after arg2.
- transitive `… then the clinician should prescribe an immediate-release-opioid instead-of an ER-LA-opioid.` ⇒ + `guideline_preference(Box, E, IR, ERLA)` after the `instead-of` pp clause.
- combined `An NSAID is preferred instead-of an opioid.` ⇒ Preferred = N (arg 1), Alternative = O; one literal after the pp clause.
- negated `An NSAID is not preferred.` ⇒ the literal sits in the `-` box context; the UI shows the negation (D8).

D5 No table, or a table with no S1 row: no grade or preference pattern runs; `instead-of` stays an ordinary pp; such documents compile byte-identical to C1 apart from the D1 declaration block. A table with S1 rows that no sentence uses = the D4 comparison (digest exception). Unused rows stay legal (no liveness check).

D6 Questions. The goal whitelist = the 15 semantic predicates. Question mode keeps C1's question law: neither D3 nor D4 runs, so an S1 question projection = C1's projection of the same question with the table minus its S1 rows (+ the D4 inert row), byte for byte, the record's table digest aside. A committed ACE question reaches a grade through its source label and a preference through its primitives (`be` + preference property, the alternative pp), which every typed document keeps (D4 projection preservation) — a comparator-free question matches bare and combined preferences alike. The normalized records are reachable by typed queries naming `guideline_grade` / `guideline_preference` directly (CDS consumers; demonstrated by canonical tests/v1 query fixtures, P4). Certification rejects a grade or preference goal in a committed question (no ACE derivation exists).

D7 Certification. `certify_doc` / `certify_query` re-derive D3/D4 from the DRS + the raw table bytes (record digest checked as in C1). A changed, dropped, added, misplaced or duplicated grade|preference literal — wrong Context, Event, Rec, Dimension, Value, Label, Preferred or Alternative — fails as `clauses(S)` | `projection`; a document compiled without a table that carries an annotation fails; primitives unchanged in every mutation case.

D8 UI (clinician copy; no functor names; final form = the user's screenshot ruling at the phase close).
- Document page, ≥1 grade: section "Grade" after the timing table; one row per grade literal: dimension (Strength | Evidence), value in plain words, source label (the label noun as it stands in the pl).
- Document page, ≥1 preference: section "Preferences" after Grade; one row per preference literal: sentence number, part (statement | condition | not-provable condition, as the timing table), how it is stated (the operator path from `actual` to the literal's context, e.g. should, not, should not; plain fact when `actual`), action (event lemma), preferred option (noun), alternative (noun, or "none named").
- Every other page stays byte-identical (the 4-line declaration delta aside: the "Compiled Prolog (N lines)" count).
- Guideline page: the "Time words" section becomes one vocabulary section grouped by kind group — time words (unit … range, C1 order), grade words (strength, evidence), preference words (preference, alternative) — each group with its own explanatory sentence; rows in file order within a kind; a group with no rows renders nothing.
- No judgment note, flag or marker (user ruling d972a813).

D9 Release + export: unchanged law; the README-dist schema section lists both predicates; the release manifest re-derives.
