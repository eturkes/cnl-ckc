# M5.3 — `ckc check` validators (K4) (contract)

Unit = the K4 partition (`archive/rust-rewrite-plan.md` § Kernel partition +
§ Byte-parity strategy) graded by the verification line. Design input =
`.scratch/agents/map-k4.md` (S1–S7 + Register). Legacy `goal.py check`
stays CI-authoritative until M5.7; `ckc check` runs beside it in `just rust`.

## Tier

Mixed, per section (map-k4 S4): kernel = custody/coverage/lexicon/align-
content/adjudication + review-manifest derivation/release-manifest
derivation; shell = inventories, fork-notice/pristine/vendor policy,
compendium, projection-notes, census-map, rights, probes, subprocess
orchestration (rulings R44–R46 below). Spec = `ckc-spec/src/check.rs`
(MAIN-authored) for the kernel sections; shell sections = enumerated
`ckc/src/check/*.rs` files, fixture-gated.

## Scope (M5.3 = sections 1–25 + 31–35 of map-k4 S1; UI/dist/strict
composite wrappers excluded per plan; strict retires at M5.7)

`ckc check [<repo-root>]` runs the legacy dispatcher order over the same
state sources (W/I/H/C/P per section, R45) and prints the same meters +
violations byte-for-byte (`goal:` prefix retained, R44), rc law identical
(V → stdout + rc1; F → stderr + rc2; R relays children). Sections:
source-record, pl/align inventory, prolog inventory, pristine/vendor/fork-
notice, docid/trace-numeric/swipl-wall probes, adjudication fixtures,
compendium (orgs/rows), corpus (projection ledger, product vocabulary,
coverage, census map, adjudication + review-manifest + ledger + commit
row, lexicon), documents (compile determinism/freshness/proof/load via the
pinned swipl + K1/K2 kernels for load/aggregate/recursion), queries
fixtures (K2/K3 seams), trace probes. Excluded here: `check_ui`,
`check_copy_*`, `check_dist*`, `check_strict*` (M5.5/M5.6/M5.7).

## Predicates (acceptance)

- P1 `just verify` green with `check.rs` kernel bindings (coverage closure,
  lexicon gates, align content, review-manifest derivation incl.
  `semantic_clause_sha256` input bytes, ledger classification) discharged.
- P2 `just trust` green (manifest += `check.rs`).
- P3 parity: `ckc check` vs `goal.py check` on HEAD — identical stdout
  meter sequence for the in-scope sections; identical first violation
  (bytes + rc) on every red battery (tests/adjudication 42R/9G,
  tests/queries 24R/11G + pins, tests/red 29 probes) and on ≥30 lead-
  authored corpus mutants (one per section, `.scratch/m5u3/mutants.py`).
- P4 FC2 register ruled: R44 (`goal:` retained), R45 (state sources
  preserved), R46 (Python-traceback paths → structured `goal: <section>:
  <detail>` rc1 classes, enumerated), review-manifest/projection header
  strings retained verbatim.
- P5 `just rust` + `just legacy` green; corpus byte-stable.
- P6 wall: `ckc check` in-scope sections ≤ legacy wall (legacy full check
  ≈ 40 min dominated by 337×4 swipl compiles; the Rust side reuses the
  same subprocess count, so parity ±10 %).

## Gate identities

`just rust`; parity = `python3 -P .scratch/m5u3/parity.py` (lead-authored:
runs both checkers, diffs stdout/rc; mutant loop).

- R58 exec surface (prod-m5u3-1 Phase A, accepted): exec mirrors in

  (`source_lookup`/`digest_lookup`, first match, Missing/empty default) +

  `check_class_count`, `check_adjudication_meter`, `check_lexicon`. Bindings

- R59 `census_of` = first FULL `identify the <digits> payloads below` match
  (legacy `census_rx.search`), not the first `identify the ` occurrence.
- R61 whitespace law = Python `str.strip()`/`str.split()` over the UTF-8
  text, enumerated as byte sequences in `ws_len` (ASCII 09–0D, 1C–1F, 20;
  U+0085, U+00A0, U+1680, U+2000–200A, U+2028/9, U+202F, U+205F, U+3000);
  `strip_ws`/`ws_split` (`lead_ws`, `last_end`, `tokens_acc`) follow it.
- R62 evidence sources = `FileSrc { Symlink, Missing, Unreadable, Bad,
  Bytes }` in legacy read order; `coverage`/`files_check` take the display
  `root` (the guideline path as legacy prints it) and name evidence files
  as `full_path(root, f)` = `root + "/" + f` wherever legacy printed
  `str(evidence_path)` (`is a symlink:`, `missing:`, census/content-line/
  payload-count diagnostics); `rows/locators … for: f` keep the row field;
  R46 classes = `unreadable <full>` / `invalid_utf8 <full>`.
- R63 committed manifest = constructive `parse_manifest(src, path) →
  (prefix, first grammar violation)` in legacy `parse_review_manifest`
  order (encoding, CR, final newline, header lines 1/2, `holds no rows:
  <path>`, per row from row 3: field-count, docid-grammar, duplicate-docid,
  sort-order, the four component names, review_sha256); `review_sha256
  self-consistency` = the shell's hash check over the returned prefix rows
  BEFORE the reported grammar violation (legacy per-row order);
  `manifest_accepts(src, path, review_of)` = clean parse + every row's
  review digest = `review_of(bundle_block)`; binding `check_parse_manifest
  (src: &ESrc, path) -> (Vec<EBundle>, Option<Vec<u8>>)`.
- R64 `adjudication_meter` unreviewed count = `unreviewed(ds, bs)`, total
  (0 when reviewed docids exceed the bundles; unreachable through `ledger`'s
  known-docid law) — `as nat` on a negative int is unspecified, so the
  precondition-free binding could not discharge.
- R68 ledger = `(decision prefix, first grammar violation)` like R63: legacy
