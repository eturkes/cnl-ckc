Reduce the scope of this project dramatically. It should be minimally sufficient for fetching clinical guidelines, normalizing them into ACE, and then compiling them into Prolog, all using a single `/goal` command in Claude Code. Extend/fork APE, Clex, and others where necessary, and build upon the existing work of other people as much as possible. Optimize for the smallest compiler/lexicon that can support the currently analyzed guidelines and adapt the compiler/lexicon as needed. All Prolog must be compiled from ACE. All Python must be compiled from canonical E--. Extend/fork E-- liberally; the upstream is an abandoned proof-of-concept by a solo developer. As much as possible, avoid using libraries in Python so that all aspects of the program can be made transparent. Make exceptions only for libraries that can easily be reasoned about, are considered mature, and may damage the system if implemented incorrected; an example that covers these three cases would be libraries for file system writes. As much as possible, the codebase should only contain Prolog and Python (and their ACE/E-- counterparts). Aim for the smallest codebase possible, including tests, so that a human can audit everything through reading the ACE and E--. Prolog and Python code itself remains agent-oriented, including their comments, Git messages, etc.
